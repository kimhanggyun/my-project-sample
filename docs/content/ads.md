## 2. 띠 배너 광고

### 2.1 노출 위치

```
┌─────────────────────┐
│ 군량 12,000[+] 돈 300[+] ⚙│  ← 상단 바
├─────────────────────┤
│ ░░░░ 띠 배너 광고 ░░░░ │  ← 상단 바 바로 아래
│     (탭별 화면)       │
├─────────────────────┤
│ 스토리 장수 부대 편성    │  ← 하단 탭
└─────────────────────┘
```

### 2.2 노출 규칙

**메인 화면의 탭별 화면에서만** 보인다. 그 밖의 화면에서는 모두 숨긴다.

| 화면 | 배너 |
|---|---|
| 스플래시, 로그인, 약관 동의 | 숨김 |
| 타이틀 | 숨김 |
| **메인 화면 · 각 탭 (스토리, 장수, 부대, 편성, "준비 중" 포함)** | **노출** |
| 설정 팝업 (메인 위에 뜨는 창) | 노출 유지 (제안) |
| 스토리 대사 장면 | 숨김 |
| 출진 준비 (군량 조정 등) | 숨김 (제안) |
| **전투** | **숨김 (확정)** |
| 전투 결과, 포로 처리 | 숨김 |
| 보상형 광고 재생 중 | 숨김 |
| 광고 제거 구매 상태 | 모든 화면에서 숨김 |

### 2.3 화면 배치

- 배너가 보일 때는 배너 높이만큼 탭 화면이 아래로 내려간다.
- 배너를 불러오지 못했거나(인터넷 없음 등) 광고 제거 상태면 **배너 자리를 접어서** 빈칸이 남지 않게 한다.
- 폰마다 다른 화면 위쪽 영역(노치 등)을 고려해 상단 바 아래에 붙인다.
- 배너 크기: 화면 폭에 맞추는 적응형 배너 (광고 서비스 기본 기능).

### 2.4 갱신

- 배너 교체 주기는 광고 서비스 기본값을 따른다.
- 탭을 옮겨도 배너는 다시 불러오지 않고 그대로 유지한다.

## 3. 보상형 광고 (군량 충전)

### 3.1 흐름

```
군량 [+] 버튼 → 확인 창 ("광고를 보고 군량 ○○을 받으시겠습니까?")
 → 동영상 광고 재생 → 끝까지 시청 → 군량 지급 + 알림
                    └ 중간에 닫음 → 지급 없음
```

### 3.2 규칙 (설정값, 수치는 추후)

| 항목 | 설정값 이름 | 기본값 |
|---|---|---|
| 1회 지급 군량 | `rewardSupply` | 미정 |
| 하루 최대 시청 횟수 | `dailyLimit` | 미정 |
| 다시 볼 때까지 대기시간 | `cooldownSec` | 미정 |
| 하루 초기화 시각 | `dailyResetTime` | 00:00 (기기 시간, 서버 도입 후 서버 시간) |

- 남은 횟수와 대기시간은 [+] 버튼 근처에 표시한다 (예: "오늘 3/5회").
- 광고를 불러올 수 없을 때(인터넷 없음, 광고 재고 없음): "지금은 광고를 볼 수 없습니다. 잠시 후 다시 시도해 주세요."
- 광고 제거 구매자도 보상형 광고는 그대로 볼 수 있다.

### 3.3 부정 보상 방지

- 서버 도입 전: 기기에서 시청 완료 신호를 받으면 지급.
- 서버 도입 후: 광고 서비스가 서버로 시청 완료를 알려주는 **서버 검증** 방식으로 바꾼다.

## 4. 광고 제거 상품 (앱 결제)

### 4.1 상품 목록

| 상품 | 가격 | 효과 | 상품 형태 |
|---|---|---|---|
| 배너 광고 영구 제거 | 5,000원 | 띠 배너 영구 제거 | 비소모성 (한 번 사면 계속 유지) |
| 배너 광고 한 달 제거 | 1,000원 | 구매 시점부터 30일간 띠 배너 제거 | **30일 이용권 (자동 갱신 없음, 확정)** |

- 구글 플레이와 앱스토어 **둘 다** 같은 상품을 등록한다 (동시 출시).
- 상품 목록은 데이터(`products.json`)로 관리해서 나중에 상품을 추가하기 쉽게 한다.

### 4.2 한 달 상품의 형태 (확정: 30일 이용권)

| 방식 | 장점 | 단점 |
|---|---|---|
| **30일 이용권 (확정)** | 단순함. 자동 결제가 없어 사용자 부담이 적음 | 기간이 끝나면 다시 사야 함 |
| 월 구독 (자동 갱신) | 꾸준한 수익 | 구독 관리·해지·환불 처리와 스토어 구독 정책 대응이 필요 (채택 안 함) |

- 스토어 등록: 한 번 쓰고 끝나는 **소모성 상품**으로 등록하고, 효과(30일)는 게임이 기록·관리한다.

### 4.3 구매 규칙

- **한 달 상품 중복 구매**: 남은 기간에 30일을 더한다 (예: 10일 남았을 때 사면 40일).
- **영구 제거를 산 경우**: 한 달 상품은 상점에서 숨긴다.
- **한 달 상품 사용 중 영구 제거 구매**: 영구 제거가 우선. 남은 기간은 의미가 없어진다 (구매 화면에서 안내).
- **만료**: 30일이 지나면 배너가 다시 나온다. 만료 며칠 전 알림은 추후 검토.
- **구매 복원**: 설정에 "구매 복원" 버튼을 둔다. 앱을 지웠다 다시 깔거나 기기를 바꿨을 때 영구 제거를 되살린다 (애플 정책상 필수).
- **환불**: 스토어에서 환불된 구매는 효과를 되돌린다 (서버 도입 후 처리).
- **게스트 계정**: 구매 기록은 스토어 계정에 남으므로 "구매 복원"으로 되살릴 수 있다. 계정 연동을 권장하는 안내를 둔다.

### 4.4 가격 주의

- 구글 플레이는 원하는 원화 가격을 직접 정할 수 있다.
- 앱스토어는 **정해진 가격 단계 중에서 골라야** 해서 정확히 1,000원·5,000원이 없을 수 있다. 그 경우 가장 가까운 단계를 고른다 (등록 시 확인).
- 스토어 수수료가 빠진 금액이 수익이 된다.

### 4.5 구매 화면 위치

- 설정 팝업 안 "광고 제거" 항목.
- 상점 탭이 생기면 상점에도 함께 노출.

## 5. 광고 동의·정책

| 항목 | 내용 |
|---|---|
| 아이폰 추적 허용 요청 (ATT) | 첫 실행 약관 동의 단계에서 요청. 거부해도 광고는 나오지만 수익이 낮아짐 |
| 지역별 광고 동의 | 유럽 등 해당 지역 사용자에게 광고 동의 화면 (광고 서비스의 동의 도구 사용) |
| 연령 | 아동 대상 앱이 아니므로 일반 광고 사용. 스토어 연령 등급과 맞춘다 |
| 개인정보 처리방침 | 광고 식별자 사용 사실을 기재 |

## 6. 데이터 예시

`ads.json`

```json
{
  "banner": {
    "enabled": true,
    "showOn": ["mainTabs", "settingsPopup"]
  },
  "rewarded": {
    "supply": { "rewardSupply": 0, "dailyLimit": 0, "cooldownSec": 0 }
  }
}
```

`products.json`

```json
[
  { "id": "remove_banner_permanent", "type": "nonConsumable", "priceKRW": 5000,
    "effect": { "removeBanner": "permanent" } },
  { "id": "remove_banner_30d", "type": "pass", "priceKRW": 1000,
    "effect": { "removeBanner": { "days": 30, "stack": true } } }
]
```

## 7. 코드 구조

| 클래스 | 역할 |
|---|---|
| `IBannerAdService` | 배너 표시·숨김, 배너 높이 전달 |
| `BannerVisibilityController` | 현재 화면과 광고 제거 상태를 보고 배너 표시 여부 결정 (2.2 규칙) |
| `IRewardedAdService` | 보상형 광고 재생, 끝까지 본 경우만 보상 콜백 |
| `AdRewardService` | 군량 지급, 하루 횟수·대기시간 관리 |
| `AdRemovalEntitlement` | 광고 제거 권한: 영구 여부, 만료 시각. `ITimeProvider` 사용 |
| `IStoreService` | 구매, 구매 복원 (Google Play + App Store) |
| `PurchaseHandler` | 구매 완료 → 상품 효과 적용 (`products.json`의 `effect`) |
| `AdConsentService` | ATT, 지역별 광고 동의 |

광고 서비스(LevelPlay 또는 AdMob)는 위 인터페이스 뒤에 숨겨서, 나중에 바꿔도 다른 코드는 그대로 둔다.
