# 용병 등록 · 고용 (온라인)

> 상태: 기획 중 (구현 전) · **서버 필수**

## 1. 목적

장수 키우기·부대 키우기의 목적은 **다른 유저가 고용할 만한 장수·부대를 만드는 것**이다.

```
키우기 ──▶ 서버에 등록 ──▶ 다른 유저가 전투 기록을 보고 고용 ──▶ 등록한 유저에게 보상
   ▲                                                              │
   └──────────────────── 보상으로 다시 키우기 ◀─────────────────────┘
```

- 사용자는 장수·부대를 키워서 **서버에 등록**한다.
- 등록된 장수·부대는 **다른 유저가 고용**할 수 있다.
- 고용되면 등록한 유저에게 **보상**이 간다.
- 등록된 장수·부대의 **이력(전투 기록)**은 서버에 쌓이고, 다른 유저가 보고 고용할지 판단한다.

---

## 2. 등록

| 항목 | 내용 (초안) |
|---|---|
| 등록 단위 | **장수 + 그 군단**(소부대 6개 병종, 진형, 스킬) 한 세트 (제안) |
| 등록 내용 | 등록 시점의 **복사본**(스냅샷): 레벨, 능력치, 병력, 병종, 배운 진형·스킬, 특성 |
| 원본 | 등록해도 내 장수·부대는 그대로 쓸 수 있다 (제안) |
| 갱신 | 더 키운 뒤 다시 등록하면 새 스냅샷으로 교체. 이력은 이어진다 |
| 등록 수 한도 | 설정값 (예: 3개) |
| 등록 해제 | 언제든 가능 (고용 중인 건 그 전투가 끝난 뒤 해제) |
| 고용 가격 | 등록한 유저가 범위 안에서 정함 / 전투력에 따라 자동 (결정 필요) |

---

## 3. 고용

| 항목 | 내용 (초안) |
|---|---|
| 고용 화면 | 등록된 장수·부대 목록, 검색·정렬 (병종, 능력치, 승률, 가격, 레벨) |
| 고용 단위 | **전투 1회** (제안). 출진 준비에서 고용 장수를 편성 슬롯에 넣는다 |
| 지휘 | 고용한 유저가 자기 군단처럼 지휘한다 |
| 결과 영향 | 고용한 전투에서 병력이 줄거나 포로가 돼도 **원본에는 영향 없음** (제안). 대신 **이력에 기록**된다 |
| 비용 | 고용한 유저가 돈(또는 군량)을 낸다 |
| 보상 | 등록한 유저에게 지급 (비용에서 일정 비율 + 승리 보너스 등, 결정 필요) |
| 제한 | 하루 고용 횟수, 같은 장수 연속 고용 대기시간 (설정값) |
| 자기 장수 | 내가 등록한 장수는 내가 고용할 수 없다 |

---

## 4. 이력 (전투 기록)

등록된 장수·부대마다 서버에 기록한다. 다른 유저가 고용 전에 본다.

| 기록 | 예 |
|---|---|
| 고용 횟수 | 128회 |
| 승률 | 72% (승 92 / 패 36) |
| 결과 분포 | 승리 · 패배 · **퇴각** · **포로** 횟수 |
| 전투 성과 | 평균 격파 병력, 평균 손실(사망·부상), 평균 생존율 |
| 상대 | 주로 이긴·진 상대의 전장 유형·진형 |
| 최근 전투 | 최근 N회: 날짜, 스텝(전장), 결과, 고용한 유저, 주요 수치 |
| 등록 정보 이력 | 스냅샷이 바뀐 날짜와 레벨 변화 |
| 원본 기록 (선택) | 등록한 유저가 직접 싸운 전투 기록도 공개할지 (결정 필요) |

- 기록은 **조작할 수 없어야** 한다 (5장).

---

## 5. 공정성 (서버 검증)

전투가 기기에서 계산되면 결과를 조작해 이력·보상을 부풀릴 수 있다. 그래서:

- 전투 규칙(Model)은 **고정 시드로 같은 입력이면 같은 결과**가 나오게 만든다 (이미 설계에 있음).
- 기기는 결과 대신 **전투 입력**(시드, 편성, 명령 기록)을 서버에 보낸다.
- 서버가 같은 C# 규칙 코드로 **다시 계산(재현)**해서 결과를 확정하고, 그 결과로 이력·보상을 기록한다.
  - Unity Gaming Services의 Cloud Code(C#) 또는 별도 서버에서 같은 Model 코드를 실행한다.
- 재현 결과와 기기 결과가 다르면 기록하지 않는다.

---

## 6. 화면

- **고용 탭** (하단 탭 추가, 5개째): 등록 목록 보기·검색, 상세(능력치 + 이력), 고용.
- **내 등록 관리**: 장수 키우기 탭 또는 고용 탭 안에서 등록·갱신·해제, 받은 보상 확인.
- **출진 준비**: 편성 슬롯에 고용 장수 넣기.

---

## 7. 장수·부대 키우기와의 관계

- 장수 키우기·부대 키우기는 이 기능 때문에 **핵심 컨텐츠**가 된다 (키운 결과가 수익이 됨).
- 키우기 탭의 세부 컨텐츠는 나중에 구성하지만, **등록 가능한 데이터 형태**(스냅샷)는 지금 정의해 둔다.

---

## 8. 미결 사항

- [ ] 등록 단위: 장수 + 군단 세트(제안) / 장수만 / 부대만 따로도 가능
- [ ] 고용 가격: 등록자가 정함 / 전투력 자동 계산
- [ ] 보상 출처와 크기: 고용 비용의 일부 / 시스템 지급 / 둘 다, 승리 보너스 여부
- [ ] 고용한 전투 결과가 원본에 영향을 줄지 (제안: 영향 없음, 이력만 기록)
- [ ] 고용 지불 자원 (돈 / 군량)
- [ ] 원본 전투 기록 공개 여부
- [ ] 고용 탭 해금 시점 (처음부터 / 스텝 N 이후)
- [ ] 평판·후기 등 추가 정보 여부
