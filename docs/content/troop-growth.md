# 부대 키우기 (TO-BE)

> 상태: **TO-BE** — 하단 탭에 "준비 중"으로 표시. 컨텐츠는 나중에 구성한다.
> 전체 흐름: [../flow.md](../flow.md) · 관련 규칙: [battle.md](battle.md) 2.2.1(진형), 2.3(병종과 성장) · 코드: [../architecture.md](../architecture.md) 4 Game.Progression

## 1. 목적

부대(병종)를 특화 병종으로 성장시키고, 새 전술 진형을 늘린다.

**최종 목적: 다른 유저가 고용할 만한 부대를 만드는 것.** 장수와 함께 서버에 등록되어 고용 대상이 된다 ([hiring.md](hiring.md)).

## 2. 지금까지 정해진 것

- **병종 승급**: 기본 4병종(보병·창병·궁병·기병)에서 특화 병종으로 승급한다. 승급 트리는 [battle.md](battle.md) 2.3.
- 승급 조건(초안): 소부대 숙련도, 장수 레벨, 스텝 해금.
- **진형 해금**: 특정 컨텐츠로 새 진형을 배운다.
- 병종·진형은 모두 데이터(`troopTypes.json`, `formations.json`)라 추가가 쉽다.

## 3. 탭이 생기기 전까지

- 병종은 초기 지급 구성 그대로, 진형은 초기 지급 + 스토리 보상으로만 늘어난다.

## 4. 연결 방식

- 이 탭은 **부대 데이터(병종, 숙련도, 배운 진형)를 바꾸는 역할만** 한다. 전투·편성 코드는 바뀌지 않는다.
- 탭 모듈: `TroopGrowthTab`, `PromotionService`.

## 5. 미결 사항

- [ ] 승급 조건 확정과 첫 버전 승급 트리
- [ ] 진형 해금 컨텐츠
- [ ] 성장에 쓰는 자원
