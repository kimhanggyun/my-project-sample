# 부대 편성 · 초기 지급

> 상태: 기획 확정 (구현 전) · 범위: Step 1~2
> 전체 흐름: [../flow.md](../flow.md) · 관련: [story.md](story.md)(출진 준비), [battle.md](battle.md)(군단 구조·진형) · 코드: [../architecture.md](../architecture.md) 4.5 Game.Campaign, 6 Game.UI

## 1. 장수·부대 능력치가 바뀌는 경로

장수 키우기·부대 키우기는 TO-BE이므로, 장수·부대 능력치는 **초기 지급값 + 전투 결과(경험치·레벨업)**로만 바뀐다. 출전 구성은 **부대 편성 탭**에서 정한다 (스텝 데이터는 적군만 정함).

- 아군 출전 장수·부대는 **부대 편성**에서 가져온다. 스텝 JSON에는 적군, 맵, 출전 가능한 군단 수 등만 넣는다.
- 장수·부대의 능력치는 스텝 JSON 값과 전투 결과(경험치·레벨업)로 바뀐다.
- 나중에 키우기 탭이 생기면, 그 탭이 같은 데이터(장수 능력치, 부대 병종·진형)를 바꾸는 방식으로 붙는다. 전투 쪽은 수정하지 않는다.

## 2. 초기 지급 (새 게임)

새 게임을 시작하면 바로 출전할 수 있도록 기본 장수와 부대를 지급한다.

| 항목 | 내용 |
|---|---|
| 장수 | **3명** (기본 군단 수 3과 맞춤). **익명**(임시 이름, 예: 장수 A·B·C) |
| 능력치 | **중간 정도** (1~100 기준 약 50 전후). 세 장수의 합계는 비슷하게, 성격은 다르게 (예: 통솔형 / 무력형 / 지략형) |
| 레벨 | 1 |
| 군단 | 장수마다 군단 1개. 소부대 6개 병종 기본 구성 (예: 보병·창병·궁병 혼합) |
| 병력 | 장수 **통솔에 따라 5,000 ~ 20,000** 한도까지 채워서 지급 ([battle.md](battle.md) 2.4.4) |
| 진형·스킬 | 기본 진형 1~2종, 기본 스킬 0~1개 (배운 상태로 지급) |
| 군량 | 시작 군량 (첫 전투 몇 번 분량) |
| 편성 | 기본 편성 1개가 미리 채워져 있음 |

- 장수 이름·능력치·병종 구성은 **데이터(`startingKit.json`)**로 정의한다. 지금은 임시 값으로 넣고 나중에 교체한다.
- 키우기 탭이 생기기 전까지 새 진형·스킬은 **스토리 보상**으로 얻게 할 수 있다 (스텝 데이터에 보상으로 지정).

## 3. 부대 편성 탭

- 보유 장수를 군단 슬롯(기본 3개)에 배치한다.
- 군단마다 소부대 6개(선봉·중앙·좌익·우익·좌비·우비)의 병종을 고르고, 배운 진형 중 하나를 고른다.
- **상황별 편성 저장**: 야전·공성·공격·수비 편성을 따로 저장해 둔다. 출진 시 스텝의 전장 유형에 맞는 편성이 자동 선택된다.
- 포로가 된 장수는 편성에서 빠지고 "포로" 표시가 붙는다.


## 3.1 병력 관리 (편성 탭 안)

부대 키우기 탭이 TO-BE이므로 병력 보충은 **편성 탭의 군단 상세 화면**에서 한다.

| 기능 | 내용 |
|---|---|
| 병력 현황 | 출전 가능 병력 / 부상병(회복까지 남은 시간) / 한도 |
| 징병·모병 | 군량을 써서 새 병사 보충 (한도까지) |
| 치료 | 군량(징병·모병 비용의 절반)으로 부상병 즉시 회복 |

- 비용·속도 수치는 `balance.json` 설정값. 규칙은 [battle.md](battle.md) 2.4.4, 비용 흐름은 [economy.md](economy.md).

## 4. 교체·확장 포인트

| 바꾸고 싶은 것 | 방법 |
|---|---|
| 초기 장수·군량·진형 | `startingKit.json` 수정 |
| 상황별 편성 종류 (야전·공성 …) | 편성 프리셋 목록 데이터 |
| 군단 슬롯 수 | 기본 3 (`balance.json`), 스텝별 덮어쓰기 ([battle.md](battle.md) 2.0) |
| 키우기 컨텐츠 연결 | 키우기 탭이 같은 장수·부대 데이터를 바꾸면 편성에 자동 반영 |

## 5. 미결 사항

- [x] 초기 장수 3명 → 익명(임시 이름). 성격은 통솔형 / 무력형 / 지략형
- [x] 초기 군단 병력 → 통솔에 따라 5,000 ~ 20,000
- [x] 잃은 병력 → 사망은 회복 불가, 부상은 시간 회복. 군량으로 징병·모병, 치료는 절반 비용
