# 군량 · 결제 (경제)

> 상태: 기획 확정 (구현 전) · 범위: Step 1(표시·보유), Step 2(소비·포획), 결제·광고는 이후
> 전체 흐름: [../flow.md](../flow.md) · 전투 중 소비 규칙: [battle.md](battle.md) 2.15 · 광고: [ads.md](ads.md) · 코드: [../architecture.md](../architecture.md) 4.6 Game.Economy

## 1. 군량의 역할

- 게임 진행 자원. **출진하려면 군량이 필요**하다.
- 전투 길이를 정한다 (군량이 떨어지면 사기 하락 → 퇴각).

## 2. 군량 흐름

```
얻기                                   쓰기
─────────────────────────────          ─────────────────────────
시작 군량 (초기 지급)          ──┐
광고 보기 보상                 ──┤
앱 결제 (상점, 추후)           ──┼──▶  보유 군량  ──▶ 출진 시 지참 (자동 3분 분량, 증감 가능)
특수 패키지 시간 회복 (추후)   ──┤                      │
승리 시 적 군량 포획           ──┘                      ▼
                                              전투 중 소비 (병사 1명 하루 1, 1분 = 1주)
                                                        │
                                              남은 지참 군량 반환 ──▶ 보유 군량
```

## 3. 규칙 요약

| 항목 | 규칙 | 상세 |
|---|---|---|
| 소비 | 병사 1명 하루 1, 전투 1분 = 7일. 특수 병종 2·3 (확장) | [battle.md](battle.md) 2.15 |
| 출진 지참 | 자동 약 3분 분량, 플레이어가 증감 | [story.md](story.md) 4 |
| 남은 지참분 | 전투 후 반환 | |
| 승리 포획 | 적 남은 군량. 퇴각한 적은 생존 병사 몫만 가져가고 나머지 몰수 | [battle.md](battle.md) 2.15 |
| 광고 보상 | [+] 버튼 → 보상형 광고 → 군량 | [ads.md](ads.md) 3 |

## 5. 교체·확장 포인트

| 바꾸고 싶은 것 | 방법 |
|---|---|
| 자원 종류 추가 (예: 판타지의 마나) | 자원 종류 데이터 추가 (`Wallet`은 종류를 데이터로 관리) |
| 자원 이름 (군량 → 식량 등) | 테마 문자열 ([../theme.md](../theme.md)) |
| 소비·포획 수치 | `balance.json` |
| 상품 추가 | `products.json` + 스토어 등록 |
