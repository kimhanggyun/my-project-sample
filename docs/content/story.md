# 스토리 탭 · 출진

> 상태: 기획 확정 (구현 전) · 범위: Step 1(스텝 목록·대사), Step 2(출진·전투 연결)
> 전체 흐름: [../flow.md](../flow.md) · 관련: [battle.md](battle.md), [formation.md](formation.md), [captivity.md](captivity.md), [economy.md](economy.md)

## 1. 흐름

```
스토리 탭 → 스텝 목록 → 스텝 선택 → (대사) → 출진 준비(편성 확인·군량) → 전투 → 결과 → (포로 처리) → (대사) → 저장 → 다음 스텝 해금
```

- 스텝은 차례로 해금된다.
- 아군 장수가 포로가 되면 스텝 목록에 **구출 전투**가 따로 표시된다 (수용소 이름 표기). 이기면 장수가 돌아온다.
- 적 장수를 잡으면 결과 화면 다음에 **포로 처리(등용·해방)** 화면이 나온다.
- 대사는 임시 텍스트로 넣고 나중에 교체한다.
- 출진 직전에 **"출진 준비"** 단계가 있다: 스텝의 전장 유형에 맞는 편성이 자동으로 선택되고(그 자리에서 변경 가능), 가져갈 군량을 조정한다.


## 2. 스텝 데이터

- 스텝(step01, step02 …)마다 JSON 하나. 형식은 [battle.md](battle.md) 6장 "스텝 JSON 예시".
- 스텝이 정하는 것: 전투 이름, 세력, 맵(안개 포함), 적 군단·레벨·군량, 출전 가능한 아군 군단 수, 승패 조건, 이벤트(대사·증원), 보상(경험치, 진형·스킬 해금).
- 아군 출전 구성은 스텝이 아니라 [부대 편성](formation.md)에서 가져온다.
- 스텝을 추가하는 방법: JSON 파일 하나 + 대사 파일 추가. 코드 수정 없음.

## 3. 대사

- 대사 파일은 스텝마다 전/후로 분리 (`stepNN_before`, `stepNN_after`) + 전투 중 이벤트 대사.
- 지금은 **임시 대사**를 넣고, 나중에 파일만 바꿔 넣는다.

```json
[
  { "speaker": "general_a", "portrait": "general_a", "text": "(임시 대사) 출진하라!" }
]
```

- `speaker`는 장수 id. 화면에 보이는 이름은 테마 문자열에서 가져온다 ([../theme.md](../theme.md)).

## 4. 출진 준비

1. 스텝의 전장 유형(야전·공성 …)에 맞는 편성이 자동 선택된다. 바꿀 수 있다.
2. 가져갈 군량이 자동 계산된다 (약 3분 분량). 늘리거나 줄일 수 있다 ([economy.md](economy.md)).
3. 출전 → 전투 ([battle.md](battle.md)).

## 5. 전투 이후

- 결과 화면: 승패, 경험치·레벨업, 포획한 군량.
- 포로 처리: 적 장수 등용·해방, 아군 장수 포로 시 구출 전투 생성 ([captivity.md](captivity.md)).
- 저장 → 다음 스텝 해금.

## 6. 교체·확장 포인트

| 바꾸고 싶은 것 | 방법 |
|---|---|
| 스텝 추가·수정 | `Steps/stepNN.json` |
| 대사 교체 | `Story/stepNN_*.json` |
| 스텝 해금 규칙 | `StepFlow` (차례 해금이 기본) |
| 스토리 대신 다른 진행 방식 (예: 전략 지도) | 같은 `BattleSetup`을 만들어 전투 호출, `BattleResult`를 받아 처리 ([../flow.md](../flow.md) 5장) |
