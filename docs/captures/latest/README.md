## 원격에 넘길 버그

### B5. 퇴각 선택 창과 조언 창이 동시에 뜬다
- 재현: 샘플전투 test_plain, ×4 → 장수 C 사기 30대로 떨어질 때
- 기대: 퇴각 선택 창 하나 (조언 창은 그 뒤나 아예 안 뜸)
- 실제: 위에 조언 창 "장수 C: (임시) 병사들이 흔들립니다!" + [후퇴][휴식][재정비][닫기], 아래에 퇴각 선택 창. 위쪽 알림 줄도 "장수 C: 퇴각할지 버틸지 정해야 한다!"로 같은 말을 세 번 한다
- 캡처: pt36
- 추정: 사기 경고 조언(SpeechPlanner/조언)과 퇴각 기준 창이 같은 틱에 따로 뜸. 퇴각 창이 떠 있는 동안 같은 군단의 사기 조언을 막기.

### B6. 퇴각·패주 알림 확인 못 함 (도구 한계일 수 있음)
- 재현: 위 창에서 [버틴다] 또는 [퇴각한다] → 90초 지켜봄
- 기대: "장수 C 군단이 끝내 무너져 패주한다!" / "…사기가 무너져 퇴각한다."
- 실제: 도구가 화면 글자에서 두 문장을 못 찾음 (90초). 알림이 아주 짧게 떴다 사라졌거나, 대답이 안 먹었을 수 있다
- 다음: 데스크탑이 도구를 고쳐 누른 뒤 2초마다 캡처하도록 하거나, 사람이 한 번 직접 확인. 규칙 테스트(R-93)로 이미 확인했다면 화면 쪽 알림만 남음

### B7. 사기 막대가 장수 머리와 겹친다
- 재현: 접전 중 카메라를 장수 가까이(거리 12)
- 실제: 이름표 "★적장 정" 아래 막대가 장수 모델의 머리 위에 겹쳐 그려진다 (pt34_zoom)
- 제안: 이름표·막대를 장수 모델 키(+탈것)보다 조금 더 위로, 또는 카메라 거리에 따라 올림

### B8. 총대장 쪽으로 카메라를 옮기면 빈 땅이 보인다
- 재현: 전투 시작 직후 `BattleField3D.LookAt(총대장 군단)` + `Rig.SetDistance(8)`
- 실제: P1(아군 총대장)·enemy_corps_01(적 총대장) 캡처가 군단 없이 빈 땅. 일반 장수(P2·P3)는 제대로 보임
- 추정: 총대장 군단의 `Anchor`가 화면 위치와 다르거나(맵 끝 근처), 카메라가 맵 끝에서 막힘. 사람이 지도에서 총대장을 눌러 확대할 때도 그런지 확인 필요
