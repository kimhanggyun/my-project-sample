## 리뷰 (2026-11-13)

화풍은 바꿔도 된다(사용자). 지금 문제는 화풍보다 **모든 화면이 같은 모양의 글자 상자**라 중요도가 안 보이는 것.

### 공통
1. **하단 탭 넘침**: "부대 정비" 오른쪽 탭이 잘린다. 5개 이하 + 아이콘 권장 (예: 스토리 / 장수(키우기·포로) / 부대(키우기·정비) / 영지 / 대결).
2. **버튼 위계 없음**: 주요·보조·비활성이 구분 안 된다. 비활성 회색 = 잠긴 스테이지 = 타이틀 "시작"(연결 중). 제안: 주요 = 주홍 채움, 보조 = 테두리, 비활성 = 흐림 + 자물쇠/이유.
3. **상단 재화 바**: "+" 버튼이 재화보다 눈에 띈다. 작게.
4. **화면 맨 위 설명 문장**: 작고 연한 회색이라 폰에서 안 읽힌다 → 첫 안내나 ⓘ로.
5. **안내 팝업이 화면 가운데를 가림** (05, 07, 18) → 대상을 가리키는 말풍선으로.
6. **돈 부족 표시 없음**: 돈 3인데 비용 60~1,000 버튼이 활성처럼 보인다 → 모자라면 비용 빨강.
7. 색 의미가 화면마다 다름 (초록·파랑·빨강 글자). 색 토큰을 정해 통일.

### 화면별
- 01 타이틀: 위 절반 빈 화면. "화면을 눌러 시작"과 "시작" 버튼이 중복.
- 03 약관: 체크박스가 버튼 안에 있어 누르면 동의인지 보기인지 헷갈림.
- 04 스토리: 단순 목록 → 두루마리 지도 위 경로·지점 형태 제안.
- 05·11 장수: 초상 자리 없음. 희귀도는 글자 대신 카드 테두리 색.
- 06 부대 키우기: 길고 빽빽함. 훈련·승급 버튼 모양이 같음 → 승급은 펼치기로.
- 08 영지: 거의 빈 화면 (지도 자리).
- 09 고용: "불러오는 중..."에서 멈춘 듯 → 서버 응답 확인 필요.
- 10 출진 준비: 정보 구성 좋음. 적·아군 좌우 비교 배치 제안.
- 12 모집: 가운데가 비어 있음 (배너 자리).
- 15 설정: **세이브 경로(Windows 사용자 이름)와 서버 주소가 그대로 보임** → 출시 빌드에서 숨기기.
- 17 대사: 화면 80%가 비어 있음 (말하는 장수 전신 그림 자리).
- 18 전투: 상단 정보(스테이지·군량·바람)가 어두운 바탕에 어두운 글자라 안 보임. 지형은 회색 덩어리, 부대는 작은 점. 명령 버튼 13개가 한 판 → 자주 쓰는 명령만 남기고 진형·스킬은 따로 펼치기.
- 20 결과: 부대 순서 뒤섞임(1, 2, 3, 7, 8, 6, 9…). "부대 결속" 13줄이 모두 −1 → 한 줄 요약. 패배 시 "다음에 할 일"(병력 보충 등) 안내 없음.
