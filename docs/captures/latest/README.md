## 데스크탑이 고친 화면 버그

- **전투 위 두 줄(스테이지·시간 / 군량·바람·날씨)이 안 보임**: 3D 전장을 그릴 때 화면 배경을 꺼서 검은 바탕에 먹색 글자였다 → `BattleScreen` 위 두 줄에 `Palette.Bar` 바탕 (pt17에서 확인).
- **탭 줄 "›"가 끝에서도 남음**: 끝까지 밀면 숨김 (`MainScreen.MoreHint`, pt02에서 확인).

## 원격에 넘길 버그

### B1. 마스터 지급이 모두 거절됨 (서버 설정·정책)
- 재현: 개발 빌드(에디터) → 마스터 탭 → [+100,000 군량] 등 / [모든 스텝 깬 것으로] / [모든 장수 받기]
- 기대: 상단 숫자가 바뀌고 스텝·장수가 늘어난다
- 실제: "서버 마스터 계정이 아닙니다. 서버가 거절해 되돌아갑니다. 위 계정 id를 서버 설정 Game:Masters에 넣어 주세요." 자원·스텝(2/12)·장수(3) 그대로
- 캡처: pt04
- 추정: 이 계정(`acct-7b35c8e4e6c05570`)이 서버 `Game:Masters`에 없다. 서버에 넣을지, 개발 빌드는 서버를 끄면 로컬로 지급되게 할지 정해 줘.

### B2. 적의 일기토 신청 알림 문구가 거꾸로
- 재현: 전투 중 적장이 일기토를 걸어 옴
- 기대: "적장 정이(가) 장수 A에게 일기토를 걸어 왔다!" (창 안 문장은 맞음)
- 실제: 위쪽 알림 "장수 A: 적장에 일기토를 걸어 왔다!" — 주어가 우리 장수처럼 읽힘
- 캡처: pt14 (화면 맨 위)
- 추정: 알림 문구 키(대사·이벤트 알림)의 주어 자리. 문구 수정 필요 (strings).

### B3. 교전 중 빼기(R-88) 미확인
- 위 표 5번. 총대장이 맵 끝에 있어 시험이 성립하지 않았다. 규칙 테스트(R-88)가 있다면 그쪽 결과를 믿고, 아니면 사람이 한 번 해 보기.

### B4. 마주침 일기토 기회 창이 이번 두 전투에서 안 뜸
- 재현: 샘플전투 test_plain, ×4로 약 2분 두 번
- 기대: 대장끼리 가까워지면 [일기토 신청]/[넘어가기]
- 실제: 적의 신청 창만 떴고 마주침 기회 창은 못 봄
- 추정: 확률·거리 조건(contests.json `duel.trigger`)상 드문 것일 수 있다. 버그가 아니면 무시.

### 참고 (버그 아님)
- 큰 전투 FPS는 에디터 값이라 폰 측정이 따로 필요하다 (`soldierBudget` 2000을 낮출지는 폰 결과로).
- 장수 화면 ⓘ 카드가 열리면 맨 위 [장수 모집] 버튼 아래쪽을 덮는다 (pt19). 닫으면 되므로 그대로 둠.
