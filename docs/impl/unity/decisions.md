## 1. 구현 후보

| 항목 | 후보 (잠정) | 이유 | 관련 요구사항 |
|---|---|---|---|
| 엔진 | Unity | 모바일 3D, 안드로이드·아이폰 동시 출시 | 플랫폼 |
| 버전 | **Unity 6.3 LTS — `6000.3.28f1` (확정, 2026-11)**. 6.x 안의 다음 LTS(예: 6.7)가 나오면 그때 올릴지 정한다 | 장기 지원(2027-12까지), 대량 렌더링 개선. 6.6은 LTS가 아니라 지원이 짧음 | 병사 대량 표시 |
| 개발 환경 | **Windows** + Unity Hub, Git for Windows + Git LFS (`core.longpaths true`), 짧은 경로에 clone (예: `C:\dev\my-project-sample`) | 개발·안드로이드 빌드는 Windows에서 모두 가능 | 플랫폼 |
| iOS 빌드 | Windows에서는 Xcode 프로젝트까지만. 실제 빌드·서명·업로드는 **Mac + Xcode 또는 Unity Build Automation(클라우드)** | iOS 빌드는 macOS 필요 | 플랫폼 |
| 렌더링 | URP | 모바일 기본 파이프라인 | 성능 |
| 3D 아트 | 장수는 세밀하게, 병사는 스타일라이즈드(로우폴리 + 카툰) | 대량 병사를 저사양 폰에서도 표시 | 화면 병사 최대한 많이 |
| 대량 병사 | GPU 인스턴싱, 애니메이션 굽기, 거리별 단순화, 품질 자동 조정 | 성능 | 화면 병사 최대한 많이 |
| 대량 처리 확장 | 필요 시 DOTS | 병사 수천 단위 | |
| 언어 | C# (규칙은 Unity 비의존 순수 C#) | 서버에서도 같은 코드로 전투 재현 | 결정적 전투, 서버 검증 |
| 데이터 | JSON (StreamingAssets), Newtonsoft.Json (`com.unity.nuget.newtonsoft-json`) | 텍스트 편집, 클라우드에서도 수정 | 데이터 주도 |
| 결제 | Unity IAP (구글 플레이 + 앱스토어) | 하나로 두 스토어 | 결제 |
| 광고 | Unity LevelPlay 또는 Google AdMob (중개) | | 광고 |
| 백엔드 | Unity Gaming Services (인증, 클라우드 저장, Cloud Code C#) 또는 PlayFab | 서버 재현에 같은 C# 코드 사용 가능 | 고용·이력·검증 |
| 결정적 계산 | **10진 고정소수점 `Fix`(소수 4자리) 채택 (확정, [../core.md](../core.md))**. 부동소수점 차이 방지 | 서버 재현·실시간 대전 락스텝 | 결정적 전투 |
| 실시간 대전 (확장) | 명령 중계 서버(예: Unity Relay, Photon 등) + 락스텝 | 명령만 주고받아 트래픽 적음 | 유저 대전 |
| 영상 저장 | 녹화 재생을 화면 캡처해 mp4로 인코딩하는 런타임 녹화 플러그인 + 기기 공유 창 연동 | 서버 없이 게임 밖 공유 | 영상 공유 |
| 로그인 | Google Play 게임즈, Game Center, Apple 로그인 | 스토어 정책 | 로그인 |
| 씬 생성 | 에디터 메뉴로 자동 생성 | 클라우드에서 에디터 실행 불가 | 개발 환경 |
| 화면 기준 | 세로 1080×1920, 안전 영역 (확정) | | 세로 화면 |
| 카메라 | 고정 쿼터뷰, 이동·핀치 확대, 회전 없음 (확정) | 모델을 한 각도 기준으로 최적화 가능 | 성능 |
| 세이브 | 클라우드(백엔드) 기본 + 기기 사본 (확정) | 고용·대전·뽑기로 서버 필수 | |
| 저장소 | 현재 `my-project-sample`, Git LFS | 큰 에셋 관리 | |
