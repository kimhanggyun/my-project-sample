## 3. 참고 서버 (`online = http`)

1. 터미널: `dotnet run --project server/Game.Server --urls http://0.0.0.0:5000 --Game:StoreRoot=server-data`
2. 에디터: `onlineUrl = http://localhost:5000`. 폰: PC의 와이파이 주소 (예: `http://192.168.0.10:5000`), PC 방화벽에서 5000 허용.
3. Player Settings ▸ Allow downloads over HTTP = *Allowed in development builds*.

## 5. 3D 전장 (1.6·1.7에서 함께)

- 병사(상자 또는 넣은 모델), 깃발, 선택 링, 이동 경로선·예약 지점, 스킬 사거리 원, 화살·불·스킬 파동, 맞을 때 깜빡임.
- 카메라: 끌기 이동, 두 손가락 확대·회전, 미니맵 누르기.
- 임시 아트를 넣었다면 ([art.md](art.md)): 병종별 병사 모델, 숲·산 소품. 크기·방향이 어색하면 `catalog.json`의 `height`·`yaw`.

## 6. 화면 캡처 (UI 확인용)

1. Game 뷰 해상도를 폰 세로로 둔다 (예: `1080x2400`, Game 뷰 위 해상도 목록 ▸ + 로 추가).
2. Play → 타이틀이 뜨면 메뉴 **Game ▸ Capture All Screens**.
3. 화면이 차례로 바뀌며 20장 정도를 `저장소/captures/날짜_시각/`에 PNG로 저장하고, 끝나면 그 폴더를 연다 (git에는 들어가지 않음).
   - 타이틀·로그인·약관, 메인 탭 6개, 스텝 정보, 장수, 모집, 도감, 내 녹화, 설정, 대결·대사, 전투(시작·3초 뒤), 결과.
   - 세이브는 바꾸지 않는다 (전투·결과는 사본으로).
4. 폴더의 PNG를 채팅에 올린다.
