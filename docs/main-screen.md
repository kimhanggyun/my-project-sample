# 메인 화면 기획

> 상태: 기획 중 (구현 전)
> 관련 문서: [planning-notes.md](planning-notes.md), [battle-design.md](battle-design.md), [architecture.md](architecture.md)

## 0. 앱 시작 흐름

```
① 스플래시 (회사·게임 로고)
② 버전 확인 / 점검 공지          ← 서버 필요, 지금은 자리만
③ 자동 로그인 시도
     안드로이드: 구글 플레이 게임즈 / 아이폰: Game Center
   └ 처음이거나 실패 → [게스트로 시작] / [구글로 로그인] / [Apple로 로그인]
④ 첫 실행이면 약관 동의 (이용약관, 개인정보 처리방침)
   + 광고 관련 동의: 아이폰은 추적 허용 요청(ATT), 해당 지역이면 광고 동의 화면
⑤ 타이틀 화면 ("터치하여 시작")
⑥ 메인 화면 (첫 번째 탭)
```

**로그인 규칙**
- **게스트로 시작 허용** (확정). 게스트 진행 상황은 그 기기에 묶인다.
- 설정에서 **계정 연동**(구글 / Apple)을 하면 기기를 바꿔도 이어서 할 수 있다. 안드로이드 ↔ 아이폰 이동도 같은 계정으로 연동하면 가능하다.
- 아이폰에서 구글 로그인을 제공하므로, 애플 정책에 따라 **Apple로 로그인**도 함께 제공한다.
- **카카오 등 국내 로그인은 출시 시점에는 넣지 않는다.** 대신 나중에 추가할 수 있게 로그인 수단을 끼워 넣는 구조로 만든다 (`IPlatformSignIn` 구현 추가 + 로그인 버튼 목록 데이터에 등록).
  - 주의: 아이폰에 카카오 로그인을 추가할 때도 Apple 로그인은 이미 있으므로 애플 정책 조건을 그대로 충족한다.

**서버가 없는 동안 (Step 1)**
- ②는 건너뛰고, ③은 **게스트(기기 저장)**로 바로 진행한다.
- 서버(Unity Gaming Services 등)를 붙이면 같은 자리에 실제 로그인이 들어간다. 다른 코드는 바꾸지 않는다.

## 1. 화면 구성

```
┌─────────────────────┐
│ 군량 12,000 [+]     ⚙ │  ← 상단 바: 군량(충전), 설정
├─────────────────────┤
│ ░░░░ 띠 배너 광고 ░░░░ │  ← 상단 바 바로 아래
│                     │
│    선택한 탭의 화면     │
│                     │
├─────────────────────┤
│ 스토리 장수 부대 편성  … │  ← 하단 탭 (추가 가능)
└─────────────────────┘
```

- **하단 탭**이 메인 메뉴다. 세로 화면에서 엄지로 누르기 쉽다.
- **설정**은 하단 탭이 아니라 **상단 톱니바퀴**에서 연다.
- 상단에는 **군량**을 표시한다. 군량이 있어야 출진할 수 있다.
- **군량 충전 방법**
  - **광고 보기 보상**: [+] 버튼 → 보상형 광고(동영상)를 끝까지 보면 군량 지급. 1회 지급량, 하루 최대 횟수, 재시청 대기시간은 설정값 (추후 결정).
  - 앱 결제 (상점, 추후).
- **띠 배너 광고**: 상단 바 바로 아래, **탭별 화면에서만** 노출. 전투 화면에서는 제거. 광고 제거 상품(영구 5,000원 / 한 달 1,000원)으로 없앨 수 있다. 자세한 규칙은 [ads.md](ads.md).
- 앱을 켜면 **탭 목록의 첫 번째 탭**이 열린다. 지금은 스토리가 첫 번째라 스토리가 열린다. 나중에 순서를 바꾸면 처음 열리는 탭도 바뀐다.

## 2. 탭 목록

| 순서 | 탭 | 상태 | 내용 |
|---|---|---|---|
| 1 | 스토리(단계) | **이번 범위** | 스텝을 차례로 진행. 스텝 선택 → 출진 → 전투 → 결과 |
| 2 | 장수 키우기 | **TO-BE** | 레벨업, 능력치 성장. 세부 항목(지략, 무력, 통솔 …)별로 나뉨. 각 항목 컨텐츠는 나중에 구성 |
| 3 | 부대 키우기 | **TO-BE** | 특정 컨텐츠로 진형 해금, 병종 승급 등 |
| 4 | 부대 편성 | **이번 범위** | 보유 장수로 군단 구성, 상황별(야전·공성·공격·수비) 편성 저장 |
| - | 설정 (상단) | **이번 범위** | 사운드, 배속 기본값 등 |

- TO-BE 탭은 하단에 자리를 두고, 누르면 **"준비 중" 화면**을 보여준다 (확정). 숨김으로 바꾸려면 데이터 값만 바꾼다.
- 나중에 상점, 도감 등이 추가될 수 있다. 탭이 5개를 넘으면 "더보기" 탭으로 묶는다.

## 3. 이번 범위에서 장수·부대 능력치를 정하는 방법

장수 키우기·부대 키우기는 TO-BE이므로, 장수·부대 능력치는 **초기 지급값 + 전투 결과(경험치·레벨업)**로만 바뀐다. 출전 구성은 **부대 편성 탭**에서 정한다 (스텝 데이터는 적군만 정함).

- 아군 출전 장수·부대는 **부대 편성**에서 가져온다. 스텝 JSON에는 적군, 맵, 출전 가능한 군단 수 등만 넣는다.
- 장수·부대의 능력치는 스텝 JSON 값과 전투 결과(경험치·레벨업)로 바뀐다.
- 나중에 키우기 탭이 생기면, 그 탭이 같은 데이터(장수 능력치, 부대 병종·진형)를 바꾸는 방식으로 붙는다. 전투 쪽은 수정하지 않는다.

## 3.1 초기 지급 (새 게임)

새 게임을 시작하면 바로 출전할 수 있도록 기본 장수와 부대를 지급한다.

| 항목 | 내용 |
|---|---|
| 장수 | **3명** (기본 군단 수 3과 맞춤) |
| 능력치 | **중간 정도** (1~100 기준 약 50 전후). 세 장수의 합계는 비슷하게, 성격은 다르게 (예: 통솔형 / 무력형 / 지략형) |
| 레벨 | 1 |
| 군단 | 장수마다 군단 1개. 소부대 6개 병종 기본 구성 (예: 보병·창병·궁병 혼합) |
| 진형·스킬 | 기본 진형 1~2종, 기본 스킬 0~1개 (배운 상태로 지급) |
| 군량 | 시작 군량 (첫 전투 몇 번 분량) |
| 편성 | 기본 편성 1개가 미리 채워져 있음 |

- 장수 이름·능력치·병종 구성은 **데이터(`startingKit.json`)**로 정의한다. 지금은 임시 값으로 넣고 나중에 교체한다.
- 키우기 탭이 생기기 전까지 새 진형·스킬은 **스토리 보상**으로 얻게 할 수 있다 (스텝 데이터에 보상으로 지정).

## 3.2 부대 편성 탭

- 보유 장수를 군단 슬롯(기본 3개)에 배치한다.
- 군단마다 소부대 6개(선봉·중앙·좌익·우익·좌비·우비)의 병종을 고르고, 배운 진형 중 하나를 고른다.
- **상황별 편성 저장**: 야전·공성·공격·수비 편성을 따로 저장해 둔다. 출진 시 스텝의 전장 유형에 맞는 편성이 자동 선택된다.
- 포로가 된 장수는 편성에서 빠지고 "포로" 표시가 붙는다.

## 4. 스토리 탭 흐름

```
스토리 탭 → 스텝 목록 → 스텝 선택 → (대사) → 출진 준비(편성 확인·군량) → 전투 → 결과 → (포로 처리) → (대사) → 저장 → 다음 스텝 해금
```

- 스텝은 차례로 해금된다.
- 아군 장수가 포로가 되면 스텝 목록에 **구출 전투**가 따로 표시된다 (수용소 이름 표기). 이기면 장수가 돌아온다.
- 적 장수를 잡으면 결과 화면 다음에 **포로 처리(등용·해방)** 화면이 나온다.
- 대사는 임시 텍스트로 넣고 나중에 교체한다.
- 출진 직전에 **"출진 준비"** 단계가 있다: 스텝의 전장 유형에 맞는 편성이 자동으로 선택되고(그 자리에서 변경 가능), 가져갈 군량을 조정한다.

## 5. 확장 구조

- 탭 목록, 순서, 상태(사용 / TO-BE / 숨김), 해금 조건은 **데이터(`mainTabs.json`)**로 정의한다.
- 탭 하나 = 화면 모듈 하나 (`IMainTab` 구현). 새 탭은 모듈을 만들고 데이터에 등록하면 된다.
- 키울 게 생겼을 때 탭에 **알림 표시(빨간 점)**를 띄우는 기능을 공통으로 둔다.
- 장수 키우기의 세부 항목도 데이터(`growthTracks.json`)로 정의할 예정 (TO-BE).

```json
[
  { "id": "story",     "name": "스토리",     "status": "active" },
  { "id": "general",   "name": "장수 키우기", "status": "tobe" },
  { "id": "troop",     "name": "부대 키우기", "status": "tobe" },
  { "id": "formation", "name": "부대 편성",  "status": "active" }
]
```
