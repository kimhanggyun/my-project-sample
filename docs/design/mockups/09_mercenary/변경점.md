# 09 용병 (예전 고용 탭) — 확정 시안 (2026-11-14)

> **확정 · 구현 1단계 (2026-11-15)**: 규칙 R-98 닉네임 장수 (#167) · R-99 배신 (#168) + 화면 (탭 이름 용병, 용병 고용(등록자마다 카드 · 장수+부대 / 장수만 / 부대만 · [고용 ›] = 다음 출진에 담기) · 내 용병 등록(닉네임 장수 · 내가 이끄는 부대 · 깃발에 나가 있으면 불가 · 해제), 공성전 출진에 담은 고용 · 반간 낌새 줄). 아직: 상세 아래 판 · 이력 막대 · 거르기 정렬 · 전장 배신 알림 연출 · 결과의 환불 줄 · 서버 쪽 "깃발에 나간 장수 등록 불가" 검사 · 부대 등록 제한(규칙). 사용자·데스크탑 합의 (v1 → v2 빌리는 단위 이름 · 배신 → **v3 확정**: 배신은 숨김, 반간이 있을 때만 낌새, 첫 교전 뒤 배신). 화면·문구·규칙 모두 데스크탑 ([collab.md](../../../collab.md) 2.2). 정책: [hiring-v2.md](../../content/hiring-v2.md).

## 역할

**플레이어 자신(닉네임 장수)이 용병으로 나가고, 다른 유저의 닉네임 장수·부대를 빌리는 곳.** 정의 장수(관우 등)는 여러 유저가 같이 가지므로 등록하지 않는다. 탭 이름 **고용 → 용병**.

## 꼭 필요한 것 → 시안에서

| # | 필요한 것 | 시안 |
|---|---|---|
| 1 | 빌리기 / 빌려주기 | 위 세그먼트 탭 **용병 고용 · 내 용병 등록** + 주홍 ⓘ |
| 2 | 원하는 용병 찾기 | 빌리는 단위 **[장수+부대] [장수만] [부대만]** + [정렬: 승률 ▾] [병종 ▾], "오늘 고용 3/10 · 고용한 병사도 내 군량을 먹습니다", 새로고침 |
| 3 | 한눈에 판단 | 카드 = 유저 한 명: 닉네임 장수 초상 · 이름 · 계급 · Lv, 능력치·스킬·진형, **이력 한 줄**(고용 · 승률 · 생존율 · 포로/퇴각), 등록 병종(그림 · 인원 · 훈련 · 결속), 가격 줄, [고용 ›]. 장수만 등록 = 짧은 카드. 대기 중 = 흐림 + "다시 고용까지 12분" |
| 4 | 자세히 + 고용 | **아래에서 올라오는 판**: 능력치 4칸, 스킬·특성·진형, 부대, 이력 막대(승·패·퇴각·포로) + 최근 전투 3 (재생 ›), 고용하기 = 단위 고르기 · 넣을 곳(편성 · 군단 자리 ▾) · 병력 [−][n][+][최대] (최대 = 내 군량 · 장수 통솔 중 작은 쪽) · 비용 상자 · [닫기] [고용하기 — 편성에 (고용)]. **배신 경고는 없다** |
| 5 | 내 용병 등록 | 닉네임 장수 카드 ("등록 중"), 등록할 부대 = 내가 직접 이끄는 부대 (기본 편성 제1군), 등록 뒤 바뀐 점, 번 보상 (우편으로). 가격: 장수 1회 · 병사 1명 [−][n][+] + 자원 ▾ (돈/군량) + 추천 · 최대. [✓ 부대도 등록], [해제] [지금 모습으로 다시 등록], 최근 고용 (누가 · 어디서 · 결과 · 보상 · 재생) |
| 6 | 못 나갈 때 | 영토 깃발에 나가 있음 → 빨간 "등록 불가" + "⚠ 영토 제1 깃발에 나가 있어 … 깃발을 거두면 등록" [영토 ›], 가격·버튼 꺼짐 |
| 7 | 배신 낌새 (숨김) | 출진 직전, **내 닉네임 장수에게 반간**이 있고 용병 주인의 깃발을 칠 때만 확인 창: "수상한 용병이 있습니다" + 낌새 문구, [용병 빼고 출진] [그대로 출진] [취소] |
| 8 | 배신 순간 | 전장: 우리 편 **첫 교전 직후** 위 빨간 알림 "⚠ 용병 ○○이 배신했습니다!", 용병 장수 말풍선, 용병 부대 붉은 고리 + "(배신 · 적 편)", 아래 안내 "고용비는 결과 화면에서 돌려받습니다 · 이제 적 AI가 지휘" |

## 규칙 쪽 할 일 (데스크탑) — [hiring-v2.md](../../content/hiring-v2.md)

1. 닉네임 장수: 닉네임 정할 때 생김, 일반 장수와 같은 성장, 장수 탭 맨 앞.
2. 등록: 닉네임 장수 + 그가 직접 이끄는 부대만. 영토 깃발에 나가 있으면 불가.
3. 빌리기: 장수+부대 / 장수만 / 부대만(병종 하나 골라 인원, 내 군단 빈 칸).
4. 배신: 용병 주인 본인의 깃발 공성전 → 첫 교전 직후 적 편, 고용비 돌려받음, 반간(내 닉네임 장수)이면 출진 전 낌새 창. verification 새 규칙.
5. 탭 이름·문구 `ui.hire.*` → 용병.
