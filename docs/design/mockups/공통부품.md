# 공통 부품 목록 (시안에서 반복되는 것)

> 화면별 시안에서 되풀이되는 모양을 `Unity/Scripts/UI/Ui.cs`의 공통 함수로 한 번 만들어 두고, 화면은 그것을 놓기만 한다. 모양을 바꿀 때는 여기 한 곳만 고친다.
> 색은 지금처럼 `Palette`(화면 스타일 데이터 `UiStyle`)에서. 확정 화면이 늘 때마다 이 목록을 보탠다.
> 처음 정리: 2026-11-14, 01 타이틀·02 로그인·03 약관 기준.

| 부품 | 모양 | 상태 | 쓰는 곳 | 지금 코드 |
|---|---|---|---|---|
| **주요 버튼** `Ui.PrimaryButton` | 주홍 `Palette.ButtonActive` (#C95640), 먹 테두리 4px, 밝은 글자, 높이 140~160 | 켜짐 = 주홍 / 꺼짐 = 회색 #C6BEAF·글자 #8C8478 / 처리 중 = 글자 "…중" + 도는 표시, 누름 막음 | 타이틀 [시작], 약관 [동의하고 시작] | `Ui.Button(..., Palette.ButtonActive)` 화면마다 따로 |
| **보조 버튼** `Ui.SecondaryButton` | 한지색 `Palette.Button` (#E2D6B9), 먹 테두리 3px, 먹 글자 | 켜짐 / 꺼짐(흐리게) | 로그인 [게스트로 시작], 약관 본문 [닫기] | `Ui.Button` 기본 |
| **꺼진 버튼** | 회색 바탕, 흐린 글자. 꺼진 이유는 버튼 위/아래 안내 문구로 | — | 위 둘의 꺼짐 상태 | `Ui.SetEnabled(false)` |
| **브랜드 버튼** | 구글 = 흰 바탕·회색 테두리·G 로고 / Apple = 검은 바탕·흰 사과·흰 글자. **공식 버튼 그림** 사용 | 켜짐 / 꺼짐(흐리게) / 처리 중 | 로그인 | 없음 |
| **체크 상자 줄** `Ui.CheckRow` | 상자(48~60px, 둥근 8) + 글자 + 오른쪽 작은 링크(선택). 켜짐 = 주홍 바탕·흰 체크, 꺼짐 = 한지 바탕·먹 테두리. 줄 전체가 누르는 칸 | 켜짐 / 꺼짐 | 약관 (전체 동의는 큰 상자·굵은 글자) | 버튼 글자 "■ □" |
| **실패 문구** | 빨간 `Palette.Bad` (#B03A2E), 작은 글자 한 줄, 관련 버튼 **바로 위** | 평소엔 비움 | 로그인 실패, 약관 다시 동의 | 화면마다 `Ui.Label(…, Palette.Bad)` |
| **안내 문구** | 작은 회색 `Palette.TextDim` (#706858), 가운데. 관련 버튼 바로 위/아래 | — | 연결 중, 진행 조건, 게스트 설명 | `Ui.Label(…, Palette.TextDim)` |
| **첫 화면 머리** `Ui.TitleHeader` | 위 대표 그림 자리(높이 700, `Resources/Ui/title_art.png`, 없으면 비움) + 붓 획 제목(y 720~950). 한자 낙관 없음 | 버튼이 많으면 그림 높이를 줄임 | 타이틀, 로그인 | 타이틀 화면 안에만 |
| **링크 글자** | "보기 ›" — 작은 회색 + "›", 오른쪽 정렬. 누르는 칸은 줄 높이 | — | 약관, 스토리 "다시 하기 ›" | 없음 (버튼으로 대신) |
| **자원 칩** `Ui.ResourceChip` | 둥근 칩(높이 66): 아이콘 52 + 숫자 + 작은 주홍 원 [+] 44 | — | 메인 자원 바 | 아이콘·숫자·큰 [+] 따로 |
| **아이콘 버튼** `Ui.IconButton` | 80×74 보조 버튼 안에 아이콘 (가방=상점, 톱니=설정) | — | 메인 자원 바 | 글자 버튼 |
| **띠 배너 자리** | 자원 바 아래 높이 100, 광고 없으면 0 | 광고 있음/없음 | 메인 틀 (탭 화면만) | 없음 |
| **강조 카드** `Ui.FeatureCard` | 카드 바탕 + 색 테두리 5px + 왼쪽 위 색 꼬리표(예: "다음 도전") + 큰 제목 + 요약 + 주요 버튼 | 주홍 = 다음 도전 / 빨강 = 구출(기한) | 스토리 | 없음 |
| **목록 줄** `Ui.ListRow` | 높이 84~90: 왼쪽 상태 기호(✓ 초록 / 자물쇠 회색) + 이름 + 오른쪽 링크·작은 안내 | 보통 / 흐림(잠김) | 스토리 | 큰 버튼 한 줄 |
| **구역 머리말** | 굵은 회색 28px ("깬 스텝", "다음 스텝") | — | 스토리 | 없음 |
