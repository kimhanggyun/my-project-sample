# 03 약관 동의 화면 — 확정 시안 (2026-11-14)

> 사용자·데스크탑 합의. 구현: 원격 (`Screens/StartupScreens.cs` `TermsScreen`).
> 그림: [current.jpg](current.jpg) → [mock_default.jpg](mock_default.jpg) (체크 전), [mock_checked.jpg](mock_checked.jpg) (모두 체크), [mock_view.jpg](mock_view.jpg) (본문 보기), [mock_reagree.jpg](mock_reagree.jpg) (다시 동의). 1080×1920 기준.

## 역할

로그인 다음, **처음 실행 또는 약관 판(`termsVersion`)이 바뀌었을 때만** 나온다. 필수 약관에 동의해야 타이틀로 넘어간다 (건너뛸 수 없음).

## 꼭 필요한 것 → 시안에서

| # | 필요한 것 | 시안 |
|---|---|---|
| 1 | 항목별 동의 (이용약관·개인정보, 둘 다 필수) | 체크 상자 줄 |
| 2 | 전체 동의 | 목록 맨 위 "전체 동의" 줄 |
| 3 | 긴 본문 보기 | "보기 ›" → 전체 화면 본문 + [닫기] |
| 4 | 진행 조건이 보이게 | 다 체크 전: 안내 문구 + 꺼진 버튼 / 다 체크: 주홍 버튼 |
| 5 | 판이 바뀌어 다시 묻는 경우 | 제목 아래 빨간 한 줄 |
| 6 | 나중의 선택 항목 자리 | 목록 아래 빈 공간 |

## 합의한 것

1. **"전체 동의"는 목록 맨 위 체크 줄** (크게·굵게). 누르면 전부 체크/해제. 아래 [모두 동의] 버튼은 **없앤다**.
2. **본문은 전체 화면**: "보기 ›" → 제목 + 본문 상자(스크롤) + [닫기]. 카드 안 펼치기는 없앤다.
3. **다시 동의 안내 넣음**: 판이 바뀐 경우 제목 아래 "약관이 바뀌었습니다. 다시 확인해 주세요."
4. 체크 상자는 **진짜 체크 상자 모양** (지금은 버튼 글자에 "■ □"). 켜짐 = 주홍 바탕 + 흰 체크, 꺼짐 = 한지 바탕 + 먹 테두리.
5. 아래 버튼은 [동의하고 시작] 하나 — 꺼짐(회색) / 켜짐(주홍).

## 구현 메모 (원격)

- `Item()`의 "■/□ + 버튼" → 공통 체크 상자 줄 ([공통 부품](../공통부품.md) `Ui.CheckRow`).
- [모두 동의] 버튼 삭제, 대신 "전체 동의" 줄. 항목이 하나라도 풀리면 전체 동의도 풀린다.
- `_open` 펼치기 대신 본문 화면(`TermsBodyScreen` 같은 것)으로 이동, [닫기] → 체크 상태를 유지한 채 돌아옴.
- 다시 동의 여부: 저장된 동의 판이 있고 지금 `termsVersion`보다 낮으면 안내 줄.
- 문구 키: 새 `ui.terms.changed` ("약관이 바뀌었습니다. 다시 확인해 주세요."), `ui.terms.needAll` ("필수 항목에 모두 동의해야 시작할 수 있습니다."), 본문 화면 제목용 `ui.terms.name.terms`("이용약관")·`ui.terms.name.privacy`("개인정보 처리방침"), `ui.common.close`가 없으면 ("닫기"). 안 쓰게 됨: `ui.terms.all`, `ui.terms.hide`.
