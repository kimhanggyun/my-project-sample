## 역할

**계정 · 기기 · 알림 · 도움**을 한곳에서. 출시에 꼭 필요한 것(계정 삭제 — 구글 · 애플 정책, iOS 구매 복원, 약관 · 개인정보처리방침 · 위치정보 약관 링크)을 넣고, 개발용은 일반 유저에게 숨긴다.

## 결정 (사용자)

- **개발용(서버 · 화면 스타일 · 세이브 위치 · 초기화)은 개발 빌드 · 마스터 계정만** 보인다 (맨 아래 점선 구역).
- **소리: 배경음 · 효과음 따로** (막대 + 아이콘 누르면 음소거).
- **한 페이지 + 구역 머리** (아이콘 줄 목록).

| 도움 | 처음 안내 다시 보기 · 문의하기 (계정 번호가 같이 감) · 이용약관 · 개인정보처리방침 · 위치정보 이용약관 · 버전 |

## 규칙 쪽 할 일 (데스크탑)

1. **계정 삭제**: 서버 삭제 요청 → 7일 유예 (그 안에 로그인하면 취소) → 영구 삭제. 서버 API · verification 새 규칙. 스토어 정책 (계정을 만들 수 있는 앱은 앱 안 삭제 필수).
2. **구매 복원**: 결제 서비스 인터페이스에 복원 (iOS 필수, Android는 자동 — 버튼은 같이).
3. **알림 설정**: 종류별 켜기/끄기 (기기 저장 + 서버에 보냄, 푸시 서비스 뒤).
4. **소리**: 배경음 · 효과음 값 (기기 설정).
5. 개발용 구역 = 개발 빌드(`Debug.isDebugBuild`) 또는 마스터 계정일 때만.
6. 약관 링크 = 설정 데이터의 주소 (startup.md 약관과 같은 곳).
