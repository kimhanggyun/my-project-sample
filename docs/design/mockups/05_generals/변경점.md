# 05 장수 탭 — 확정 시안 (2026-11-14)

> 사용자·데스크탑 합의. 구현: 원격 (`Screens/MainScreen.cs` `GeneralsTabView`).
> 그림: [current.jpg](current.jpg) → [mock_default.jpg](mock_default.jpg) (기본), [mock_tip.jpg](mock_tip.jpg) (카드 ⓘ를 누른 상태). 1080×1920 기준. 위 자원 바·띠 배너·아래 탭은 [04](../04_main_story/변경점.md) 틀.
> 시안의 **장수 D~F는 등급·상태를 보이려고 넣은 예시** (실제 데이터 아님).

## 역할

가진 장수를 훑어보고 한 명을 골라 장수 화면(11)으로 들어가는 목록. 장수 모집(뽑기) 입구. 장수는 모집·등용으로 계속 는다 (마스터 "모든 장수 받기"면 수십 명).

## 꼭 필요한 것 → 시안에서

| # | 필요한 것 | 시안 |
|---|---|---|
| 1 | 누군지 한눈에 (초상·이름·등급·레벨) | 카드 위 초상 자리 + 이름 + Lv |
| 2 | 상태 (출전 가능/경상/중상/포로) | 출전 가능 = 표시 없음. 나머지 = 초상 아래 색 띠 + 카드 흐리게 |
| 3 | 능력치 | 아이콘 + 숫자 3개 + **카드 ⓘ → 이름 붙은 말풍선** |
| 4 | 많을 때 정렬 | 머리 줄 [정렬: 등급 ▾] |
| 5 | 할 일 | 배울 스킬북 등 → 카드 오른쪽 위 빨간 점 |
| 6 | 모집 입구 | 머리 줄 작은 보조 버튼 [모집] |
| 7 | 탭 도움말 | 머리 줄 맨 오른쪽 주홍 ⓘ (다른 버튼을 가리지 않음) |

## 합의한 것

1. **두 줄 격자 카드**. 2. 모집은 **작은 보조 버튼**. 3. 등급은 **카드 테두리 색**(+ 왼쪽 위 등급 꼬리표). 4. **카드마다 작은 테두리 원 "i"** — 누르면 "통솔 60 / 무력 45 / 지력 45"(아이콘 + 이름 + 숫자) 말풍선. 아이콘만으로는 뜻을 모를 수 있어서.

## 구현 메모 (원격)

- 카드 전체 = 장수 화면으로. **작은 ⓘ는 따로 누르는 칸** (카드 누름이 같이 일어나지 않게).
- 말풍선은 [공통 부품](../공통부품.md) `Ui.StatTip` — 장수 화면(11)·포로·전투 정보 줄 등 능력치 아이콘이 있는 곳에서 같이 쓴다.
- 정렬: 등급(높은 순) → 레벨 → 이름. 고르는 칸은 등급·레벨·출전 가능 먼저. 고른 값은 기기 설정에 기억.
- 할 일 점 조건: 그 장수가 지금 배울 수 있는 스킬북이 있거나 한계 돌파 가능 (규칙 쪽 조건은 원격 판단).
- 문구 키 (새): `ui.generals.count` ("{0}명"), `ui.generals.sort` ("정렬: {0}"), `ui.generals.sort.grade`/`level`/`ready`, `ui.generals.recruitShort` ("모집"). 능력치 이름은 있는 `stat.*` 또는 `ui.generals.stats`의 이름.
- `ui.tab.generalNote`(지금 ⓘ 설명)은 그대로 머리 줄 ⓘ.
