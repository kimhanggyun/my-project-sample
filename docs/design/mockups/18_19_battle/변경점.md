## 결정 (사용자, 2026-11-14~15 논의)

| 주제 | 결정 |
|---|---|
| 부대 게이지 | **바닥 링** (바깥 병력 · 가운데 사기 · 안쪽 책략). 고른 군단만 굵게 + **병력 칩**, 다른 군단은 얇은 병력 링, 병력이 적으면 빨강 |
| 많이 축소했을 때 | 링 대신 깃발 옆 작은 병력 막대 |
| 명령 조작 | 부대 위 원형 메뉴 **없앰** → **군단 카드 바로 위 명령 줄** (손이 닿기 쉽고 전장을 안 가림, 자리가 늘 같음). 군단을 골랐을 때만 나타남 |
| 명령 줄 | 고른 군단에 맞는 것만 (여러 군단이면 **함께 할 수 있는 것만**), 가로 스크롤, 하위는 **줄이 그 자리에서 하위 줄로 바뀜** ([‹] 뒤로), 대상 고르는 중엔 안내 + [취소] |
| 위임 · 예약 | 명령 줄 오른쪽 끝 **고정 작은 스위치** |
| 여러 군단 고르기 | 군단 카드를 **누를 때마다 켜고 끄기** (✓ + 빨간 테두리, 길게 누르기 없음) |
| 자주 쓰는 명령 순서 | **나중에** (명령 줄 순서 편집) |
| 아래 패널 | 명령 버튼 14개 없앰 → [전군 진군] (작전 시간엔 [전투 시작]) + **작은 군단 카드** |
| 군단 카드 | 초상 · 번호(★ 대장) · 상태 아이콘 · **병력 게이지 + 지금/처음 숫자 + 잃은 비율(−%)** · 사기 막대. 위험하면 빨간 테두리 |
| 병력 표시 | 숫자만으론 얼마나 잃었는지 몰라서 **게이지 함께**: 막대 전체 = 처음 병력, 초록 = 남은 병력, 옅은 빨강 = 잃은 병력 |
| 위 막대 | **아이콘 한 줄**: 시계 고리 n/10 · 군량 아이콘 + 막대 · 바람 화살표 · 날씨 · [▶/⏸] [×1] [지도] [⏭]. 전투명은 시작 때만 |
| 전투 시작 | **승패 조건 카드** → [작전 시작] → **멈춘 채 작전 시간** → [전투 시작] |

## 명령 구성 (명령 줄)

| 명령 | 하위 | 쓰는 법 |
|---|---|---|
| **공격 ›** | 공격 · 돌격 (빨리 부딪힘, 사기·피로) · 사격만 (거리 유지) · **유인** (건드리고 정한 지점까지 끌고 옴) | 고르고 → 상대를 누름. **여러 군단이면 자동 일제 공격** (서로 기다렸다 동시에, 협공 대기 규칙) |
| **이동 ›** | 이동 · 강행 (교전 무시, 빨리, 피로) · **은밀** (느리지만 안개 속에서 덜 들킴) · **집결** (고른 군단이 한 지점에 모임) | 고르고 → **경로를 그림** (끝이 적 · 군량고면 그 길로 가서 공격 = 우회 습격) |
| **스킬 ›** | 그 장수의 스킬 (남은 횟수 점) | 고르고 → 대상 · 지점 |
| **진형 ›** | 방진 · 장사 · 어린 · 학익 … | 누르면 바로 |
| **대기 ›** | 그냥 대기 · 휴식 · 협공 대기 · **지키기** (지점 범위 안 적만 치고 제자리) · **엄호** (아군 군단을 따라다니며 지킴) | 지키기 = 지점, 엄호 = 아군 군단 |
| **후퇴 ›** | 후퇴 · 퇴각(이탈, 확인 한 번) | |

- **지름길** (명령 줄 없이): 부대를 고르고 땅을 누르면 이동, 적을 누르면 공격, 부대에서 끌면 경로.
- 영토 공성전 표시(상대 직접 지휘 · 지원군 도착 · 배신)는 위 막대 꼬리표와 알림 띠로 (08 · 09 시안의 알림을 그대로).

## 규칙 쪽 할 일 (데스크탑) — battle.md 4장 · verification

1. **작전 시간**: 전투 시작 시 일시정지 상태로 시작, 명령 · 예약 가능 (지금 "정지 중 명령" 규칙 그대로), [전투 시작]으로 진행.
2. **새 명령**: 돌격 · 사격만 · 유인 · 강행 · 은밀 · 집결 · 지키기 · 엄호 — 명령 데이터 · AI 동작 · 재현 (verification 새 규칙). 은밀 = 이동 느림 + 안개 속 발견 범위 감소 (수치 데이터).
3. **경로 그리기**: 경유점 목록 명령 (지금 예약 · 경유 명령을 확장), 끝이 적 · 시설이면 도착 후 공격.
4. **여러 군단 공격 = 일제 공격**: 협공 대기와 같은 동기화 (가장 늦게 닿는 군단에 맞춤).
5. 바닥 링 · 병력 칩 · 카드 게이지 = 처음 병력(전투 시작 때) 대비.
6. 축소 단계 기준 (링 → 깃발 막대) 데이터.
