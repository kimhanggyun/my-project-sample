## 역할

전투 직후 **어떻게 됐고 무엇을 얻고 잃었나**를 한눈에, 그리고 **다음 행동**(포로 처리 · 다시 도전 · 영토 · 녹화)으로 넘긴다.

## 결정 (사용자)

- **큰 도장 찍기**: 승리 = 주홍 낙관, 패배 = 먹 도장. 크게 찍힌 뒤 위로 작아지며 내용이 나온다.
- **졌을 때 한 줄 팁 + 바로가기** (규칙이 고름: 병력 차 · 상성 · 군량 … → [충원 ›] [편성 ›] [공략 보기 ›]).
- **성장은 게이지로** (v2, 사용자 요청): 장수 경험치 · 병종 훈련도 · 결속 · 진형 숙련 · 일기토/논쟁 진행 · (경험치 정책 뒤) 계정 계급 — 원래 양(진한 색) + 이번에 얻은 양(밝은 색, 차오르는 움직임 + "+n") / 줄어든 양(빨간 빗금 + "−n") / 꽉 차면 금 테두리 반짝 + [Lv UP] · [결속 UP] (줄면 [결속 DOWN]). 바뀐 것만 많이 오른 순서로, 나머지는 "외 n개 ›".
- **요약 + 구역 접기** (잃은 것 · 자란 것 · 얻은 것 · 포로 한 줄 요약, 누르면 펼침. 새로 생긴 것 — Lv UP · 숨은 보상 — 이 있는 구역은 늘 펼침).

| 2 | 영토 결과 | 공성전 승리: **깃발 교체** (상대 깃발 ✕ → 내 깃발) + [+수입 / 일] [반지름] / 패배: "30분 뒤 다시" |
| 3 | 잃은 것 | 접힘: 전사 · 부상 · 적 격파 / 펼침: 병종 그림 + **손실 막대** (살아남음 초록 · 부상 주황 · 전사 빨강) + 숫자, "부상은 시간이 지나면 돌아옵니다 ⓘ" |
| 4 | 자란 것 | **성장 게이지** 줄 (아이콘 56 · 이름 · 막대 600×20 · +n / −n · 꼬리표): 장수 경험치 [Lv UP] · 병종 훈련도 · 결속 [결속 UP/DOWN] · 이번 진형 숙련 · 일기토/논쟁 다음 보상까지 · "외 n개 ›". 단계가 오른 게 있으면 구역 금 테두리 |
| 5 | 얻은 것 | 군량 (돌아옴 · 포획), 첫 클리어 보상, **숨은 보상 발견!** 카드 [NEW] → [도감 ›] (주홍 테두리) |
| 6 | 포로 | "○○를 잡았다 → 다음에 등용 · 해방" (계속을 누르면 포로 처리 화면) |
| 7 | 배신 | 용병이 배신했으면 보라 줄 "고용비 … 돌려받음" |
| 8 | 졌을 때 | **팁 카드** (노랑 · ! 아이콘): 한 줄 이유 + 바로가기 2~3개 |
| 9 | 다음 | 아래 고정: [▶ 녹화 ⋯] ("최근에 남음", 저장 · 공유) · 주요 [계속 ›] ("다음: 포로 처리 → 영토") / 패배: [스토리로 · 영토로] + 주요 [다시 도전] |
