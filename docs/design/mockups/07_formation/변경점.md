# 07 부대 편성 — 확정 시안 (2026-11-14)

> **구현 (desktop/formation-07, R-95)**. 사용자·데스크탑 합의. 화면·문구·규칙 모두 데스크탑 ([collab.md](../../../collab.md) 2.2). 정책: [army-v2.md](../../content/army-v2.md) (병종 묶음 · 계급 · 진형 칸 자동 배치).
> 그림 (1080×1920): [current.jpg](current.jpg) (임시판, 예전 세이브) → [mock_main.jpg](mock_main.jpg) (편성) · [mock_tip.jpg](mock_tip.jpg) (계급 ⓘ, 2판 그림 — 3판의 [복사]·[최대]·군량은 main 기준) · [mock_board.jpg](mock_board.jpg) (군단 편성) · [mock_formpick.jpg](mock_formpick.jpg) (진형 고르기) · [mock_leave.jpg](mock_leave.jpg) (저장 확인).
> 예시 상태: 천부장 Lv.6 (출진 군단 2 · 군단당 병종 칸 2 · 병종 최대 8,000). 숫자·장수 D~F는 예시.

## 역할

출진 전에 **누가(장수) 무엇을(병종·인원) 어떤 모양(군단 진형)으로, 군단끼리 어디에(전군 배치)** 데리고 나갈지 정한다. 계급이 오르면 군단·칸이 늘어나는 보람이 보여야 한다. 두 페이지로 나눈다: **편성**(군단 안) / **군단 편성**(군단끼리 자리·장수).

## 꼭 필요한 것 → 시안에서

| # | 필요한 것 | 시안 |
|---|---|---|
| 1 | 내 전체 병력이 얼마나 남았나 (다른 군단 편성 참고) | 위 고정 **보유 병력 줄**: 병종 미니 카드(그림·이름·남은/보유), 좌우 스크롤. 다 쓰면 흐림, 넘치면 빨강 |
| 2 | 계급과 열린 군단·칸, 다음 계급 | 위 고정 **계급 띠** + 작은 ⓘ → 말풍선 (지금 계급 내용 + 다음 계급에서 늘어나는 것) |
| 3 | 군단마다 장수·진형·병종·인원 | **접는 군단 카드** (기본 펼침 ▾ / 접으면 한 줄 ▸): 장수, [진형 ▾], 진형 미리보기, 병종 칸 줄, 군단 병력 게이지(합/통솔 한도), 하루 군량 |
| 4 | 병력이 진형 칸 6개에 어떻게 서나 | **진형 미리보기** (병종 색 + 칸 인원). 누르면 **진형 고르기**(진형마다 미리보기·특성 ⓘ, 배운 것/잠김) |
| 5 | 인원 조절 | 병종 칸: [−] 인원 [+] **[최대]**(남은 인원·통솔 한도 중 작은 쪽) [빼기]. 길게 누르면 빨리, 숫자 누르면 직접 입력 |
| 6 | 다음 칸·군단 | 열린 칸 다음에 잠긴 칸 하나 ("3번째 칸 — 교위(Lv.10)가 되면"), 잠긴 군단 줄 ("제3군 — 장군(Lv.15)이 되면 열림") |
| 7 | 군단끼리 자리·총대장 | [군단 편성 ›] → 새 페이지: 위 **장수 미니 카드 줄**(놓인 장수는 흐림 + "제n군", 상태 띠), **3×3 포진판**에 끌어 놓기. 앞줄 = 선봉, 가운데 = 측면, 뒷줄 = 후위. 장수를 누르면 ★ 총대장, 판 밖으로 끌면 빼기. 계급 군단 수가 차면 빨간 칸 + 안내 |
| 8 | 상황별 편성 | 위 세그먼트 탭 (기본·야전·성새전·수상전) + **[복사 ▾]** (이 편성을 다른 상황으로) |
| 9 | 빠르게 | 아래 **[자동 편성]** (남은 병력을 열린 군단·칸에 고르게), 병력 카드를 누르면 펼친 군단에 그 병종 칸 넣기 |
| 10 | 저장 | 아래 고정 [되돌리기] [저장]. 저장 안 되면 한 줄 + 문제 군단 빨간 테두리. 저장 안 하고 나가면 **확인 창** (바뀐 것 한 줄, [저장하고 나가기] [저장 안 하고 나가기] [취소]) |
| 11 | 장수 상태 | 경상 노랑 / 중상 주황 / 포로 빨강 띠 (05와 같은 상태 띠), 포로·중상은 출진 불가 경고 |

## 규칙 쪽 할 일 (데스크탑) — 했음 (R-95: BoardRow·BoardCol·Commander, CorpsSetup.SlotRow·SlotCol, Army.AutoFill, FormationEditor.CopyTo)

구현 메모: 군단 편성의 장수 줄은 끌기와 가로 스크롤이 부딪혀 **여러 줄로 감싼 격자**(6개씩)로 했다. 병종 칸 넣기([+ 병종 칸])는 아직 예전 고르기 화면(UnitPickerScreen)을 쓴다 — 미니 카드 누르기(빠른 넣기)가 주 경로.

1. **전군 배치 (3×3 포진판)**: 편성에 군단 자리(줄·칸) + 총대장 저장. 출진 때 자리 → 전투 시작 위치 오프셋(맵 진영 기준) + 진군 역할(앞 선봉 · 가운데 측면 · 뒤 후위). 총대장 = ★ 군단 (지금은 첫 군단). verification 새 규칙, 기존 역할(Role)은 자리에서 계산.
2. **[자동 편성]**: 남은 병력을 열린 군단(통솔 한도 큰 장수부터)·칸에 고르게 — 규칙 함수로 (화면·서버 같은 결과).
3. **[복사]**: 상황별 편성 복사 (편집기 함수).
4. 진형 고르기의 특성 ⓘ: 진형 특성치(R-72) 문구.
