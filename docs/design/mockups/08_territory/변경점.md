## 역할

내 위치(GPS) 근처에 **장수를 보내 깃발을 꽂고**, 깃발 둘레 원을 내 땅으로 삼는 **땅따먹기**. 남의 원 안에 꽂으면 바로 **공성전**. 줌을 바꾸면 동네(깃발 하나하나) → 시·구(칸 대표) → 나라(연합 세력도)로 본다.

## 꼭 필요한 것 → 시안에서

| # | 필요한 것 | 시안 |
|---|---|---|
| 1 | 내 위치와 위치 동의 상태 | 위 **위치 띠**: "서울특별시 근처 · 내 칸 (위경도)" + "GPS 위치 동의함 · 정확도 · 깃발은 100m 칸 가운데에" + [위치 확인]. 동의 안 했으면 "위치 동의가 있어야 영토전 가능" + [동의하기] |
| 2 | 내 땅·남의 땅이 어디까지 | **영토 지도**: 깃발 둘레 **원** (반지름 = 계정 계급, 모든 장수 같음), 겹쳐도 됨. 색 = 내 주홍 · 우리 연합 초록 · 다른 유저 검붉음, 옅게 칠 |
| 3 | 누구 깃발인지 | **깃발**: 깃 색 = 주인, 깃 글자 = 계급(십·백·천·교·장·대), 깃대 아래 둥근 표 = 연합(청·백·주). 이름 꼬리표 (깃발 · 장수) |
| 4 | 어디에 꽂을 수 있나 | 내 위치 파란 점 + **점선 원 = 꽂을 수 있는 범위** (= 계급 반지름) |
| 5 | 줌마다 알맞은 양 | [내 위치] [+] [−] + 줌 이름 칩. **가까이**(~5km): 모든 깃발·원 / **중간**(~50km, 칸 5km): 칸마다 **대표 깃발 1개**(세력 = 병력 큰 순, 같으면 계급) + "+12" 나머지 수, 시·도 경계 / **멀리**: **세력도** — 칸 색 = 그 칸에서 가장 센 연합, 연합 이름·연합장. **내 깃발은 어느 줌에서도 늘 보임** |
| 6 | 주변에 누가 있나 | 탭 **주변 부대**: 맨 위 [지금 여기에 깃발 꽂기] 카드(빈 땅 · 반지름 · 깃발마다 하루 수입) → 주변 부대 가까운 순 카드 (주인 · 계급 · 연합 · 장수 · 병력 · 거리). 범위 안 = [공격 ›], 밖 = 흐림 "가까이 가면", 같은 깃발 다시 공격 대기 = "다음 공격까지 24분". 중간 줌 = 칸 대표 목록 [가까이 ›], 멀리 = 연합 세력 순위 |
| 7 | 내 깃발 관리 | 탭 **내 깃발**: 깃발 카드 (장수 · 꽂은 날 · 반지름 · 수비 병력 · 보호 시간 · 쌓인 수입 게이지) + [수입 받기] [병력 바꾸기] [깃발 거두기]. 겹친 내 깃발 = "↔ 제1 깃발과 겹침 — 전투 중 서로 지원 (전장 하루 뒤 도착)". 맨 아래 [+ 깃발 더 꽂기 — 남은 장수 n] |
| 8 | 공격하면 | **카운트 판** (가운데 창): "○○ 깃발 공성전 · 전투 준비 중 — 1분 뒤 시작", 원 게이지 0:42, "상대에게 알림 보냄 — 들어오면 유저 대전, 안 오면 AI 수비", [공격 취소] / 0:00이면 자동 시작. 지도 위 빨간 띠 + 공격 화살표 |
| 9 | 공격받으면 | 휴대폰 **알림** ("⚔ 제2 깃발이 공격받습니다! … 누르면 바로 전장으로") → 게임 안 **카운트 판** (빨간 테두리): 공격자·수비 병력, 0:42, [AI에게 맡기기] [전장 들어가기 ›]. 안 고르면 AI 수비 |
| 10 | 지원군 | 영토 화면에는 없다 — **전장에서** 지원 부대가 들어올 때 알림("지원군 도착: ○○"). 카운트 판에 한 줄 안내만 |
| 11 | 연합 | 탭 **연합**: 연합 정보 · 연합 열기 (지금 연합 화면 재사용) |

## 규칙 쪽 할 일 (데스크탑) — [territory-v2.md](../../content/territory-v2.md)

1. 깃발 원형 땅: 좌표 100m 칸 맞춤, 반지름 = 계급 (데이터), 꽂기 = 내 위치에서 반지름 안 · 빈 땅 · 남은 장수 1명 이상.
2. 공성전: 남의 원 안에 꽂기 = 공격 → 준비 1분 (수비자 알림) → 유저 대전(1단계: 수비자 명령·계략) / AI 수비. 이기면 상대 깃발 뽑고 내 깃발. 같은 깃발 다시 공격 대기.
3. 전장 지원: 겹친 내 깃발 = 전장 하루 뒤(데이터), 연합원 = 거리만큼 늦게. 전장에서 지원 부대 입장.
4. 줌 단계: 칸 대표(세력 · 계급), 세력도(칸마다 가장 센 연합).
5. 지도: Natural Earth (공공 영역) 한지풍 자체 그림. 동네 길(OSM)은 나중.
6. verification 새 규칙 (원형 땅 · 공성전 · 지원 지연 · 줌 대표) — 구현할 때.
