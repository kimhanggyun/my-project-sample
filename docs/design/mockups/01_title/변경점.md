# 01 타이틀 화면 — 확정 시안 (2026-11-14)

> 사용자·데스크탑 합의. 구현: 원격 (`unity/Assets/Game/Scripts/Screens/TitleScreen.cs`).
> 그림: [current.jpg](current.jpg) (지금) → [mock_connecting.jpg](mock_connecting.jpg) (서버 연결 중), [mock_ready.jpg](mock_ready.jpg) (준비 완료). 모두 1080×1920 기준.

## 화면의 역할

게임 얼굴 + (온라인이면) 서버 세이브 받기. 받는 동안 [시작]을 막고, 끝나면 [시작] → 메인.

## 합의한 것

1. **시작 방법은 [시작] 버튼 하나.** "화면을 눌러 시작" 문구(`ui.title.tapToStart`)는 지운다. 화면 아무 곳이나 눌러도 시작되는 동작은 남긴다 (준비됐을 때만).
2. **연결 상태 문구는 지금처럼** 제목과 버튼 사이. 연결 중 `ui.online.connecting`, 끝나면 `ui.online.<결과>` (예: "서버 세이브를 받았습니다.").
3. **위쪽은 대표 그림 자리.** 제목을 위로 올린다.
4. **한자 낙관(戰) 제거** (`ui.title.seal` 자리). 이 화면만인지 전체 규칙인지는 아직 미정 — 공통 규칙 정할 때 다시.

## 배치 (위에서부터, 1080×1920)

| 영역 | 위치·크기 | 내용 |
|---|---|---|
| 대표 그림 | y 0~700 (높이 700, 가로 꽉) | `Resources/Ui/title_art.png`가 있으면 그것(가로 맞춤, 아래쪽 가운데 기준). **없으면 비워 둔다** (시안의 먹 산·점선 상자·"대표 그림 자리" 글은 시안 표시용, 구현하지 않음) |
| 제목 | y 720~950 | 지금의 붓 획 + 제목 글자 그대로 (크기 그대로), 위치만 올림. 낙관 없음 |
| 빈 공간 | 유동 | |
| 연결 문구 | 가운데 y ≈ 1300 | `Ui.FontSmall`, `Palette.TextDim` (지금과 같음) |
| [시작] 버튼 | x 80~1000, y 1450~1610 (높이 160) | 연결 중: 꺼진 버튼(지금 회색 그대로). **준비되면 `Palette.ButtonActive` (주홍 #C95640), 글자 밝은색** |
| 아래 여백 | y 1610~1920 | |

## 구현 메모 (원격)

- `Ui.Size(Ui.Label(Root, T("ui.title.tapToStart") …` 줄 삭제, 낙관(`stamp`) 블록 삭제.
- 맨 위에 높이 700짜리 그림 자리 (`Ui.Rect` + 그림 있으면 `Image`), 그 아래 제목.
- [시작] 버튼: 처음엔 `Ui.SetEnabled(start, false)`, 동기화 끝나면 `Ui.SetEnabled(start, true)` + `Ui.Recolor(start, Palette.ButtonActive)` (글자색은 `Palette.TextOn`). 오프라인 설정이면 처음부터 주홍.
- 문구 키 변경: `ui.title.tapToStart` · `ui.title.seal`은 안 쓰게 됨 (지울지 원격 판단).
