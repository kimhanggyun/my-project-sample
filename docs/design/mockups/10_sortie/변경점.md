## 역할

공격(또는 스텝 출진) 직전에 **"이길 수 있나?"를 판단하고 데려갈 것을 확정**한다. 영토 공성전이 기준이고, 스토리 스텝도 같은 틀을 쓴다 (스토리 전용 칸만 더함). 영토가 메인 컨텐츠가 되어도 이 화면은 그대로 쓴다.

## 결정 (사용자)

- **1분 준비 카운트는 출진 준비가 끝난 뒤** 시작한다: 영토 [공격 ›] → 출진 준비 (시간 제한 없음, 상대는 모름) → [공격 개시] → 1분 카운트 + 수비자 알림 (08 mock_attack).
- **상대 병력은 대략** (~5,000, 병종 그림 + "?"). **내 닉네임 장수에게 척후 파견**이 있으면 병종별 정확한 수 (반간처럼 닉네임 장수 스킬이 가치).
- **직접 지휘 · 위임 둘 다**: 주요 = [공격 개시] (직접), 보조 = [위임] (AI가 대신, ⓘ).
- **글자 대신 아이콘 · 도형 · 숫자, 설명은 ⓘ** (공통부품.md 원칙 6).

## 규칙 쪽 할 일 (데스크탑)

1. 출진 준비 → [공격 개시]에서 공성전 시작 (territory-v2 2.3 순서: 준비 → 1분 카운트).
2. 상대 병력 대략값 (반올림 규칙, 병종 위주) / 척후 파견(닉네임 장수)이면 정확 — verification 새 규칙.
3. 전력 판단 [우세·비슷·위험] 기준 (병력 비 + 지원 예상, 데이터 값).
4. 상황 편성 자동 고르기 = 전장 종류 (지금 규칙 유지).
5. 깃발에 나간 장수 출진 불가 (territory-v2 2.1).
