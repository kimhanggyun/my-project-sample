# 디자인 시안

> 사용자·데스크탑 Claude가 화면을 하나씩 보며 합의한 **확정 시안**. 데스크탑이 이것을 보고 화면 코드를 고친다 ([collab.md](../../collab.md) 2.1·2.2).
> 그림은 LFS 밖(`.gitattributes`)이라 원격도 직접 열어 볼 수 있다. 1080×1920 기준.

## 폴더마다

| 파일 | 내용 |
|---|---|
| `current.jpg` | 지금 화면 (캡처) |
| `mock_*.jpg` | 확정 시안 (상태가 여럿이면 여러 장) |
| `변경점.md` | 화면 역할, 합의한 것, 배치 표(위치·크기·색), 원격 구현 메모, 문구 키 변경 |

## 진행 순서

0. **먼저 화면의 역할과 꼭 필요한 것**(언제 나오나, 여기서 무엇을 하나, 필요한 상태: 기다림·실패·빈 목록 등)을 정리한다. 디자인은 그다음.
1. 데스크탑이 캡처를 보고 의견 → 사용자 의견 → 합의
2. 데스크탑이 시안(실제 캡처·게임 글꼴·색으로 합성)을 만들고 사용자가 확정
3. 이 폴더에 넣고, 몇 화면씩 묶어 PR → 원격이 구현
4. 데스크탑이 다시 캡처해 시안과 비교
