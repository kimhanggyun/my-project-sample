# 04 메인 화면 틀 + 스토리 탭 — 확정 시안 (2026-11-14)

> 사용자·데스크탑 합의. 구현: 원격 (`Screens/MainScreen.cs` 틀, `Screens/StoryScreens.cs` `StoryTabView`).
> 그림: [current.jpg](current.jpg) → [mock_story.jpg](mock_story.jpg). 1080×1920 기준.

## 역할

- **메인 틀** (모든 탭 공통): 게임의 허브. 자원이 늘 보이고, 탭으로 이동, 상점·설정 입구. 설계상 자원 바 아래 **띠 배너 광고 자리**(탭 화면에서만, 광고 제거 상품으로 없앰 — main-screen.md 1장).
- **스토리 탭**: 다음에 할 스텝을 골라 출진. 진행도·숨은 보상 도감·내 녹화로 가는 길.

## 꼭 필요한 것 → 시안에서

| 층 | 필요한 것 | 시안 |
|---|---|---|
| 틀 | 자원 3종 + 충전 [+] | 자원마다 "아이콘 + 숫자 + 작은 주홍 [+]" 한 덩어리 (둥근 칩) |
| 틀 | 상점·설정 입구 | 오른쪽 아이콘 버튼 두 개: 가방(상점)·톱니(설정) |
| 틀 | 띠 배너 자리 | 자원 바 바로 아래 높이 100 (광고 없으면 높이 0) |
| 틀 | 탭 이동·할 일 점 | 지금 그대로 (두 줄) |
| 스토리 | 다음에 할 스텝이 눈에 띄게 | **"다음 도전" 큰 카드** (주홍 테두리) |
| 스토리 | 진행도 | "스토리  2 / 12 클리어" |
| 스토리 | 잠긴 이유 | 자물쇠 + "앞 스텝을 깨면 열림" |
| 스토리 | 고르기 전 요약 | 카드에 전투 종류·제한 시간·적 군단 수·첫 클리어 보상 |
| 스토리 | 도감·녹화 | 머리 줄 오른쪽 작은 버튼 [도감 1/8] [녹화 0] |

## 합의한 것

1. 띠 배너 자리를 둔다. 2. 상점·설정은 아이콘 버튼. 3. 스텝 목록 = 다음 도전 큰 카드 + 깬/잠긴 스텝 작은 줄. 4. 도감·녹화는 작은 버튼.

## 배치 (1080×1920)

| 영역 | 위치 | 내용 |
|---|---|---|
| 자원 바 | y 0~110, `Palette.Bar` | 자원 칩 3개 (x 24 / 330 / 560, 높이 66, 둥근 33, 연한 바탕·테두리): 아이콘 52 + 숫자 30px + 주홍 원 [+] 44. 오른쪽 아이콘 버튼 80×74 두 개 (x 880, 980) |
| 띠 배너 | y 110~210 | 광고 SDK 배너가 들어갈 빈 자리. 광고가 꺼졌거나 제거 상품이면 0 |
| 스토리 머리 | y 230~330 | "스토리"(제목 글꼴 64) + "2 / 12 클리어"(회색 32) / 오른쪽 작은 보조 버튼 170×72 두 개 |
| 다음 도전 카드 | x 25~1055, y 350~860 | 카드 바탕, **주홍 테두리 5px**. 주홍 꼬리표 "다음 도전" → 스텝 이름(제목 글꼴 54) → 요약 한 줄(회색 30) → "첫 클리어 보상"(굵게) + 보상 한 줄 → 주홍 [출진] 버튼(높이 130) |
| 깬 스텝 | 머리말 "깬 스텝"(굵은 회색 28) + 줄 높이 90 | 카드 바탕, 초록 ✓ + 이름 34px + 오른쪽 "다시 하기 ›" |
| 잠긴 스텝 | 머리말 "다음 스텝" + 줄 높이 84 | 흐린 바탕, 자물쇠 + 흐린 이름 + 오른쪽 작은 "앞 스텝을 깨면 열림" |
| 아래 탭 | 지금 그대로 | |

## 시안에 없는 줄 종류 (지금 코드에 있음)

- **구출 스텝** (`[구출]` + 갇힌 장수·남은 기한, E23): 기한이 있어 급하므로 **다음 도전 카드 바로 아래**에 빨간 꼬리표 "구출" + 남은 시간(`Palette.Bad`)을 단 카드로. 카드 모양은 다음 도전과 같고 테두리만 빨강.
- **연습 스텝**(drill, 머리 아래 extras 줄): 작은 보조 버튼으로 머리 줄 아래 한 줄에.

## 아직 정하지 않은 것 (10 스텝 화면에서 정함)

- 카드의 [출진]이 지금처럼 스텝 화면(10)을 거칠지, 바로 출진 준비로 갈지.
- 깬 스텝 "다시 하기 ›"가 같은 스텝 재도전인지, 기록 보기인지.

## 구현 메모 (원격)

- 자원 칩·아이콘 버튼·띠 배너 자리는 **메인 틀**이라 모든 탭에 같이 바뀐다.
- 스토리: `StoryTabView`의 스텝 버튼 목록 → "첫 미클리어·열린 스텝" 하나를 큰 카드로, 나머지는 상태별 작은 줄. 요약은 `StepDef`(전투 종류·시간·적 군단 수)와 첫 클리어 보상에서.
- 문구 키 (새): `ui.story.progress` ("{0} / {1} 클리어"), `ui.story.next` ("다음 도전"), `ui.story.sectionCleared` ("깬 스텝"), `ui.story.sectionNext` ("다음 스텝"), `ui.story.lockedHint` ("앞 스텝을 깨면 열림"), `ui.story.replay` ("다시 하기 ›"), `ui.story.sortie` ("출진"), `ui.story.firstReward` ("첫 클리어 보상"). [도감]·[녹화] 짧은 문구 `ui.codex.short` ("도감 {0}/{1}")·`ui.replay.short` ("녹화 {0}").
