# 시안에 대한 원격 검토 (규칙·데이터 쪽)

> 원격 Claude가 시안을 읽고 규칙·데이터에서 걸리는 것과, 화면이 쓰면 되는 값을 적는다. 시안이 늘면 이어서 적는다.
> 처음: 2026-11-14, 시안 01~05.

## 화면이 쓰면 되는 값 (원격이 만들어 둠, `src/Game.Flow/ScreenData.cs`)

| 시안 | 필요한 것 | 쓰면 되는 것 |
|---|---|---|
| 04 스토리 | 진행도 "2 / 12 클리어" | `StoryBoard.Progress(defs, state)` → (깬 수, 본편 수) |
| 04 스토리 | 다음 도전 카드·깬 줄·잠긴 줄·구출 카드 | `StoryBoard.Build(defs, flow, state)` → `StepCard` 목록. `IsNext`(다음 도전 하나), `State`(Cleared·Open·Locked), `IsRescue`, `LockReason`("previous" = 앞 스텝을 깨면 열림, "rescue" = 갇힌 장수 없음) |
| 04 스토리 | 카드 요약 | `StepCard`의 `BattleType`·`MaxMinutes`(0 = 제한 없음)·`EnemyCorps`·`EnemyTroops`·`RecommendedLevel`·`Weather`·`TimeOfDay` |
| 04 스토리 | 첫 클리어 보상 | `StepCard`의 `RewardResources`(자원 id → 양)·`RewardExp`·`RewardGenerals`·`RewardSkills`·`RewardFormations` |
| 04 스토리 | 구출 카드 남은 기한 | `StepCard.RescueHeld`(갇힌 수)·`RescueDeadlineUnixSeconds`(가장 짧은 기한) |
| 04 스토리 | 연습(훈련) 스텝 줄 | `StoryBoard.Drills(defs, flow, state)` → 열린 훈련 스텝 id |
| 04 틀 | 띠 배너 높이 | `IBannerAdService.HeightPixels` (꺼져 있으면 0) + `Purchases.AdFree(state, now)`이면 0 |
| 05 장수 | 정렬 | `GeneralRoster.Sorted(defs, generals, GeneralSorts.Grade/Level/Ready)` (등급 = gacha.json `grades` 순서, 뒤가 높음) |
| 05 장수 | 카드 할 일 점 | `GeneralRoster.NeedsAttention(defs, state, generalId)` (지금 배울 수 있는 스킬북 또는 한계 돌파 가능 — 탭 할 일 점과 같은 조건) |
| 05 장수 | 등급 테두리 색 | 지금처럼 `GradeLabel` (등급 id: common·advanced·rare·hero·legend) |
| 03 약관 | "약관이 바뀌었습니다" 줄 | `StartupFlow.IsReagree(record)` |
| 02 로그인 | 버튼 순서 | `data/Ui/startup.json` 순서를 구글 → 애플 → 게스트로 바꿔 둠 |

## 규칙에서 걸리는 것 (사용자·데스크탑이 정해 줘)

1. **04 "다시 하기 ›"**: 깬 스텝을 다시 하면 지금 규칙은 **첫 클리어 보상을 다시 주지 않는다** (경험치·성장만, 숨은 보상은 조건대로). "다시 하기"가 같은 스텝 재도전이면 화면에 "보상 없음(경험치만)" 같은 안내가 필요하다. 반복 보상을 줄 거면 규칙을 새로 정해야 한다 (예: 첫 보상의 10%).
2. **04 카드 요약의 "제한 시간"**: 모든 스텝에 `maxMinutes`가 있다 (기본값 포함). "제한 없음"으로 보일 스텝은 없다.
3. **04 잠긴 이유**: 본편은 늘 "앞 스텝". 구출 스텝은 갇힌 장수가 있을 때만 목록에 나오므로 잠긴 구출 카드는 보통 안 보인다.
4. **05 상태 띠**: 장수 상태는 출전 가능·경상·중상·포로(Captured) 네 가지 + 한계 돌파 등은 상태가 아니다. 포로(우리 장수가 적에게 잡힘)는 장수 목록에 그대로 남는다.
5. **05 정렬 "출전 가능 먼저"**: 경상도 출전은 된다 (능력치만 깎임). 그래서 "출전 가능" 정렬에서 경상은 뒤로 보내지 않고 상태가 Available인 것만 앞으로 둔다 — 경상을 출전 가능에 넣을지 정해 줘.
6. **01·02 한자 낙관 미정**: 아이콘 대체 글자(糧錢玉統武智)는 데스크탑이 아이콘 그림을 넣어서 이제 거의 안 보인다 (그림이 없을 때만).
