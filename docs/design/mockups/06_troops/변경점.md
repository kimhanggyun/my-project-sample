## 역할

가진 부대(병종 하나 = 부대 하나)를 훑어보고 **키우는** 곳: 훈련(훈련도), 충원(병력), 승급(특화 병종). 전투 전에 "어느 부대가 약한가"를 보고 바로 손댄다. 부대 편성(07)은 장수에게 부대를 붙이는 곳이라 따로.

## 합의한 것

1. 탭 이름 **"부대" → "부대 관리"** (`ui.tab.troop`).
2. 병종 그림은 **전투 병사 모델**을 쓴다 (보병·창병·궁병·첨병·공병 = KayKit 병사, 기병 = 말).
3. 줄 순서 = **이름 → 게이지 → 값**. 사기는 전투 밖에 없으므로 **결속**을 보인다.
4. 병력 게이지 = 최대 **5,000** (`troopCap.unitMax`) 기준. 부상병 수만큼 같은 색 **반투명**(알파 약 0.37)으로 이어서 그림. 병력+부상이 가득이면 충원할 수 없음.
5. 오른쪽 버튼은 **좁게(190)** 두 단: 위 = 무엇(+양), 아래 = 비용. 돈·군량이 모자라면 **흐린 바탕 + 빨간 비용**.
6. **[충원]은 고르는 작은 메뉴**: 징병(군량) · 모병(돈) · 치료(부상병 → 병력, 부상이 있을 때만). 버튼 아래 줄에는 징병 비용을 보임. 가득이면 버튼에 "가득".
7. 승급 상세에서는 **훈련도 줄을 다시 보이지 않는다** (목록에 있음). 상세 = 승급 카드만.
8. 승급 카드: "→ 방패병" + 설명 + **조건 체크 줄** (✓ 초록 / ✗ 빨강, "훈련도 50% 이상 (지금 50%)", "(임시) 숲길 매복 클리어", "돈 400 (보유 3)") + **승급할 인원 [−] 800 [+] / 2,096 [모두]** + 승급 버튼(조건을 모두 채우면 켜짐).
9. **승급한 부대는 기본 부대 아래 들여쓴 카드**("제1부대 › 방패병"). 아래 줄에 "제1부대 보병에서 부분 승급 · 다음 승급 없음".
10. **기본 병종 카드는 항상 남는다.** 부분 승급 = 남은 병사는 기본 부대에 그대로. 전체 승급 = 기본 카드는 **병력 0 / 5,000**으로 남고 "모두 중기병으로 승급함 · 충원하면 다시 기병". (전체 승급을 둘지는 나중에 정함 — 시안은 둘 다 보임)

## 구현 메모

- 카드 눌러도 아무 일 없음 (버튼·ⓘ·"승급 ›"만 누름). 승급 부대 카드의 아래 줄은 누르는 칸 아님.
- 병종 그림은 미리 찍어 둔 그림(데스크탑이 모델에서 만들어 `Resources/Ui/troops/`에 넣음). 승급 병종은 기본 병종 그림을 같이 써도 됨 (나중에 따로).
- 충원 메뉴는 버튼 바로 위에 뜨는 작은 목록 (공통 부품 "고르는 작은 메뉴"). 부대 정비 탭(징병·모병·치료)과 겹치는 부분은 **07 이후 부대 정비 탭을 볼 때 정한다** (정비 탭을 없앨지, 여러 부대 한꺼번에로 남길지).
- 결속 게이지 최대값: 시안은 100으로 그림 (지금 값 4~7이라 짧음). 결속에 최대가 없으면 표시용 기준을 정한다 (아래).
- 문구 키 (새·바꿈, 데스크탑이 넣음): `ui.tab.troop` "부대 관리", `ui.troops.count` ("{0}개"), `ui.troops.row.troops`/`training`/`cohesion` ("병력"/"훈련도"/"결속"), `ui.troops.wounded` ("+부상 {0} / {1}"), `ui.troops.trainShort` ("훈련 +{0}%"), `ui.troops.refill` ("충원 +{0}"), `ui.troops.refill.full` ("가득"), `ui.troops.refill.conscript`/`recruit`/`heal`, `ui.troops.promoteCount` ("승급 {0}가지 ›"), `ui.troops.noPromotion` ("다음 승급 없음"), `ui.troops.promotedFrom` ("{0} {1}에서 부분 승급" / 전체 승급), `ui.troops.allPromoted` ("모두 {0}(으)로 승급함 · 충원하면 다시 {1}"), `ui.troops.promoteTitle` ("{0} — 승급"), `ui.troops.promoteAmount` ("승급할 인원"), `ui.troops.promoteAll` ("모두"), `ui.troops.promoteButton` ("승급"), `ui.troops.promoteLocked` ("승급 (조건을 모두 채우면 켜짐)"), 조건 줄 `ui.troops.cond.training` ("훈련도 {0}% 이상 (지금 {1}%)"), `ui.troops.cond.gold` ("돈 {0} (보유 {1})").
- 기본 병종 설명 키 (새): `troop.desc.infantry`·`spearman`·`archer`·`cavalry`·`scout`·`engineer` (승급 병종은 이미 있음).

## 규칙 변경 할 일 (데스크탑, 원래 원격 요청으로 쓰던 것)

### 1. 승급 규칙 변경 (게임 규칙 — `troop-growth.md`, `verification.md` 같이)

지금: 승급하면 **부대 전체의 병종이 바뀐다** (`ui.troops.note` "승급해도 병력·훈련도는 그대로").
바꿀 것:
1. **기본 병종 부대는 항상 남는다.**
2. **부분 승급**: 승급할 인원 N(1 ≤ N ≤ 지금 병력)을 고른다. N명이 **새 승급 부대**(같은 부대 번호 아래, 병종 = 승급 병종)로 옮겨 가고, 나머지는 기본 부대에 그대로. 비용은 인원에 비례할지 고정일지 정한다.
3. **전체 승급**(둘지는 나중에): N = 지금 병력. 기본 부대는 병력 0으로 남고 다시 충원할 수 있다.
4. 같은 승급 병종으로 또 승급하면 이미 있는 승급 부대에 합친다 (부대 상한 5,000 안에서). 넘치면 막거나 최대로 줄임.
5. 정할 것: 승급 부대의 훈련도·결속 (기본 부대 값을 물려받나, 합칠 때 평균인가), 부상병은 옮겨 가지 않음(제안), 승급 부대도 편성(07)에서 따로 고를 수 있는 부대인가 (제안: 예).
- 화면이 쓸 값: 부대마다 "어느 기본 부대에서 왔나"(부모 id), 승급 조건별 충족 여부·지금 값.

### 2. 결속 표시 기준
- 결속 게이지 최대값(표시용). 정해진 최대가 없으면 하나 정한다 (시안은 100).
