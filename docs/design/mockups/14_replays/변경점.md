## 역할

내 전투를 **다시 보고**, 잘된 전투를 **공략으로 공유**하거나 **영상으로 저장**한다. 다른 사람의 공략을 둘러본다.

## 결정 (사용자)

- **탭 2개: 내 녹화 + 공략** (공략은 출진 준비 [공략 보기] 말고 여기서도 둘러봄, 서버 꺼지면 탭 숨김).
- **최근 5개 자동 보관** (저장 안 한 최근 전투, 새 전투가 오면 밀려남, [저장]하면 20칸으로 — 결과 화면에서 잊어도 됨).
- **카드 = ▶ 재생 + ⋯ 메뉴** (공략으로 공유 · 영상으로 저장 · 삭제).

## 규칙 쪽 할 일 (데스크탑)

1. **최근 자동 보관**: 마지막 전투 기록 5개(데이터 `recentKeep`)를 저장소에 따로 — 새 전투가 오면 가장 오래된 것 밀어냄, [저장]하면 저장 목록으로 옮김. verification 새 규칙.
2. 분류 (스토리 · 영토 · 용병) = 전투 종류에서.
3. 공략 탭: 지금 R-81 목록을 스텝·영토 전투 고르기로 (서버 API 그대로), 추천(♥) 수 — 서버 새 필드.
4. 영상 저장은 네이티브 녹화가 필요 (replay.md 2.1, 이어서).
