# 02 로그인 화면 — 확정 시안 (2026-11-14)

> 사용자·데스크탑 합의. 구현: 원격 (`Screens/StartupScreens.cs` `SignInScreen`, 순서 데이터 `data/Ui/startup.json`).
> 그림: [current.jpg](current.jpg) → [mock_default.jpg](mock_default.jpg) (기본), [mock_loading.jpg](mock_loading.jpg) (로그인 중), [mock_failed.jpg](mock_failed.jpg) (실패). 1080×1920 기준.

## 역할

자동 로그인이 안 될 때(처음 실행·실패)만 나온다. 계정 방식을 하나 고르면 약관 → 타이틀로 넘어간다. 한 번 로그인하면 보통 다시 안 본다.

## 꼭 필요한 것 → 시안에서

| # | 필요한 것 | 시안 |
|---|---|---|
| 1 | 로그인 방법 버튼 | 구글 → Apple → 게스트 |
| 2 | 게스트와 계정 연동의 차이 | 게스트 버튼 바로 아래 작은 글씨 |
| 3 | 로그인 실패 안내 | 버튼들 바로 위 빨간 한 줄 (mock_failed) |
| 4 | 로그인 중 (두 번 누르기 방지) | 누른 버튼 글자 → "로그인 중…" + 도는 표시, 다른 버튼 흐리게 막음 (mock_loading) |
| 5 | 버튼이 늘어도 되는 자리 (카카오 등 데이터로 추가) | 버튼 4개 이상이면 위쪽 그림 자리를 줄여 버튼이 아래쪽에 들어가게 |
| 6 | 첫인상 | 위쪽은 [01 타이틀](../01_title/변경점.md)과 똑같이 (그림 자리 + 붓 획 제목) |

## 합의한 것

1. 위쪽 = 01 타이틀과 같은 그림 자리(y 0~700) + 붓 획 제목(y 720~950). 글자만 있던 제목은 없앤다.
2. **구글·Apple 버튼은 각 회사 버튼 모양**: 구글 = 흰 바탕·회색 테두리·색깔 G 로고·검은 글자, Apple = 검은 바탕·흰 사과 로고·흰 글자. **시안의 로고는 모양만 흉내 낸 것 — 구현은 구글·Apple이 제공하는 공식 로그인 버튼 그림을 쓴다** (두 회사 모두 버튼 모양 규정이 있다: Google Sign-In branding guidelines, Apple Human Interface Guidelines "Sign in with Apple").
3. **Apple은 지금처럼 꺼진 버튼** + "(준비 중)" (`startup.json` status `tobe`) — 흐리게.
4. 게스트 = 보조 버튼 (지금 한지색 `Palette.Button`). 맨 아래.
5. 설명(`ui.signIn.note`)은 버튼 위에서 **게스트 버튼 아래**로.

## 배치 (1080×1920, 버튼 3개일 때)

| 영역 | 위치 | 내용 |
|---|---|---|
| 그림 자리 | y 0~700 | 01과 같음 (그림 없으면 비움) |
| 제목 | y 720~950 | 01과 같음 |
| 실패 문구 | y ≈ 1095 (가운데) | `Palette.Bad`, `Ui.FontSmall`. 평소엔 비움 |
| 구글 | x 80~1000, y 1150~1280 (높이 130) | 공식 버튼 모양 |
| Apple | y 1310~1440 | 공식 버튼 모양, 꺼짐 = 흐리게 |
| 게스트 | y 1470~1600 | 보조 버튼 |
| 게스트 설명 | y 1620~ | `Ui.FontSmall`, `Palette.TextDim`, 두 줄 |
| 버튼 4개 이상 | | 그림 자리 높이를 줄인다 (버튼 하나당 160만큼) |

## 구현 메모 (원격)

- 버튼 순서는 `startup.json`의 `signIn` 순서를 따른다 → **구글·Apple·게스트 순으로 데이터를 바꾸면** 된다 (지금 게스트가 첫째).
- 버튼 모양을 방식 id별로: `google` → 흰 바탕 공식 모양, `apple` → 검은 바탕 공식 모양, 그 밖(`guest`, 나중 `kakao` 등) → 기본/보조 버튼. 공식 버튼 그림은 데스크탑이 받아 `Resources/Ui/signin/<id>.png`로 넣을 수 있다 (요청하면).
- 로그인 중: 누른 버튼 글자를 `ui.signIn.waiting`(새 키, 예: "로그인 중…")으로, 다른 버튼 `Ui.SetEnabled(false)`. 콜백이 오면 원래대로.
- 실패 문구 `ui.signIn.failed`를 **"로그인하지 못했습니다. 다시 시도하거나 게스트로 시작하세요."**로 (지금: "…다시 시도해 주세요.").
- 문구 키: 새 `ui.signIn.waiting`, 수정 `ui.signIn.failed`.
