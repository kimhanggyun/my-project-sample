> 지금 데이터에 들어 있는 값은 모두 **예시**다. 이 문서는 "무엇이 아직 정해지지 않았고, 지금 임시로 무엇이 들어 있으며, 무엇부터 정하면 좋은가"를 한곳에 모은다.

### 3.6 숨은 보상

- 지금 예시 8개 (`secrets.json`, secrets.md 7장): 위 4개 + step03 불로 3군단 → 특성 화염의 달인, step04 손실 5% 이하 → 재정비, step05 궁병 없이 → 특성 야습, step06 손실 10% 이하 → 특성 불굴.
- 문턱(5%·10%)은 위임 출진 60판 중 약 3판이 나오게 맞춘 예시. 비 오는 스텝이 없어 "빗속 행군"은 아직 얻을 수 없다.
- 정할 것: **첫 버전 목록** (secrets.md 미결), 특성 효과 수치 (traits.md 미결 — 지금 특성은 이름만 있고 효과 없음).

## 5. 수치가 아닌 미결 (참고)

수치는 아니지만 위 값에 영향을 주는 결정이다.

- 적 군단 병력은 스텝 데이터에 직접 쓴다 (아군과 달리 장수 통솔 한도를 검사하지 않음. ai.md 1장 "스토리 난이도는 스텝 데이터에서 명시적으로"). 한도를 적에게도 적용할지
- 장수 등급 단계 수와 이름, 등급별 스킬·특성 칸 수 (generals.md, traits.md)
- 진형 특성치(정면 폭·돌파력 …)를 넣을지, 넣는다면 수치 (formations.md) — 지금 전투는 "접전이면 근접 소부대 전부 교전"으로 단순화되어 있다
- 병종 승급 트리 (troops.md, troop-growth.md)
- 맵 칸 크기·맵 크기 기준 (maps.md)

## 6. 정하는 순서 (제안)

1. **A-1 목표 전투 길이**와 **스텝별 목표 승률**을 정한다.
2. `StepSimulator`(위임 출진으로 스텝을 여러 시드 자동 대전, ai.md 11장 "스텝 승률 확인")로 승률·길이·손실·군량을 잰다.
3. A-2, A-3(피해·사기)으로 전투 길이를 맞추고, A-6·A-7(적 군량·병력·난이도)로 스텝 승률을 맞춘다.
4. A-8·A-9(일기토)를 조정하고 다시 잰다.
5. B는 콘텐츠를 늘릴 때마다, C는 서버·결제 단계에서.

정한 값은 데이터만 고치면 된다 (코드 수정 없음). 값이 바뀌면 기준 전투 정답 파일을 다시 저장하고, 바뀐 결과를 PR에서 확인한다.
