# 아트 방향

> 상태: 방향 결정 (2026-11-11, 사용자 "추천대로") · 시안: 화면 스타일 `ink` (`data/Ui/styles.json`, 설정 → 화면 스타일)
> 관련: [content/main-screen.md](content/main-screen.md) 2.2(스타일 데이터), [theme.md](theme.md)(테마·문자열)

## 1. 한 줄 방향

**수묵·한지 느낌의 화면 + 단순하고 잘 읽히는 3D 전장.** 와룡전은 전투 장면의 진행만 참고하고, 그림·화면은 자체 세계관으로 만든다.

## 2. 전장 (3D)

- 단순화한 지형(평지·숲·언덕·강·습지)을 부드러운 색으로. 세로 폰 화면에서 **대형·진형이 한눈에 보이는 것**이 디테일보다 먼저.
- 부대 = 작은 병사 무리 또는 깃발 토큰. 병종은 실루엣·깃발 무늬로 구분.
- 진영 색은 진하게 (아군 쪽빛, 적군 붉은색). 선택·명령 표시는 먹선 느낌의 원·화살표.

## 3. 화면 (UI)

- 바탕: 한지 질감, 밝은 종이색. 글자: 먹색. 강조: 낙관(도장) 붉은색.
- 제목: 붓글씨 느낌 (글꼴은 본명조 계열). 본문: 읽기 쉬운 고딕 (Pretendard 계열). 둘 다 상업적 무료(OFL) 글꼴 — 글꼴 파일은 크기가 커서 실제 적용 때 넣는다.
- 버튼·카드: 살짝 둥근 판, 얇은 먹선 테두리 (지금 시안은 색·둥글기만).
- 아이콘: 시험 단계는 game-icons.net (CC BY 3.0, 출처 표기), 나중에 같은 붓 터치로 다시 그린다.

## 4. 장수 초상

- 상반신 일러스트, **한 화풍**으로 통일 (수묵 실루엣 계열이 통일하기 쉽다).
- 외주·AI 보조 어느 쪽이든 화풍 통일과 사용권(상업 이용)을 먼저 확인한다.

## 4.5 적용 (2026-11-13)

- 기본 화면 스타일을 `ink`로 (`data/Ui/styles.json` default). 한지 바탕(`paper`), 버튼·카드 먹선 테두리(`inkBorder`), 낙관 붉은색(`seal`), 전장 위 알림판(`promptBack`·`promptText`), 지우기 버튼(`danger`).
- 질감·테두리·붓 획·낙관은 코드로 만든 임시 그림 (`Scripts/UI/UiArt.cs`). 진짜 그림은 `Resources/Ui/paper|frame|brush|seal` 스프라이트를 넣으면 그것을 쓴다.
- 글꼴 적용: 제목 = 본명조(Noto Serif KR SemiBold, 한글·라틴·쓰는 한자만 남긴 부분 글꼴), 본문 = Pretendard Medium. 둘 다 SIL OFL (`Resources/Fonts/LICENSE-*.txt`). 본문 글꼴에 없는 한자는 제목 글꼴로 대체.
- 상단 바 자원 표식: 낙관 안에 한 글자 (糧·錢·玉, 문구 `ui.top.seal.*`). 타이틀: 먹 붓 획 위 제목 + 낙관(戰).
- 버튼 글자색은 판 밝기에 맞춰 자동 (먹색/종이색). 전장 위 글자(깃발 이름·알림)는 테두리를 둘러 어느 바탕에서도 읽히게.
