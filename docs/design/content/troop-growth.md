# 부대 키우기 (TO-BE)

> 상태: **TO-BE** — 하단 탭에 "준비 중"으로 표시. 컨텐츠는 나중에 구성한다.
> 전체 흐름: [../flow.md](../flow.md) · 관련 규칙: [battle.md](battle.md) 2.2.1(진형), 2.3(병종과 성장) · 구조: [../structure.md](../structure.md)(../structure.md) Progression 모듈

## 0. 대상

이 탭이 키우는 것은 **보유 부대**다 (장수와 따로 보유, [formation.md](formation.md) 2장).

## 1. 목적

부대(병종)를 특화 병종으로 성장시키고, 새 전술 진형을 늘린다.

**최종 목적: 다른 유저가 고용할 만한 부대를 만드는 것.** 부대는 장수와 **따로** 서버에 등록되어 고용 대상이 된다 ([hiring.md](hiring.md) 2.2).

부대 키우기는 부대를 **통째로 손발이 맞게 훈련**시키는 것이다. 예: 단순 보병을 훈련시켜 **등갑병 부대**로 만든다.

## 2. 지금까지 정해진 것

- **결속**: 전투 **승리**로 쌓이는 부대 값. 상태이상(혼란 등) 회복이 빨라진다 ([battle.md](battle.md) 2.19.1). 이 탭과 별개로 전투에서 쌓인다.
- **훈련도**: 부대 단위로 쌓이는 값. 높을수록 응집력·반응 속도·판단력 보너스 (함께 훈련한 부대라 손발이 맞음). 부대에 붙어 있어 누가 이끌어도 유지된다.
- **특화 승급 예**: 보병 → (훈련) → **등갑병** (예: 물리 방어가 매우 높지만 화공에 약함).

- **병종 승급**: 기본 4병종(보병·창병·궁병·기병)과 첨병·공성 계열에서 특화 병종으로 승급한다. 전체 트리는 [troops.md](troops.md).
- 승급 조건(초안): 소부대 숙련도, 장수 레벨, 스텝 해금.
- **진형 해금**: 특정 컨텐츠로 새 진형을 배운다. 진형 습득 단계는 [formations.md](formations.md) 7장.
- 병종·진형은 모두 데이터(`troopTypes.json`, `formations.json`)라 추가가 쉽다.

## 3. 탭이 생기기 전까지

- 병종은 초기 지급 구성 그대로, 진형은 초기 지급 + 스토리 보상으로만 늘어난다.

## 4. 연결 방식

- 이 탭은 **부대 데이터(병종, 숙련도, 배운 진형)를 바꾸는 역할만** 한다. 전투·편성 코드는 바뀌지 않는다.
- 탭 모듈: `TroopGrowthTab`, `PromotionService`.

- [ ] 진형 해금 컨텐츠
