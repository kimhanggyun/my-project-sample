# 부대 키우기 (TO-BE)

> 상태: **1차 구현** (2026-11-09, R-52): 부대 탭 = 훈련(돈 → 훈련도, 전투 공격·방어 보정)·승급(1단계 → 2단계 특화 4종: 방패병·장창병·노병·중기병 → 3단계 정예 4종: 근위병·창벽병·강노병·철기). 데이터 `data/Rules/troopGrowth.json`·`troopTypes.json`, 수치는 예시. 3단계는 능력치·태그(`elite`, 근위병 `bodyguard`) + 태그 효과(R-58: 정예 사기 안정, 근위병 포로 압력 감소, 창벽병 방원·횡진 정면 철벽). 재훈련·진형 해금 컨텐츠도 아직. **2026-11-14 승급을 인원 갈라 내기로 바꿈** (2.1, 시안 06)
> 전체 흐름: [../flow.md](../flow.md) · 관련 규칙: [battle.md](battle.md) 2.2.1(진형), 2.3(병종과 성장) · 구조: [../structure.md](../structure.md)(../structure.md) Progression 모듈

## 0. 대상

이 탭이 키우는 것은 **보유 부대**다 (장수와 따로 보유, [formation.md](formation.md) 2장).

## 1. 목적

부대(병종)를 특화 병종으로 성장시키고, 새 전술 진형을 늘린다.

**최종 목적: 다른 유저가 고용할 만한 부대를 만드는 것.** 부대는 장수와 **따로** 서버에 등록되어 고용 대상이 된다 ([hiring.md](hiring.md) 2.2).

부대 키우기는 부대를 **통째로 손발이 맞게 훈련**시키는 것이다. 예: 단순 보병을 훈련시켜 **등갑병 부대**로 만든다.

## 2. 지금까지 정해진 것

- **결속**: 전투 **승리**로 쌓이는 부대 값. 상태이상(혼란 등) 회복이 빨라진다 ([battle.md](battle.md) 2.19.1). 이 탭과 별개로 전투에서 쌓인다.
- **훈련도**: 부대 단위로 쌓이는 값. 높을수록 응집력·반응 속도·판단력 보너스 (함께 훈련한 부대라 손발이 맞음). 부대에 붙어 있어 누가 이끌어도 유지된다.
- **특화 승급 예**: 보병 → (훈련) → **등갑병** (예: 물리 방어가 매우 높지만 화공에 약함).

- **병종 승급**: 기본 4병종(보병·창병·궁병·기병)과 첨병·공성 계열에서 특화 병종으로 승급한다. 전체 트리는 [troops.md](troops.md).
- 승급 조건(초안): 소부대 숙련도, 장수 레벨, 스텝 해금.
- **진형 해금**: 특정 컨텐츠로 새 진형을 배운다. 진형 습득 단계는 [formations.md](formations.md) 7장.
- 병종·진형은 모두 데이터(`troopTypes.json`, `formations.json`)라 추가가 쉽다.

### 2.1 승급 = 인원을 골라 갈라 낸다 (2026-11-14, R-52, 시안 [06](../mockups/06_troops/변경점.md))

- **기본 병종 부대는 늘 남는다.** 승급할 인원 N을 고르면 그 N명이 기본 부대 **아래의 승급 부대**로 옮겨 간다 (부대 `ParentUnitId` = 기본 부대). 나머지는 기본 부대에 그대로.
- **전체 승급** = N이 지금 병력 전부. 기본 부대는 **병력 0으로 남고** 다시 충원할 수 있다 (충원하면 다시 그 기본 병종). 행동 `unit.promote`의 Count가 0이면 전부 (예전 행동과 같은 입구).
- **비용**: 1,000명당 데이터 금액(`troopGrowth.json` promotions gold), 올림. 800명 → 1번 몫, 2,096명 → 3번 몫.
- **훈련도·결속**: 새 승급 부대는 기본 부대 값을 물려받는다. 같은 병종으로 또 승급하면 이미 있는 승급 부대에 **합치고**, 값은 인원 가중 평균(내림).
- **한도**: 새 승급 부대는 부대 수 상한(`campaign.json` units.maxCount)에 든다 — 꽉 차면 새로 못 만든다(합치기는 됨). 합칠 때 병력+부상병이 부대 상한(unitMax)을 넘으면 안 된다.
- **부상병은 옮기지 않는다** (기본 부대에 남아 회복·치료).
- 승급 부대에서 다시 승급(2단계 → 3단계 정예)하면 그 아래에 또 갈라 나간다. 화면은 나무처럼 들여써 보인다.
- 기본 부대를 해산하면 그 아래 승급 부대는 맨 위 부대가 된다.
- 화면: 승급 화면에서 [−] N [+] / 최대 · [모두] (100명 단위). 편성(07)에서 승급 부대를 따로 고를 수 있다.

## 3. 탭이 생기기 전까지

- 병종은 초기 지급 구성 그대로, 진형은 초기 지급 + 스토리 보상으로만 늘어난다.

## 4. 연결 방식

- 이 탭은 **부대 데이터(병종, 숙련도, 배운 진형)를 바꾸는 역할만** 한다. 전투·편성 코드는 바뀌지 않는다.
- 탭 모듈: `TroopGrowthTab`, `PromotionService`.
