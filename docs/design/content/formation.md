# 부대 편성 · 초기 지급

> 상태: 기획 확정 (구현 전) · 범위: Step 1~2
> 전체 흐름: [../flow.md](../flow.md) · 관련: [story.md](story.md)(출진 준비), [battle.md](battle.md)(군단 구조·진형) · 구조: [../structure.md](../structure.md)(../structure.md) Campaign 모듈, UI 모듈

## 1. 장수·부대 능력치가 바뀌는 경로

장수 키우기·부대 키우기는 TO-BE이므로, 장수·부대 능력치는 **초기 지급값 + 전투 결과(부대 결속, 더딘 장수 경험치)**로만 바뀐다. 출전 구성은 **부대 편성 탭**에서 정한다 (스텝 데이터는 적군만 정함).

- 아군 출전 장수·부대는 **부대 편성**에서 가져온다. 스텝 JSON에는 적군, 맵, 출전 가능한 군단 수 등만 넣는다.
- 장수·부대의 능력치는 초기 지급값과 전투 결과(부대 결속, 더딘 장수 경험치)로 바뀐다.
- 나중에 키우기 탭이 생기면, 그 탭이 같은 데이터(장수 능력치, 부대 병종·진형)를 바꾸는 방식으로 붙는다. 전투 쪽은 수정하지 않는다.

## 2. 장수와 부대는 따로 보유한다 (확정)

```
보유 장수 목록                 보유 부대 목록
 ├ 장수 A (통솔 → 병력 한도)    ├ 보병 부대 ① 3,000명 (훈련도·결속)
 ├ 장수 B                       ├ 궁병 부대 ② 2,000명
 └ 장수 C                       └ 창병 부대 ③ 2,500명 …

편성: 군단 = 장수 1명 + 소부대 칸 6개(선봉·중앙·좌익·우익·좌비·우비)
      각 칸에 보유 부대 1개를 넣는다
```

| 규칙 | 내용 |
|---|---|
| **부대** | 장수와 별개로 보유하는 단위. 병종, 병력, 부상병, 훈련도, 결속, 익힌 진형을 가진다 |
| **칸 1개 = 부대 1개** | 군단의 소부대 칸마다 부대 하나를 넣는다. 빈 칸도 허용 |
| **병력** | 각 칸의 병력 = 그 부대가 가진 병력. 군단 합계는 **장수 통솔 한도**(5,000~20,000)를 넘을 수 없다 |
| **부대 최대 병력** | 부대 하나의 최대 병력은 설정값 (예: 5,000) |
| **병종 바꾸기** | 칸의 병종을 바꾸려면 **다른 부대로 교체**한다. 훈련도·결속은 각 부대에 그대로 남는다 |
| **승급** | 부대 키우기에서 부대가 특화 병종으로 승급하면, 같은 부대가 병종만 바뀐다 (결속 유지, 훈련도는 승급 규칙에 따름) |
| **한 부대는 한 군단에만** | 같은 부대를 두 군단에 넣을 수 없다 |
| **고용한 부대** | 출진 준비에서 빈 칸에 넣는다 ([hiring.md](hiring.md)) |
| **부대 상한** | 보유할 수 있는 부대 수 상한은 설정값 (확장 가능) |

- 전투에서 소부대 하나 = 부대 하나다. 화면 병사 수는 그 부대 병력 ÷ 비율 ([battle.md](battle.md) 2.4).
- 장수가 포로가 되어 군단이 궤멸해도 **부대는 남는다**. 전투 후 살아남은 병력(사망·부상 반영)으로 돌아온다.

## 3. 초기 지급 (새 게임)

새 게임을 시작하면 바로 출전할 수 있도록 기본 장수와 부대를 지급한다.

| 항목 | 내용 |
|---|---|
| 장수 | **3명** (기본 군단 수 3과 맞춤). **익명**(임시 이름, 예: 장수 A·B·C), 등급은 고급 정도 ([generals.md](generals.md)) |
| 능력치 | **중간 정도** (1~100 기준 약 50 전후). 세 장수의 합계는 비슷하게, 성격은 다르게 (예: 통솔형 / 무력형 / 지략형) |
| 레벨 | 1 |
| 부대 | 기본 병종(보병·창병·궁병·기병·첨병) 부대 여러 개. 세 장수의 소부대 칸을 채우고 각 장수 통솔 한도에 맞는 병력 |
| 진형·스킬 | 방진·장사(기본) + 초급 진형 일부(어린·학익 등, [formations.md](formations.md) 7장), 장수 기본 스킬 |
| 군량 | 시작 군량 (첫 전투 몇 번 분량) |
| 편성 | 기본 편성 1개가 미리 채워져 있음 |

- 장수·부대 구성은 **데이터(`startingKit.json`)**로 정의한다. 지금은 임시 값으로 넣고 나중에 교체한다.
- 키우기 탭이 생기기 전까지 새 진형·스킬은 **스토리 보상**으로 얻게 할 수 있다 (스텝 데이터에 보상으로 지정).

## 4. 부대 편성 탭

- 보유 장수를 군단 슬롯(기본 3개)에 배치한다.
- 군단마다 소부대 칸 6개에 **보유 부대**를 넣고, 배운 진형 중 하나를 고른다. 칸마다 병력과 합계(장수 한도 대비)가 표시된다.
- 군단마다 **역할**(선봉 / 측면 / 후위)을 고른다. 전투의 [전군 진군]이 이 역할대로 움직인다 ([battle.md](battle.md) 4.3.2).
- **상황별 편성 저장**: 야전·공성·공격·수비 편성을 따로 저장해 둔다. 출진 시 스텝의 전장 유형에 맞는 편성이 자동 선택된다.
- 포로가 된 장수는 편성에서 빠지고 "포로" 표시가 붙는다.

## 4.1 병력 관리 (편성 탭 안)

부대 키우기 탭이 TO-BE이므로 병력 보충은 **편성 탭의 부대 상세 화면**에서 한다.

| 기능 | 내용 |
|---|---|
| 병력 현황 | 부대별 출전 가능 병력 / 부상병(회복까지 남은 시간) / 부대 최대 병력 |
| 징병 | **군량**을 써서 그 부대에 새 병사 보충 (부대 최대 병력까지) |
| 모병 | **돈**을 써서 보충 (군량 소모 없음) |
| 치료 | 징병·모병 비용의 절반으로 부상병 즉시 회복 (군량 또는 돈 중 플레이어 선택) |
| 새 부대 창설 | 기본 병종(T1)을 골라 빈 부대를 만들고 징병·모병으로 채움 (부대 상한까지) |
| 부대 해산 | 부대를 없앰 (병력은 사라짐, 제안) |

- 새로 채운 병사는 훈련도·결속을 낮추지 않는다 (제안). 단 결속을 병력 비율로 희석할지 여부는 결정 필요.
- 비용·속도 수치는 `balance.json` 설정값. 규칙은 [battle.md](battle.md) 2.4.4, 비용 흐름은 [economy.md](economy.md).

## 4. 교체·확장 포인트

| 바꾸고 싶은 것 | 방법 |
|---|---|
| 초기 장수·군량·진형 | `startingKit.json` 수정 |
| 상황별 편성 종류 (야전·공성 …) | 편성 프리셋 목록 데이터 |
| 부대 최대 병력·보유 상한 | `balance.json` |
| 군단 슬롯 수 | 기본 3 (`balance.json`), 스텝별 덮어쓰기 ([battle.md](battle.md) 2.0) |
| 키우기 컨텐츠 연결 | 키우기 탭이 같은 장수·부대 데이터를 바꾸면 편성에 자동 반영 |
