# 메인 화면 (상단 바·하단 탭)

> 상태: 기획 확정 (구현 전) · 범위: Step 1
> 전체 흐름: [../flow.md](../flow.md) · 구조: [../structure.md](../structure.md)(../structure.md) UI 모듈

## 1. 화면 구성

```
┌─────────────────────┐
│ 군량12,000[+] 돈300[+] 💎50 🏪 ⚙│  ← 상단 바: 군량(충전), 설정
├─────────────────────┤
│ ░░░░ 띠 배너 광고 ░░░░ │  ← 상단 바 바로 아래
│                     │
│    선택한 탭의 화면     │
│                     │
├─────────────────────┤
│ 스토리 장수 부대 편성  … │  ← 하단 탭 (추가 가능)
└─────────────────────┘
```

- **하단 탭**이 메인 메뉴다. 세로 화면에서 엄지로 누르기 쉽다.
- **설정**은 하단 탭이 아니라 **상단 톱니바퀴**에서 연다.
- 상단에는 **군량**, **돈**, **뽑기 재화**(💎, 임시)를 표시한다. 군량이 있어야 출진할 수 있고, 돈은 모병·스킬북 등에, 뽑기 재화는 장수 뽑기에 쓴다. [+]와 **상점 아이콘**(🏪)은 상점으로 연결 ([economy.md](economy.md) 3.1).
- **군량 충전 방법**
  - **광고 보기 보상**: [+] 버튼 → 보상형 광고(동영상)를 끝까지 보면 군량 지급. 1회 지급량, 하루 최대 횟수, 재시청 대기시간은 설정값 (추후 결정).
  - 앱 결제 (상점, 추후).
- **띠 배너 광고**: 상단 바 바로 아래, **탭별 화면에서만** 노출. 전투 화면에서는 제거. 광고 제거 상품(영구 5,000원 / 한 달 1,000원)으로 없앨 수 있다. 자세한 규칙은 [ads.md](ads.md).
- 앱을 켜면 **탭 목록의 첫 번째 탭**이 열린다. 지금은 스토리가 첫 번째라 스토리가 열린다. 나중에 순서를 바꾸면 처음 열리는 탭도 바뀐다.

## 2. 탭 목록

| 순서 | 탭 | 상태 | 내용 |
|---|---|---|---|
| 1 | 스토리(단계) | **이번 범위** | 스텝을 차례로 진행. 스텝 선택 → 출진 → 전투 → 결과 |
| 2 | 장수 키우기 | **일부 먼저 열림** | 지금: 스킬북·특성서 사용, 일기토·논쟁 전적 보상. 나중(TO-BE): 세부 성장 컨텐츠 (지략·무력·통솔 …) |
| 3 | 부대 키우기 | **TO-BE** | 특정 컨텐츠로 진형 해금, 병종 승급 등 |
| 4 | 부대 편성 | **이번 범위** | 보유 장수로 군단 구성, 상황별(야전·공성·공격·수비) 편성 저장 |
| 5 | 영토 | **별도 컨텐츠 (기획 중)** | 실제 지역(GPS) 기반 땅따먹기, 지역 단계별 연합 ([territory.md](territory.md)) |
| 6 | 고용 | **서버 도입 후** | 다른 유저가 등록한 장수·부대를 이력 보고 고용, 내 등록 관리 ([hiring.md](hiring.md)) |
| 7 | 대전 | **확장 예정** | 유저 대전 1:1 · N:N ([pvp.md](pvp.md)) |
| - | 설정 (상단) | **이번 범위** | 사운드, 배속 기본값, 전투 패널 자동 접기, **전체 난이도** 등 |

- TO-BE 탭은 하단에 자리를 두고, 누르면 **"준비 중" 화면**을 보여준다 (확정). 숨김으로 바꾸려면 데이터 값만 바꾼다.
- 나중에 상점, 도감 등이 추가될 수 있다. 하단 탭 바는 **가로 스크롤**이다 (확정, "더보기"로 묶지 않는다). 한 화면에 5개까지 보이고 그보다 많으면 밀어서 본다.

## 2.1 개발 중 탭 운영 (2026-11-10 결정)

- **모든 컨텐츠를 하단 탭에 둔다** (확인용): 스토리·장수·장수 키우기(대결)·부대·부대 정비·편성·편성(드래그)·영토·고용 + 모집·도감·녹화·우편·연합·설정 (+ 대전 준비 중). 탭이 많으면 가로 스크롤.
- **기존 화면을 바꿀 때는 원래 것을 고치지 않고 새 버전을 새 탭으로 추가한다** (예: "부대 편성" 옆에 "부대 편성(드래그)"): 기존 탭 클래스를 복사해 새 이름으로 고치고, `MainScreen.Views`에 한 줄 + `Ui/mainTabs.json`에 한 줄.
- 비교해 보고 **채택 안 된 것은 그 클래스와 두 줄을 지우면 끝** (규칙 코드는 화면과 분리되어 있어 건드릴 것이 없다).
- 출시 전에 탭을 다시 줄인다 (상점·우편은 상단 바 등으로 옮기는 안, 6장).

## 2.2 화면 스타일 (UI 1단계 임시, 2026-11-10)

- 색·모서리 둥글기·글자 크기 배율을 **데이터(`data/Ui/styles.json`)**로 둔다. 스타일 하나 = 이름 키 + `cornerRadius` + `fontScale` + 색 13개 (`background`·`bar`·`card`·`button`·`buttonActive` …).
- 지금 스타일: `basic`(기존 화면 그대로, 각진 모서리) · `temp1`(따뜻한 갈색 계열, 둥근 버튼·카드, 글자 0.9배) · `ink`(수묵·한지 시안: 밝은 종이색 바탕, 먹색 글자, 낙관 붉은 강조, 2026-11-11). `default`가 처음 쓰는 스타일.
- 개발 빌드는 설정 화면의 "화면 스타일"에서 바꿔 비교한다 (누르면 다시 시작). 화면 코드는 그대로이고 버튼·카드만 둥근 판을 쓴다.
- 새 스타일 = `styles.json`에 한 묶음 + 이름 문자열. 채택한 것만 남기고 `default`로 정한다. 아트 방향은 **수묵·한지 + 단순 3D 전장**으로 정했다 (2026-11-11, [../art-direction.md](../art-direction.md)).

## 3. 확장 구조 (탭 교체)

- 탭 목록, 순서, 상태(사용 / TO-BE / 숨김), 해금 조건은 **데이터(`mainTabs.json`)**로 정의한다.
- 탭 하나 = 화면 모듈 하나 (`IMainTab` 구현). 새 탭은 모듈을 만들고 데이터에 등록하면 된다.
- 키울 게 생겼을 때 탭에 **알림 표시(빨간 점)**를 띄우는 기능을 공통으로 둔다.
- 장수 키우기의 세부 항목도 데이터(`growthTracks.json`)로 정의할 예정 (TO-BE).

- 실제 파일: `data/Ui/mainTabs.json` (`id`, `nameKey`, `status`). 탭 id → 화면 모듈 등록은 화면 코드(`MainScreen`)에 있고, 등록이 없거나 `tobe`면 "준비 중" 화면.

```json
{
  "tabs": [
    { "id": "story",     "nameKey": "ui.tab.story",     "status": "active" },
    { "id": "general",   "nameKey": "ui.tab.general",   "status": "active" },
    { "id": "troop",     "nameKey": "ui.tab.troop",     "status": "tobe" },
    { "id": "formation", "nameKey": "ui.tab.formation", "status": "active" },
    { "id": "territory", "nameKey": "ui.tab.territory", "status": "tobe" }
  ]
}
```
