# 튜토리얼 (H11 설계 제안)

> 상태: **제안 (사용자 결정 필요)** · 2026-11-20 원격 · 구현은 마지막 배포 전에 따로 (backlog H11)
> 관련: 처음 안내 [story.md](story.md) 7장 (R-62) · 스토리 숨김 [main-screen.md](main-screen.md) (H10) · 스텝 데이터 `data/Steps/step01~03.json` · 전투 사건 `BattleEvents`(EventKinds)

## 0. 왜 · 무엇을

- 스토리 탭을 숨겨서(H10), 새 사용자가 **전투를 처음 배우는 길이 없다**. 지금은 화면을 처음 열 때 나오는 안내 카드(R-62)뿐이다. 이 카드는 읽기만 하고, 해 보게 하지는 않는다.
- 튜토리얼 = **스토리 스텝 3개를 고쳐 쓴 짧은 전투 3판**. 판마다 **한두 가지만 해 보게** 한다. 끝나면 배포 줄 첫 탭(영토)으로 보낸다.
- 새로 만드는 것은 **"할 일 안내"**(전투를 멈추고 → 누를 곳을 가리키고 → 사용자가 그 행동을 하면 다음으로)다. 카드(R-62)는 그대로 쓴다.

## 1. 고른 스텝 · 가르칠 것 (제안)

| 판 | 바탕 스텝 | 왜 이 스텝 | 해 보게 할 것 (순서대로) | 끝나면 |
|---|---|---|---|---|
| **1. 첫 싸움** | step01 (평야 · 낮 · 적 1군단) | 지형 · 날씨 변수가 없어 조작만 배우기 좋다 | ① 내 군단 누르기 → ② 땅 누르기(이동) → ③ 적 군단 누르기(공격) → ④ [전군 진군] → (적 총대장이 무너지면 승리 조건 안내) | 결과 화면에서 보상 · 진형 하나(어린진) 얻기 안내 |
| **2. 숲길 매복** | step02 (숲 · 저녁 · 안개(시야) · 바람 · 적 3) | 시야 · 지형 · 스킬을 처음 보여 주기 좋다 | ① 시야 밖 적은 안 보인다(안개) → ② 숲에 들어가면 숨는다 → ③ 스킬 버튼 쓰기 (복병) → ④ [후퇴] · [진군]으로 적 끌어들이기 | 복병 스킬 · 학익진 얻기 |
| **3. 산길 돌파** | step03 (산길 · 적 2 · 장수 D 합류) | 군단 여럿 · 진형 · 장수 합류로 "키우기"를 이어 준다 | ① 원형 메뉴 → 진형 바꾸기 (횡진) → ② 군단 둘을 따로 움직이기 → ③ 위임(맡기기) 한 번 | **장수 합류** → 편성 탭으로 이어서 "새 장수 군단 꾸리기" 카드(R-62 `tab.formation`) |

- 3판 모두 **편성은 고정**(튜토리얼용 장수 · 병력)이고, 출진 전 화면은 건너뛴다. 곡식은 쓰지 않는다 (지갑에 영향 없음).
- 튜토리얼 판은 **조금 쉽게** 맞춘다 (적 병력 낮춤, 지면 바로 다시). 진행이 막히지 않게 한다.
- 다른 후보: step04(들판의 결전 · 사기 고양 스킬)나 수군 훈련은 튜토리얼에서 빼고 샘플전투에 남긴다. 판은 3개 안이 길이(합계 5~7분)에 맞다.

## 2. 흐름

```
첫 실행 → 로그인 · 약관 → (닉네임) → 튜토리얼 1 → 2 → 3 → 영토 탭 (환영 보상 우편)
                                   └ 언제든 [건너뛰기] → 영토 탭 (보상은 같게)
설정 → [튜토리얼 다시 하기] (보상 없음)
```

- 이미 진행이 있는 계정(지금 사용자 · 테스트 계정)은 튜토리얼을 띄우지 않는다. 설정에서 다시 할 수만 있다.
- 판 사이에는 짧은 대사 장면(17 시안 DialogueScene)을 쓸지 정해야 한다 (에셋이 적게 드는 연출).

## 3. "할 일 안내" 규칙 (새로 만들 것, 규칙 번호는 구현 때)

데이터 `Rules/tutorial.json` (제안 모양):

```json
{
  "stages": [
    { "id": "t1", "step": "step01", "army": "tutorial_army_1", "easier": { "enemyTroopsPct": 70 },
      "hints": [
        { "id": "t1.select", "when": { "type": "start" }, "lineKey": "tutorial.t1.select", "point": "myCorps:0", "pause": true, "until": "selected" },
        { "id": "t1.move", "when": { "type": "after", "hint": "t1.select" }, "lineKey": "tutorial.t1.move", "point": "ground:hill", "pause": true, "until": "command:move" },
        { "id": "t1.attack", "when": { "type": "event", "kind": "enemySighted" }, "lineKey": "tutorial.t1.attack", "point": "enemyCorps:0", "pause": true, "until": "command:attack" }
      ] }
  ]
}
```

- `when`: 판 시작 · 앞 안내 다음 · 전투 사건(`EventKinds`, 예: `ambushSprung` · `moraleCritical` · `hiddenFound`) · 시각(초). "처음 적이 보임"(`enemySighted`)은 지금 사건에 없어 새로 더한다 (화면 표시용, 전투 계산 무관).
- `until`: 사용자가 해야 할 행동 (군단 고름 · 명령 종류 · 스킬 · 진형 바꿈 · 위임). 한 뒤에야 다음 안내로 간다. `pause`면 그동안 전투를 멈춘다 (지금 R-62 전투 카드와 같은 멈춤).
- `point`: 화면이 가리킬 곳 (내 군단 n번 · 적 군단 · 지형 지점 · 버튼 id). 가리키는 그림(손가락 · 테두리)은 데스크탑 공통 부품.
- **전투 계산에는 들어가지 않는다.** 안내는 화면이 명령을 막고 기다리는 것뿐이고, 실제 명령은 평소 명령과 같다. 그래서 녹화 · 서버 검증(R-40)이 그대로 맞는다.
- 진행 기록: 세이브에 `TutorialDone`(끝냄 · 건너뜀)과 지금 판. 행동 `tutorial.finish` / `tutorial.skip` → 서버는 처음 한 번만 환영 보상 우편을 보낸다.

## 4. 처음 안내(R-62)와 잇기

- 카드 안내는 그대로 쓴다. 튜토리얼과 겹치는 것만 정리한다.
  - `welcome`(스토리 탭): 스토리가 숨겨져서 이제 안 나온다. → 튜토리얼 1 시작 대사로 옮긴다.
  - `step` · `battle`(출진 전 · 첫 전투): 튜토리얼이 같은 내용을 해 보며 가르친다. → 튜토리얼을 끝내거나 건너뛰면 **본 것으로 표시**해서 두 번 나오지 않게 한다 (`guide.seen` 두 번).
  - `formation` · `care` · `general` · `practice`: 그대로 둔다. 튜토리얼 3이 편성 탭으로 보내면 `formation` 카드가 이어서 나온다.
- 영토 탭에 첫 카드 `tab.territory`를 새로 둔다 (깃발 꽂기 · 수입). 튜토리얼이 끝나고 처음 보는 화면이기 때문이다.
- [안내 다시 보기](`guide.reset`)는 카드만 다시 보여 준다. 튜토리얼 다시 하기는 따로 둔다.

## 5. 사용자가 정할 것

1. 스텝 3개를 이대로 할지 (1 첫 싸움 · 2 숲길 매복 · 3 산길 돌파), 판마다 가르칠 것.
2. **건너뛰기를 둘지**, 건너뛰어도 같은 보상을 줄지 (제안: 둔다, 같은 보상).
3. 환영 보상 (예: 곡식 · 엽전 · 금괴 조금, 수치는 임시값).
4. 판 사이 대사 장면을 넣을지, 스텝 이름 "(임시)"를 바꿀지.
5. 지금 계정(이미 진행 있음)에 튜토리얼을 띄우지 않는 것.
