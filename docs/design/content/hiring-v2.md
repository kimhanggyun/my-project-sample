## 0. 한 줄 요약

**용병 = 플레이어 자신.** 등록할 수 있는 건 **닉네임 장수**와 **그 장수가 직접 이끄는 부대**뿐이다. 빌리는 사람은 **장수+부대 · 장수만 · 부대만**으로 빌린다. 용병 주인의 땅을 치는 데 쓰면 **첫 교전 직후 배신**한다 (고용비는 돌려받음).

## 1. 지금 → 바뀌는 것

| 항목 | 지금 (hiring.md) | 바뀜 |
|---|---|---|
| 탭 이름 | 고용 | **용병** (용병 고용 · 내 용병 등록) |
| 등록할 수 있는 장수 | 내 장수 아무나 (각 3개까지) | **닉네임 장수 하나** |
| 등록할 수 있는 부대 | 내 부대 아무나 | **닉네임 장수가 직접 이끄는 부대** (기본 편성에서 그 장수의 군단 병력) |
| 등록 불가 | — | 닉네임 장수가 **영토 깃발에 나가 있으면** ([territory-v2.md](territory-v2.md) 2.1) |
| 빌리는 단위 | 장수 / 부대 따로 | **장수+부대**(그대로, 손발 맞음) · **장수만**(내 병력을 맡김) · **부대만**(병종 하나 골라 인원, 내 군단 빈 병종 칸) |
| 같은 장수 겹침 | 이미 가진 정의 장수는 고용 막음 | 닉네임 장수는 유저마다 하나라 겹치지 않음 |
| 우편함 | 고용 탭 버튼 | 자원 바 편지 아이콘 (08) |

## 2. 닉네임 장수

- 닉네임을 정할 때 생긴다 (초상 고르기). 이름 = 닉네임.
- **다른 장수와 같은 성장 규칙** (레벨 · 능력치 · 스킬 · 특성 · 진형 숙련, [general-growth.md](general-growth.md)). 장수 탭 맨 앞.
- 편성 · 영토 깃발 · 용병 어디에나 쓴다. 단 영토 깃발에 나가 있는 동안은 용병 등록 불가.

## 3. 등록 · 고용

- 등록 = 그때 모습의 **스냅샷** (지금과 같음). [지금 모습으로 다시 등록]으로 갱신, 이력은 이어짐.
- 가격: 장수 1회 · 병사 1명, 자원 돈/군량, 추천가 + 최대 2배 (hiring.md 3.1 유지).
- [부대도 등록] 끄면 장수만 등록.
- 고용: 다음 전투 1회 편성에 "(고용)"으로 들어간다. 부대 인원 최대 = 내 군량 · 장수 통솔 중 작은 쪽 (hiring.md 2.2 유지). 하루 고용 수 · 대기 시간 (R-44 유지).
- 결과는 원본에 영향 없음, 이력에만 (유지).

## 4. 배신

| 항목 | 규칙 |
|---|---|
| 조건 | 용병을 넣은 편성으로 **용병 주인 본인의 영토 깃발**을 치는 공성전에 나감 (연합원 깃발은 아님) |
| 시점 | 우리 편이 **처음 적과 교전하는 순간** (첫 교전 직후) 용병 부대가 적 편이 된다. 그 뒤 적 AI가 지휘 |
| 알림 | 전장 위 알림 "⚠ 용병 ○○이 배신했습니다!" + 용병 장수 말풍선, 부대 표시 적 색 |
| 고용비 | 배신이 일어나면 **결과 화면에서 전액 돌려받음**. 첫 교전 없이 끝나 배신이 없으면 보통 고용과 같음 |
| 원본 | 용병 주인의 장수 · 병력에 영향 없음 (용병 규칙과 같음) |
| 이력 | "배신" 횟수를 따로 남김 |
| 미리 알기 | 기본은 **숨김** (확인 창 없음). **내 닉네임 장수에게 스킬 반간(counterIntrigue)** 이 있으면 출진 직전에 낌새 창: "수상한 용병이 있습니다" — [용병 빼고 출진] [그대로 출진] [취소]. 스킬이 없어도 깃발 주인과 용병 닉네임이 같은 건 볼 수 있다 |

- 전투 규칙: 시드로 결정되는 이벤트 (첫 교전 틱에 팀 바꿈) — 서버 재현과 같음.
