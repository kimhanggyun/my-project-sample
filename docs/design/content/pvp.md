# 유저 대전 (1:1 · N:N) — 확장

> 상태: **확장 예정** — 지금 만들지는 않지만, 나중에 붙일 수 있게 **구조를 미리 맞춘다**.
> 전체 흐름: [../flow.md](../flow.md) · 전투 규칙: [battle.md](battle.md) · 구조: [../structure.md](../structure.md) 3.4

---

## 1. 목표

- 유저끼리 대전할 수 있다.
  - **1:1**: 유저 한 명 대 한 명.
  - **N:N**: 여러 유저가 한 팀이 되어 다른 팀과 싸운다 (예: 2:2, 3:3).
- 같은 전투 규칙을 쓴다. 대전 전용으로 바꿀 규칙은 **대전 규칙 세트**(데이터)로 덮어쓴다.

---

## 2. 대전 방식 (후보)

| 방식 | 설명 | 장점 | 어려움 |
|---|---|---|---|
| **비동기 대전** | 상대가 미리 저장한 **방어 편성**을 AI가 지휘. 상대는 접속하지 않아도 됨 | 만들기 쉬움, 서버 재현 검증 그대로 사용 | 실시간 손맛은 없음 |
| **실시간 1:1** | 두 유저가 동시에 접속해 각자 지휘 | 진짜 대결 | 네트워크 동기화, 접속 끊김 처리 |
| **실시간 N:N** | 팀원 각자가 자기 군단을 지휘 | 협동·대규모 전투 | 위 + 팀 내 역할·소통 |

- 제안: **비동기 대전 → 실시간 1:1 → 실시간 N:N** 순서로 확장.

---

## 3. 지금부터 맞춰 둘 구조 (확장 대비)

나중에 대전을 붙일 때 전투 코드를 갈아엎지 않도록, 처음부터 다음을 지킨다.

| 요구사항 | 내용 |
|---|---|
| **진영 → 팀 일반화** | 전투는 "아군·적군 2개"가 아니라 **팀 N개**를 다룬다. 지금 스토리 전투는 팀 2개(플레이어 팀, 적 팀)인 특별한 경우다 |
| **군단 소유자** | 군단마다 **소유자**(어느 유저)와 **지휘 주체**를 기록한다 |
| **지휘 주체 분리** | 군단을 누가 지휘하는지를 갈아 끼울 수 있게: 이 기기의 플레이어 / 원격 플레이어(네트워크) / AI / 위임 / 리플레이 |
| **명령은 한 통로로** | 모든 명령은 "명령 기록"을 거쳐 시간(틱)과 함께 들어간다. 터치·네트워크·AI·리플레이가 모두 같은 통로를 쓴다 |
| **결정적 계산** | 같은 입력이면 **모든 기기에서** 같은 결과. 실시간 대전은 각 기기가 명령만 주고받고 같은 계산을 돌리는 방식(락스텝)을 쓰므로 필수 |
| **팀별 시야** | 전장 안개는 팀 단위로 공유 (지금의 "아군 전체 공유"가 팀 공유로 일반화) |
| **팀별 승패** | 승패 조건이 팀 단위로 판정된다 (마지막 남은 팀, 대장 포로, 군량 등) |
| **시간 조작 규칙** | 일시정지·배속은 규칙 세트로 제어 (스토리: 허용 / 실시간 대전: 불가 또는 합의) |
| **대전 규칙 세트** | 대전 모드별로 덮어쓸 값: 일시정지·배속, 사망·부상 반영 여부, 포로 처리, 군량 소비, 레벨 보정 등 |

## 4. 대전에서 정할 규칙 (미결)

| 항목 | 질문 |
|---|---|
| 손실 반영 | 대전에서 죽은 병사·부상이 실제 병력에 반영되나? (제안: 반영 안 함 또는 일부만) |
| 포로 | 대전에서 장수가 포로가 되면 실제 포로가 되나? (제안: 그 전투 안에서만) |
| 군량 | 대전 참가에 군량이 드나? 전투 중 군량 소비는? |
| 고용 장수·부대 | 대전에서 고용분을 쓸 수 있나? |
| 레벨 보정 | 능력치를 맞춰주는 공정 모드를 둘까? |
| 매칭 | 전투력·랭크 기준 매칭 |
| 랭킹·보상 | 점수(레이팅), 시즌, 보상 |
| 팀 구성 (N:N) | 친구 초대 / 자동 매칭, 팀당 인원, 한 유저가 맡는 군단 수 |
| 끊김 처리 | 접속이 끊긴 유저의 군단은 AI(위임)로 전환 |
| 화면 | 세로 화면에서 N:N 전장을 어떻게 보여줄지 (팀원 군단 표시, 핑·신호) |

---

## 5. 서버 요구사항

| 방식 | 필요한 것 |
|---|---|
| 비동기 대전 | 방어 편성 저장, 상대 검색, 결과 서버 재현 검증 (고용 이력과 같은 방식) |
| 실시간 대전 | 매칭, 실시간 명령 중계, 결과 검증, 끊김 처리 |

- 구현 후보는 엔진별 구현 문서에 둔다 ([../../impl/unity/decisions.md](../../impl/unity/decisions.md)).
