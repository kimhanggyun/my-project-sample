# 스킬 체계

> 상태: 설계 뼈대 (수치 미정) · 개발은 단계별로 순차 추가 (6장)
> 관련: [battle.md](battle.md) 2.8(사용 제한), 2.17(바람·날씨·화계), 2.18(복병·간파), 4.2(대상 지정), 4.4(장수 말풍선) · [troops.md](troops.md) · [formations.md](formations.md)
> 스킬 이름은 현재 테마(옛날 전투) 기준. 데이터는 영문 id. 수치(비용·횟수)는 모두 예시.

---

## 1. 설계 원칙

1. **모든 스킬에는 반격 수단이 있다.** 다른 스킬, 진형, 병종, 지형, 날씨 중 하나 이상으로 막을 수 있어야 한다 (영원한 승자 없음).
2. **발동 → 대응 시간 → 효과.** 큰 스킬은 바로 터지지 않고 **전조**가 있다 (불길이 번지기 시작, 둑이 흔들림, 산 위 돌무더기). 상대가 피하거나 막을 짧은 틈을 준다. 단, 은신 스킬(복병)은 전조 대신 **준비 시간**이 있다.
3. **스킬마다 하나의 역할만 강하게.** 한 스킬로 전투가 끝나지 않게 한다. 여러 스킬을 섞어 써야 이긴다.
4. **사용 제한은 공통**: 책략 점수(= 지략) + 스킬 비용 + 전투당 횟수 + 발동 조건 ([battle.md](battle.md) 2.8). 실패·취소해도 소모.
5. **계열별 요구 능력치**: 계략은 지략, 지휘는 통솔, 용맹은 무력을 요구한다. 그래서 무력형·통솔형 장수도 쓸 스킬이 있다.
   - 비용은 모두 책략 점수(= 지략)에서 낸다. 대신 **용맹·지휘 계열은 비용이 싸다** → 지략이 낮은 장수도 몇 번은 쓴다.
6. **병종·지형·날씨와 엮인다**: 일부 스킬은 특정 병종(궁병, 공병, 투석기 등)이 군단에 있어야 하고, 지형·날씨 조건이 맞아야 한다.
7. **단계는 습득 순서**: 초급 → 중급 → 고급. 고급이 무조건 강한 것은 아니다.

## 2. 계열

| 계열 | 역할 | 주 요구 능력치 | 대표 스킬 |
|---|---|---|---|
| **화공** | 불로 지형과 부대를 태움 | 지략 | 화계, 화전 일제사격 |
| **지형·공작** | 물·돌·함정·구조물로 지형을 바꿈 | 지략 (일부 공병 필요) | 수공, 낙석, 함정, 목책, 다리 파괴 |
| **정보·은신** | 숨기·찾기·속이기 | 지략 | 복병, 간파, 척후 파견, 위장 깃발, 은밀 행군 |
| **교란** | 적의 판단·지휘를 흔듦 | 지략 | 혼란, 도발, 이간, 거짓 퇴각, 유언비어 |
| **대(對)계략** | 적 계략을 막거나 되돌림 | 지략 | 반간 |
| **지휘** | 아군 대형·사기 관리 | 통솔 | 고무, 재정비, 진형 급변, 철벽, 강행군 |
| **용맹** | 장수가 앞장서 기세를 올림 | 무력 | 돌격 함성, 선두 돌파, 일기토 신청 |
| **원거리** | 궁병·공성 병기 화력 집중 | 지략 또는 통솔 | 화살비, 집중 사격, 집중 포격 |
| **보급** | 군량 싸움 | 지략 | 군량 습격, 군량 보급 |
| **회복** | 병력 손실 줄이기 | 지략 | 응급 치료 |

## 3. 스킬 목록

열: 단계(초·중·고) · 요구 · 비용(예) · 횟수(예) · 대상 · 조건·준비 · 효과 · **반격 수단**

### 3.1 화공

| 스킬 | id | 단계 | 요구 | 비용 | 횟수 | 대상 | 조건·준비 | 효과 | 반격 수단 |
|---|---|---|---|---|---|---|---|---|---|
| 화계 | `fireAttack` | 중 | 지략 50 | 40 | 1 | 지점 (숲) | 바람 있음, 비 아님. 전조: 불씨가 번지기 시작 | 바람 방향으로 숲을 태움(지형 변화), 지나는 칸 피해, 숨은 복병 노출 | 바람 읽고 이동, 강·불탄 땅으로 피함, 비, 산개진 |
| 화전 일제사격 | `fireVolley` | 초 | 지략 30 + **화궁병** | 20 | 2 | 지점 | 비 아님 | 작은 범위 점화 + 화살 피해, `flammable` 추가 피해 | 방패병, 산개진, 비 |

|---|---|---|---|---|---|---|---|---|---|

|---|---|---|---|---|---|---|---|---|---|

## 4. 스킬 상성 요약

| 이 스킬을 | 이렇게 막는다 |
|---|---|
| 복병, 함정, 은밀 행군 | 간파, 화계, 첨병 |
| 간파 | 위장 깃발 (간파를 낭비시킴) |
| 화계, 화전 | 비, 바람 반대로 이동, 산개진, 강 |
| 수공, 낙석 | 전조 보고 피하기, 고지·둑 선점 |
| 교란 (혼란·이간·도발·유언비어) | 반간, 재정비, 고무, 높은 규율·결속 |
| 반간 | 교란 대신 화공·지형 계열로 공격 |
| 돌격 함성, 선두 돌파 | 창병, 방원진, 철벽, 집중 사격 |
| 철벽 | 우회, 화살비, 집중 포격 |
| 화살비, 집중 포격 | 산개진, 방패병, 기병 기습 |
| 군량 습격 | 후위 배치, 빠른 결전 |

## 5. 데이터 예시

```json
{
  "id": "rockfall",
  "nameKey": "skill.rockfall",
  "category": "terrain",
  "tier": "intermediate",
  "requires": [{ "type": "statAtLeast", "stat": "intellect", "value": 50 }],
  "cost": 30,
  "usesPerBattle": 1,
  "target": { "type": "area", "range": 12, "radius": 3 },
  "conditions": [{ "type": "terrainBelow", "value": "narrowPath" }, { "type": "ownHighGround" }],
  "telegraphSec": 2.0,
  "effects": [
    { "type": "damage", "base": 20, "scaleStat": "intellect" },
    { "type": "status", "status": "confusion", "ratio": 0.3, "durationSec": 4 },
    { "type": "terrainChange", "to": "blockedPath", "durationSec": 20 }
  ],
  "speech": "speech.skill.rockfall"
}
```

- `telegraphSec`: 전조 시간 (대응 틈).
- `speech`: 장수 말풍선 외침 ([battle.md](battle.md) 4.4).

## 6. 개발 순서

| 단계 | 스킬 | 이유 |
|---|---|---|
| **1차** | 간파, 복병, 화계, 화살비, 고무, 재정비, 돌격 함성, 도발 | 핵심 상호작용 (은신↔간파, 화공↔바람, 교란↔지휘) |
| **2차** | 함정, 낙석, 위장 깃발, 척후 파견, 혼란, 거짓 퇴각, 철벽, 진형 급변, 집중 사격, 화전 일제사격 | 지형·정보 싸움 깊이 |
| **3차** | 수공, 목책, 다리 파괴, 집중 포격, 이간, 유언비어, 반간, 선두 돌파, 일기토 신청, 강행군, 은밀 행군 | 공병·투석기·성새전, 고급 계략 |
| **4차** | 군량 습격, 군량 보급, 응급 치료, 수상전 스킬(화선 등) | 보급전, 확장 전장 |
