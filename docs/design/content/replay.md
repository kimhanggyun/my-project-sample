# 전투 녹화 · 공유 (공략)

> 상태: 2차 구현 — 녹화 저장·내 녹화 목록·재생(일시정지·배속·아군/적군 시점·안개 끄기)·버전 확인 (R-54), **공략 공유** (R-81). 영상 저장(네이티브 녹화 필요)은 이어서
> 전체 흐름: [../flow.md](../flow.md) · 관련: [story.md](story.md), [hiring.md](hiring.md), [battle.md](battle.md) · 구조: [../structure.md](../structure.md)

---

## 1. 목적

- 전투를 **녹화**해서 다시 볼 수 있다.
- 녹화한 전투를 **다른 유저에게 공유**해서 공략 정보로 쓰게 한다.
- 별점(★) 평가는 두지 않는다.

---

## 2. 녹화 방식: 영상이 아니라 "전투 기록"

전투는 같은 입력이면 같은 결과가 나오게 설계되어 있다. 그래서 영상 파일 대신 **전투 기록**만 저장하면 똑같이 다시 재생할 수 있다.

| 저장하는 것 | 내용 |
|---|---|
| 전투 설정 | 스텝, 맵, 양쪽 편성, 시드, 규칙 세트 |
| 명령 기록 | 언제(틱) 어떤 군단에 어떤 명령을 내렸는지 |
| 버전 | 규칙·데이터 버전 (아래 4장) |

| 비교 | 전투 기록 (채택) | 영상 파일 |
|---|---|---|
| 크기 | 매우 작음 (수십 KB 수준) | 큼 (수십 MB) |
| 재생 | 게임 안에서 3D로 재생, 카메라 자유 이동, 배속 | 정해진 화면만 |
| 공유 | 서버에 가볍게 저장 | 저장·전송 비용 큼 |
| 게임 밖 공유 | 불가 (게임이 있어야 재생) | 가능 |

- 두 가지를 함께 쓴다 (확정):
  - **게임 안 공유 = 전투 기록.** 가볍고 3D로 자유롭게 볼 수 있다.
  - **게임 밖 공유 = 영상.** 전투 영상을 기기에 저장하고 메신저·SNS·영상 사이트로 공유한다 (2.1).

### 2.1 영상 저장·공유

- 결과 화면이나 녹화 재생 화면에서 **"영상으로 저장"** → 기기 사진첩(갤러리)에 영상 파일(mp4)로 저장.
- 저장 후 **"공유"** → 폰의 공유 창(카카오톡, 유튜브, SNS 등)으로 바로 보낸다.
- 영상은 **전투 기록을 재생하면서 만든다.** 그래서 전투 중에 녹화 버튼을 누르지 않아도, 끝난 뒤 원하는 전투를 골라 영상으로 만들 수 있다.
  - 영상 길이·화질은 선택 (예: 전체 / 하이라이트, 720p / 1080p).
  - 카메라는 자동 연출(교전 따라가기) 또는 재생 중 사용자가 움직인 대로.
- 영상은 **우리 서버에 올리지 않는다** (용량·비용이 큼). 게임 안 공략 공유는 전투 기록으로 한다.
- 영상 구석에 게임 로고·이름을 넣는다 (홍보 효과).
- 사진첩 저장 권한을 요청한다 (안드로이드·아이폰).

---

## 3. 화면과 흐름

**녹화**
- 모든 전투는 자동으로 기록된다. 결과 화면에서 **"녹화 저장"**을 누르면 내 녹화 목록에 남는다 (저장 개수 제한 설정값).

**재생**
- 내 녹화 목록 / 공유된 공략에서 재생.
- 재생 중: 일시정지, 배속, 카메라 자유 이동, 아군·적군 시점 전환, 안개 끄고 보기.

**공유 (공략)**
- 결과 화면이나 내 녹화 목록에서 **"공략으로 공유"** → 서버에 올림.
- 스텝 정보 화면에 **"공략 보기"** → 그 스텝의 공유된 녹화 목록.
  - 정렬: 최신, 인기(조회·추천), 적은 손실, 빠른 승리.
  - 표시: 작성자 닉네임, 편성 요약(장수 능력치·병종·진형), 결과(손실·시간).
- 공략을 보고 추천할 수 있다.
- 고용 이력([hiring.md](hiring.md))에서 그 장수·부대가 쓰인 전투를 **바로 재생**할 수 있다 (고용 판단에 도움).

---

## 4. 버전 호환

- **스텝별 적군 밸런스는 출시 후 고정**한다 (확정). 개발 중 밸런스 조정 기간에만 바뀐다.
- 다만 공통 규칙(병종 상성, 보정값 등)을 출시 후 수정하면 모든 스텝의 예전 기록이 영향을 받는다. 대비책:
  - 기록에 **규칙·데이터 버전**을 함께 저장한다.
  - 출시 후 규칙이 바뀌면 **예전 버전 규칙 데이터를 보관**해 두고, 예전 기록은 그 규칙으로 재생한다 (규칙 데이터는 JSON이라 보관 비용이 작다).
  - 개발 중 기록은 버전이 다르면 재생 불가로 표시해도 된다.
- 영상은 이미 그려진 화면이라 버전과 무관하게 항상 볼 수 있다.

## 7. 지금 구현 (1차)

| 부분 | 내용 |
|---|---|
| 기록 | `ReplayRecord` (Game.Flow/Replay.cs): 스텝 id, 전투 설정(스텝 규칙을 뺀 것), 명령 기록, 결과 요약(승패·시간·손실), 결과 지문 |
| 버전 | 따로 버전 번호를 두지 않고 **지금 데이터로 한 번 돌려 결과 지문을 비교**한다. 같으면 재생, 다르면 "다시 볼 수 없음" (4장의 "개발 중 기록은 재생 불가로 표시"). 예전 규칙 데이터 보관은 출시 후 |
| 저장 | 기기 저장소 `replays` 키 (세이브와 따로). 결과 화면 [녹화 저장], 스토리 탭 [내 녹화] |
| 공유 (R-81) | 내 녹화 [공략 공유] → 서버가 **지금 규칙으로 다시 돌려 결과 지문이 같을 때만** 받는다 (고친 녹화·옛 규칙 녹화 거절). 같은 사람이 같은 녹화를 또 올리면 하나만. 서버는 게임마다 `sharedStoreMax`(500)개, 넘으면 오래된 것부터 지움 |
| 공략 보기 (R-81) | 출진 전 화면 [공략 보기] → 그 스텝의 공유 녹화: **이긴 것 → 손실률 낮은 것 → 짧은 것 → 최근 것** 순으로 `sharedListMax`(20)개, 올린 사람 닉네임. [보기]는 받아서 지금 규칙으로 확인한 뒤 재생 (다르면 "다시 볼 수 없음"). 서버 없음(off)이면 버튼이 없고, 가짜 서버(fake)는 기기 메모리에서 같은 규칙 |
| 재생 | 전투 화면을 재생 모드로: 명령 패널·군단 카드 숨김, 화면 입력 안 받음, 일시정지·배속·카메라 이동은 그대로. 위 막대 [적군 시점]/[아군 시점]·[안개 끄기]/[안개 켜기] — 같은 전투를 이어서 보기만 바꾼다 (시야·AI 규칙은 그대로) |
- [x] 영상 저장·공유 → 전투 기록을 재생하며 영상 생성, 사진첩 저장, 폰 공유 창으로 공유
- [ ] 영상 화질·길이 선택지, 하이라이트 자동 편집 여부
- [ ] 공략 신고·관리 (부적절한 닉네임 등)
