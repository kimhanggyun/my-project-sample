# 장수 성향 · 특성

> 상태: 설계 뼈대 (수치 미정) · 개발은 단계별로 순차 추가 (6장)
> 관련: [generals.md](generals.md)(장수 데이터·등급), [battle.md](battle.md) 2.5(사기·퇴각), 2.6(능력치·지휘), 2.7(일기토·논쟁), [ai.md](ai.md)(AI 성향), [general-growth.md](general-growth.md)(보상 규칙)
> 이름은 현재 테마 기준. 데이터는 영문 id. 수치는 모두 예시.

---

## 1. 성향과 특성의 차이

| | 성향 | 특성 |
|---|---|---|
| 개수 | 장수마다 **1개** | 장수마다 **여러 개** (등급별 칸 수) |
| 무엇을 바꾸나 | **판단 방식**: 퇴각 시점, AI 행동 경향, 일기토·논쟁 응답, 위임 시 지휘 스타일 | **수치 보정**: 특정 조건에서 공격·방어·사기·시야·스킬 등 가산 |
| 바뀌나 | 거의 안 바뀜 (타고남) | 장수 키우기·보상으로 얻거나 강화 |
| 예 | 용맹, 신중 | 숲의 달인, 야습, 화공 전문가 |

## 2. 성향 (7종)

| 성향 | id | 퇴각 시점 | 일기토 | 논쟁 | AI·위임 경향 | 사기 |
|---|---|---|---|---|---|---|
| **용맹** | `brave` | 매우 늦음 | 잘 응함, 공격·필살 위주 | 잘 거절 | 돌격·진군 우선 | 승리 시 크게 오름, 패배에 둔감 |
| **냉정** | `calm` | 보통 | 상황 봐서 | 상황 봐서 | 상성·지형 계산 우선 | 잘 흔들리지 않음 |
| **신중** | `cautious` | 이름 | 잘 거절, 회피·퇴각 위주 | 응함 | 정찰·간파 먼저, 불리하면 물러남 | 보통 |
| **교활** | `cunning` | 보통 | 거절 | 잘 응함, 조롱·세뇌 위주 | 매복·유인·교란 선호 | 보통 |
| **충직** | `loyal` | 늦음 (아군 대장이 위험하면 버팀) | 보통 | 보통 | 아군 지원·협공 우선 | 아군이 무너져도 덜 떨어짐 |
| **오만** | `arrogant` | 늦음 | 무조건 응함 | 무조건 응함 | 정면 승부, 정찰 소홀 | 높게 시작, 패배하면 급락 |
| **소심** | `timid` | 매우 이름 | 거의 거절 | 거절 | 수비·후위 선호 | 낮게 시작, 기습에 취약 |

- 성향은 **좋고 나쁨이 아니라 성격**이다. 예: 소심한 장수는 쉽게 물러나지만 그만큼 포로가 될 일이 적다.
- 성향은 [ai.md](ai.md)의 군단 AI 성향, [battle.md](battle.md) 2.5.1의 퇴각 판단, 2.7의 대결 AI에 그대로 쓰인다.

**고유 (전설 장수 전용)**

### 3.3 특성 규칙

- 특성 효과는 모두 **가산 보정**으로 들어가고, 보정 합계 상한이 적용된다 ([battle.md](battle.md) 2.4.2).
- 같은 계열 특성이 겹치면 효과를 줄인다 (예: 두 번째부터 절반, 설정값).
- 일부 특성은 **단점이 섞여 있다** (성급, 대기만성). 사이드그레이드 원칙.
- 특성은 **데이터**(`traits.json`)로 정의한다. 새 특성은 보정 묶음을 데이터로 추가한다.

## 4. 특성 얻기

| 방법 | 내용 |
|---|---|
| 기본 특성 | 장수마다 처음부터 가진 특성 (뽑기로 얻은 장수 포함) |
| 장수 키우기 | 성장 보상 규칙으로 얻음 (예: 일기토 승패 차 50 이상 → 맹장, [general-growth.md](general-growth.md) 2.3) |
| **특성서** (확정) | 스킬북처럼 상점에서 구매해 장수 키우기에서 칸에 넣음 |
| 강화 (제안) | 같은 특성을 다시 얻으면 단계↑ (예: 숲의 달인 Ⅰ → Ⅱ) |

- 특성 칸이 차면 교체한다. 기본 특성·고유 특성은 지울 수 없다 (제안).

## 5. 데이터 예시

```json
{
  "id": "forestMaster",
  "nameKey": "trait.forestMaster",
  "category": "terrain",
  "rarity": "rare",
  "modifiers": [
    { "when": { "terrain": "forest" }, "stat": "moveSpeed", "addPct": 10 },
    { "when": { "terrain": "forest" }, "combat": "attack", "addPp": 5 },
    { "when": { "terrain": "forest" }, "skill": "ambush", "setupSecPct": -20 }
  ],
  "stackGroup": "terrain_forest"
}
```

```json
{
  "id": "cautious",
  "nameKey": "temperament.cautious",
  "retreatThreshold": 0.35,
  "duel": { "accept": 0.2, "bias": { "dodge": 1.5, "retreat": 1.5 } },
  "debate": { "accept": 0.7 },
  "ai": { "scoutFirst": true, "preferRetreatWhenLosing": true }
}
```

## 6. 개발 순서

| 단계 | 내용 |
|---|---|
| **1차** | 성향 7종 (퇴각·대결·AI 경향), 특성 약 12종 (맹장, 철벽, 군기, 명령 전달, 화공 전문가, 매복의 달인, 간파의 눈, 책략가, 숲의 달인, 산악 전문가, 기병 지휘, 궁병 지휘) |
| **2차** | 날씨·시간, 대결, 보급·회복 특성, 진형 숙련 |
| **3차** | 고유 특성, 특성서·강화, 공성·수상전 특성 |
