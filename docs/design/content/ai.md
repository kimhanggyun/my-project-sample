# 적 AI와 난이도

## 1. 원칙

1. **AI도 플레이어와 같은 규칙을 쓴다 (반칙 없음).**
   - 보이는 것만 안다: 전장 안개, 팀 시야, 마지막 목격 위치.
   - 같은 제한: 책략 점수, 스킬 비용·횟수, 군량, 지형 규칙.
   - 같은 명령: 진군·대기·이동·스킬·진형·후퇴 등 플레이어와 같은 명령을 내린다. 명령 기록을 거치므로 리플레이·서버 재현에서 그대로 재현된다.
2. **난이도는 "판단의 질"로 조절한다.** 능력치를 몰래 올리지 않는다. 반응 속도, 상성 대응, 스킬 활용, 협공 같은 판단 수준이 달라진다.
   - 스토리 난이도를 위해 적 능력치를 올리고 싶으면 **스텝 데이터에서 명시적으로** 한다 (AI와 분리).
3. **결정적이다.** AI의 무작위 판단도 고정 시드 난수를 쓴다 (리플레이·대전·서버 재현).
4. **AI 성향은 데이터다.** 장수마다 성향을 정하고, 스텝마다 작전을 정한다. 새 행동은 추가형이다.

## 2. AI 계층

```
사령관 AI (팀 전체)      작전 방침, 군단별 역할·목표, 전군 진군·협공 시점
   └─ 군단 AI (군단마다)   군단 명령 선택: 진군·대기·이동·공격·스킬·진형·후퇴
        ├─ 장수 판단       스킬 사용, 일기토·논쟁 응답·선택, 퇴각 판단
        └─ 소부대 AI       대상 고르기, 빈 곳 메우기 (battle.md 2.2.2, 이미 정의)
```

| 계층 | 하는 일 | 같은 일을 플레이어가 할 때 |
|---|---|---|
| 사령관 AI | 전체 작전을 정하고 군단에 역할·목표를 나눔 | 플레이어 자신 |
| 군단 AI | 군단 명령을 고름 | 플레이어가 내리는 명령 |
| 장수 판단 | 스킬·대결·퇴각 판단 | 플레이어 선택 / 장수 말풍선 응답 |
| 소부대 AI | 교전 세부 행동 | 플레이어도 맡김 (자율 판단) |

## 3. 판단 방식: 점수 매기기

- 각 계층은 할 수 있는 행동마다 **점수**를 매기고 가장 높은 행동을 고른다 (소부대 자율 판단과 같은 방식).
- 점수에 쓰는 정보 (보이는 것만):

| 정보 | 예 |
|---|---|
| 병력·사기 비교 | 내가 우세하면 공격 점수↑ |
| 상성 | 상대 진형·병종에 유리한 진형·대상이면 점수↑ |
| 지형 | 숲(복병), 고지, 좁은 길, 성벽 |
| 바람·날씨 | 순풍·건조하면 화계 점수↑, 비면 화계 점수 0 |
| 군량 | 부족하면 결전 또는 퇴각 점수↑ |
| 책략 점수·스킬 횟수 | 남은 자원 대비 효과 |
| 위협 | 포위 위험, 장수 노출 |

- 새 판단 행동은 행동 클래스를 추가하고 등록하면 붙는다.

## 4. 사령관 AI: 작전 방침

스텝 데이터에서 적 사령관의 **작전 방침**을 고른다. 전투 중 상황에 따라 다음 방침으로 바뀔 수 있다 (페이즈).

| 작전 방침 | 내용 |
|---|---|
| 총공격 | 전 군단 진군, 가장 가까운 적부터 (멀면 자기 줄로 곧게 다가가다가 aiEngageCells 안에서 공격, R-65) |
| 수비 | 지정 구역·성을 지키고, 들어오는 적만 상대 |
| 지구전 | 직접 싸움을 피하고 버텨서 상대 군량 소진을 노림 |
| 유인 매복 | 한 군단이 끌어내고(도발·거짓 퇴각) 숨은 군단이 기습 |
| 측면 포위 | 정면을 붙잡아 두고 기병으로 측면·배후 공략 |
| 정찰 후 대응 | 간파·척후로 상대 구성을 먼저 확인하고 상성 진형으로 대응 |

- **역할 배분**: 선봉·측면·후위·매복·예비대.
- **협공**: 여러 군단을 맞춰 동시 공격 (플레이어의 협공 대기와 같은 규칙).
- **페이즈 전환 조건 (예)**: 병력 비율, 시간(주차), 특정 군단 격파, 군량 잔량.

## 5. 군단 AI: 성향

장수(또는 스텝의 군단 설정)마다 성향을 정한다.

| 성향 | 특징 |
|---|---|
| 공격형 | 적극적으로 진군·돌격, 퇴각 늦음 |
| 방어형 | 진형 유지, 철벽·방원 선호, 반격 위주 |
| 성벽 수비 | 성벽 위 배치, 원거리 위주 (성새전) |
| 유격형 | 측면·후방 기습, 군량 습격, 치고 빠지기 |
| 매복형 | 숲에 숨어 기다림, 도발·거짓 퇴각과 연계 |
| 지원형 | 후위에서 화살비·고무·재정비 |
| 신중형 | 간파·정찰 먼저, 불리하면 일찍 퇴각 |

- 장수 성향(용맹·냉정·신중·교활·충직·오만·소심, [traits.md](traits.md) 2장)과 연결된다: 신중한 장수는 일찍, 용맹한 장수는 늦게 퇴각.

## 6. 대표 판단 예

| 상황 | AI 판단 (난이도가 높을수록 잘함) |
|---|---|
| 적 기병이 돌격해 옴 | 창병을 앞으로, 방원진으로 전환 |
| 수상한 숲 | 간파 사용 후 통과, 또는 우회 |
| 순풍 + 상대가 숲에 있음 | 화계 |
| 아군 궁병이 노출됨 | 방패병·근접 군단으로 가림 |
| 상대가 좁은 길·다리를 지나는 중 | 낙석·복병·집중 공격 (장사진 상대 유리) |
| 우리 사기 붕괴 직전 | 고무·재정비, 안 되면 후퇴 |
| 군량 부족 | 결전 (총공격) 또는 퇴각 |
| 상대 장수 노출 (언월·선두 돌파) | 집중 사격, 일기토 신청 |
| 교란당함 | 재정비, 다음 교란 대비 반간 |

## 7. 난이도

| 항목 | 쉬움 | 보통 | 어려움 | 지장 (최고) |
|---|---|---|---|---|
| 반응 지연 | 김 | 보통 | 짧음 | 매우 짧음 |
| 상성 대응 (진형·대상) | 거의 안 함 | 가끔 | 자주 | 거의 항상 |
| 스킬 활용 | 단순 사용 | 조건 맞을 때 | 아껴서 결정적 순간 | 연계 (간파→화계 등) |
| 정찰 (간파·척후) | 안 함 | 가끔 | 자주 | 의심 지점마다 |
| 협공·유인 | 안 함 | 단순 협공 | 협공·유인 | 여러 단계 작전 |
| 마지막 목격 위치 추적 | 안 함 | 짧게 | 기억함 | 예측 이동 |
| 실수 (무작위 판단) | 많음 | 보통 | 적음 | 거의 없음 |

- 스토리 스텝마다 AI 난이도를 정한다 (스텝 데이터).
- **전체 난이도 설정**(쉬움·보통·어려움)을 둔다 (확정). 설정 화면에서 고르고, 스텝 난이도에 더해진다.
- **목표 승률**(검증 기준, 예): 권장 레벨·표준 편성으로 보통 AI 상대 승률 50~65%.
- 구현 (2026-11-12, R-75): 난이도 쉬움·보통·**어려움**. 설정 화면의 전체 난이도가 스텝 난이도를 한 칸 옮긴다 (세이브에 남아 서버도 같은 난이도로 확인). 어려움 = 판단 간격 짧음·스킬 늘 사용·상성 진형 0.9·정찰 + **사령관 협공**(앞선 군단이 뒤처진 같은 편을 기다렸다 함께 치고, 붙으면 같은 편이 치는 적을 함께 친다). 아직: 작전 방침(수비·지구전·유인 매복·측면 포위)·페이즈 전환, 지장 난이도.

## 8. 스텝 연출 (스크립트)

스텝 데이터로 AI 행동을 연출할 수 있다.

| 연출 | 예 |
|---|---|
| 미리 배치된 복병 | "왼쪽 숲에 적 2군 매복" |
| 증원 | "5주차에 적 증원 2군단 등장", "적 대장 위기 시 증원" |
| 구역 수비 | "다리를 끝까지 지킨다" |
| 작전 페이즈 | "병력 50% 이하면 지구전으로 전환" |
| 대사 | 장수 말풍선·이벤트 대사 연결 |

- 스크립트는 AI 판단 위에 얹는 **지시**다. 스크립트가 없는 부분은 AI가 스스로 판단한다.

## 9. 다른 곳에서 쓰는 AI

| 용도 | 방식 |
|---|---|
| **위임 (아군)** | 같은 AI가 아군 군단을 지휘. 플레이어 예약 명령을 우선하고 빈 곳만 채운다. **위임 판단 수준은 그 장수의 지략·통솔에 따라 다르다** (확정) |
| **비동기 대전 방어** | 상대가 저장한 방어 편성 + **작전 방침**(수비, 유인 매복 등)을 상대가 미리 골라 둔다 |
| **일기토·논쟁** | 상태(체력·기운)와 장수 성향으로 행동 확률을 정함 (맹장은 공격·필살 위주, 신중형은 회피·퇴각 위주). 운이 주가 되는 규칙은 그대로 |
| **장수 말풍선 보고** | 위임·AI 군단은 보고를 띄우지 않고 바로 판단 |

## 10. 개발 순서

| 단계 | 내용 |
|---|---|
| **1차** | 군단 AI (공격형·방어형), 기본 스킬 판단(1차 스킬 8종), 퇴각 판단, 일기토 AI, 쉬움·보통 |
| **2차** | 사령관 AI 작전 방침(총공격·수비·측면 포위), 상성 대응, 협공, 스텝 스크립트, 어려움 |
| **3차** | 유인 매복·지구전·정찰 후 대응, 지장 난이도, 성새전 AI, 위임 판단 수준 차등 |
| **4차** | 비동기 대전 방어 AI 설정, 수상전 AI |

## 11. 검증 도구

- **AI 판단 보기** (개발 빌드): 군단마다 후보 행동과 점수를 화면에 표시.
- **AI 대 AI 자동 대전**: 시뮬레이터로 대량 대전 → 난이도별 승률, 절대 강자 편성 탐지.
- **스텝 승률 확인**: 스텝마다 권장 편성으로 자동 대전해 목표 승률에 맞는지 확인.
