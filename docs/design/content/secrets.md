# 숨은 보상 (이스터 에그)

> 상태: 기획 중 (구현 전)
> 관련: [skills.md](skills.md), [traits.md](traits.md), [story.md](story.md), [general-growth.md](general-growth.md) 2.3(보상 규칙 엔진), [generals.md](generals.md)

---

## 1. 목적

- 스토리 진행, 장수 키우기 등 **다른 컨텐츠를 하다가 특별한 조건을 만족하면** 스킬·특성을 얻는다 (확정).
- 미리 알려주지 않는 **숨은 보상**이라, 발견하는 재미와 공략 공유(녹화)의 동기가 된다.
- 상점(스킬북·특성서)이나 뽑기로는 얻을 수 없는 **희귀 스킬·특성**을 여기에 둘 수 있다.

---

## 2. 숨은 조건의 예

### 2.1 스토리 전투에서

| 조건 (예) | 보상 (예) |
|---|---|
| 스텝 3에서 **화계로 적 군단 2개 이상**을 태워 이김 | 특성 "화공 전문가" |
| 스텝 5에서 **손실 10% 이하**로 이김 | 스킬 "철벽" |
| **비 오는 날** 궁병 없이 이김 | 특성 "빗속 행군" |
| 숨겨진 지점(맵 구석의 망루)을 **점령**한 채로 이김 | 스킬 "척후 파견" |
| 적 장수를 **일기토로** 쓰러뜨림 | 특성 "일기당천" |
| 같은 스텝을 **밤**에 기습으로 이김 | 특성 "야습" |
| 특정 적 장수를 **세뇌로 논쟁 승리 후 등용** | 그 장수의 고유 스킬 |

### 2.2 다른 컨텐츠에서

| 컨텐츠 | 조건 (예) | 보상 (예) |
|---|---|---|
| 장수 키우기 | 일기토 30연승 | 고유 특성 |
| 장수 키우기 | 무력·지략 모두 80 이상 | 스킬 "선두 돌파" |
| 부대 키우기 | 한 부대 결속 최대 달성 | 특성 "군기" |
| 고용 | 내 장수가 100회 고용됨 | 특성 "인망" |
| 포로 | 같은 장수를 세 번 해방 | 그 장수가 스스로 합류 (선택) |

## 3. 규칙

| 항목 | 내용 |
|---|---|
| 조건 정의 | **보상 규칙 엔진**과 같은 방식: 기록 카운터·전투 결과·스텝 조건 → 보상 ([general-growth.md](general-growth.md) 2.3) |
| 보상 | 스킬·특성 **직접 습득**, 또는 스킬북·특성서 지급. 칸이 차 있으면 보관함으로 |
| 받는 장수 | 조건을 만족한 장수 (전투 조건은 그 전투에 나간 장수 중 해당 장수) |
| 한 번만 | 대부분 계정당 1회 (반복 가능 여부는 보상마다 설정) |
| 요구 능력치 | 숨은 보상으로 얻은 스킬도 요구 능력치는 지킨다. **모자라면 스킬북(특성서)으로 보관**했다가 능력치가 되면 배운다 (확정) |
| 숨김 | 조건은 공개하지 않는다. 발견하면 **특별 연출 + 장수 말풍선**으로 알린다 |
| 도감 | 발견한 숨은 보상은 **도감**에 기록. 못 찾은 것은 "???"로 개수만 보임 (확정) |
| 힌트 | 스텝 대사·장수 말풍선·도감의 "???" 칸에 슬쩍 힌트 (확정). 힌트 문구는 데이터 |

---

## 4. 공정성 (서버)

- 숨은 보상으로 얻은 스킬·특성은 **고용 가치와 대전에 영향**을 준다. 그래서 전투 조건 보상은 **서버의 전투 재현 결과**로 확정한다 (기기에서 조작 방지).
- 조건 판정은 전투 결과(`BattleResult`)와 명령 기록만으로 할 수 있게 만든다 (재현 가능).
