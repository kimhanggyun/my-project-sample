# 포로 · 구출 · 등용

> 상태: 기획 확정 · 구현: 포로 발생·구출·기한 석방 규칙, **포로 탭에서 등용 시도·해방 (2026-11-11, R-66)** · 범위: Step 2
> 전체 흐름: [../flow.md](../flow.md) · 전투 중 포로 발생 규칙: [battle.md](battle.md) 2.5.1 · 구조: [../structure.md](../structure.md)(../structure.md) Campaign 모듈

## 1. 규칙

### 1.1 아군 장수가 포로가 된 경우: 수용소 구출
- 잡힌 장수는 적의 **수용소**에 갇힌다. 장수 정보에 "포로 · ○○ 수용소"로 표기한다.
- 갇혀 있는 동안은 **출전할 수 없다.**
- 스토리 탭에 **구출 전투**가 생긴다. 그 수용소를 공격해서 승리하면 장수를 되찾는다.
  - 구출 전투도 스텝 JSON과 같은 형식의 데이터로 만든다. 수용소별로 맵과 수비 병력을 정의한다.
  - 구현 (2026-11-12, E23): 스토리 목록의 구출 줄에 **갇힌 장수 수와 가장 짧은 남은 기한**, 구출 스텝 화면에 **장수마다 남은 기한**과 승리 조건. 구출 전투는 적을 물리치거나 **수용소(점령 구역, R-78)를 20초 동안 차지**하면 이긴다 (`rescue_camp_north.json` `objects`, `defeatConditions`에 `zone`).
  - 승리 조건: 수용소 점령 (지정 구역에 일정 시간 머물기) 또는 수용소 파괴.
- **구출 기한: 기본 1달(30일), 변경 가능.** `balance.json`의 기본값이고 수용소·스텝별로 덮어쓸 수 있다.
  - 기한은 실제 시간 기준이다 (게임 안에 달력이 없으므로).
  - **기한이 지나면 자동 석방**되어 장수가 돌아온다.

### 1.2 적 장수를 포로로 잡은 경우: 등용 또는 해방
- 전투 결과 화면 다음에 **포로 처리 화면**이 나온다. 잡은 적 장수마다 선택한다.

| 선택 | 결과 |
|---|---|
| 등용 | 성공하면 아군 장수가 된다. **실패하면 계속 감금**되고, **재시도 대기시간**이 지나면 다시 등용을 시도할 수 있다 |
| 해방 | 풀어주고 **보상**을 받는다 (보상 내용은 추후 결정) |

- 등용 성공률은 대상 장수의 성향·충성 등으로 정한다 (공식은 `balance.json`, 미결). 그 전투의 논쟁에서 **세뇌로 이긴 상대**라면 보너스.
- **등용 재시도 대기시간**은 설정값이다 (`balance.json`, 장수별 덮어쓰기 가능). **기본값 3시간.**
- 감금 중인 적 장수는 장수 목록의 "포로" 칸에서 보고, 대기시간이 끝나면 등용을 다시 시도하거나 해방할 수 있다.
- 해방 보상은 데이터(`releaseReward`)로 정의할 자리만 두고, 내용은 나중에 정한다.
- 주의: 서버 없이 기기 시계만 쓰면 시계를 바꿔 대기시간·기한을 조작할 수 있다. 나중에 서버 시간을 쓰도록 바꿀 수 있게 시간 조회를 한 곳(`ITimeProvider`)으로 모은다.
- **등용 불가 장수**가 있다. 장수 데이터의 설정값 `recruitable: false`로 제어한다 (스토리상 다시 나와야 하는 장수 등). 등용 불가 장수는 포로 처리 화면에서 해방만 고를 수 있다.

## 2. 장수 상태 (세이브에 기록)

| 상태 | 의미 |
|---|---|
| 출전 가능 | 정상 |
| 경상 | 출전 가능, 능력치 −10%, 회복 시각 기록 ([battle.md](battle.md) 2.5.3) |
| 중상 | 출전 불가, 회복 시각 기록 |

| 등용됨 | 적 장수였다가 아군이 됨 |


## 3. 스위치 (켜고 끄기)

포로 시스템은 **기능별로 따로 켜고 끈다** (확정). 끈 기능은 계산·화면에서 빠지고, 다른 기능은 그대로 동작한다.

| 스위치 | 기능 | 기본 | 끄면 |
|---|---|---|---|
| `capture` | **포로 시스템 전체** (아래 모두의 상위 스위치) | 켜짐 | 장수는 포로가 되지 않고 퇴각만 한다 |
| `battleCapture` | 전투 중 포위되어 포로 | 켜짐 | 포위돼도 퇴각 |
| `duelCapture` | 일기토 패배 시 포로 | **켜짐** (확정) | 일기토 패배는 혼란 후 도망만 |
| `rescueBattle` | 아군 포로 구출 전투 | 켜짐 | 구출 전투 없음 (기한 경과로만 석방) |
| `rescueDeadline` | 구출 기한 경과 시 자동 석방 | 켜짐 | 구출해야만 돌아옴 |
| `recruitment` | 적 장수 등용 | 켜짐 | 해방만 가능 |
| `recruitRetry` | 등용 실패 후 재시도 | 켜짐 | 실패하면 해방 |
| `releaseReward` | 해방 보상 | 켜짐 | 보상 없음 |

- 상위 스위치(`capture`)가 꺼지면 하위 스위치 값과 상관없이 모두 꺼진 것으로 본다.
- 스텝·규칙 세트(예: 대전 모드)에서 덮어쓸 수 있다.

## 4. 기본값 (설정값)

| 값 | 기본 |
|---|---|
| 구출 기한 | 30일 (실제 시간), 지나면 자동 석방 |
| 등용 재시도 대기시간 | 3시간 |
| 등용 불가 | 장수 데이터 `recruitable: false` |
