## 0. 원칙: 상점은 지름길일 뿐, 유일한 수단이 아니다 (확정)

- 상점에서 살 수 있는 것은 **모두 게임 플레이로도 얻을 수 있어야** 한다. 상점 구매는 시간을 줄여주는 **지름길**이다.

| 상점 판매 | 플레이로 얻는 길 |
|---|---|
| 군량 | 승리 시 적 군량 포획, 보급소 점령, 광고 보상, 시작 지급 |
| 돈 | 보상(리워드), 해방 보상, 고용 수익 |
| 뽑기 재화 | 보상(리워드), 숨은 보상, 이벤트 |
| 스킬북 | 보상(리워드), 숨은 보상(보관), 스토리 보상 |
| 특성서 | 보상(리워드), 숨은 보상(보관), 장수 키우기 보상 |
| 장수 (뽑기) | 등용, 스토리 합류, 숨은 보상(합류), 고용(빌리기) |

- 예외는 **편의 기능**뿐이다: 광고 제거, 특수 패키지의 시간 회복 같은 것. 이것들은 전투력을 올리지 않는다.
- 새 상품을 추가할 때도 "플레이로 얻는 길"을 함께 정한다.

## 1. 자원 종류

| 자원 | id | 쓰임 | 얻는 곳 |
|---|---|---|---|
| 군량 | `supply` | 출진, 징병, 치료 | 시작 지급, 광고, 결제, 승리 포획, (패키지) 시간 회복 |
| 뽑기 재화 | `gem` (임시) | **장수 뽑기 전용** | 결제, 보상(제안) |
| 돈 | `gold` | 모병, 치료 | **결제**, **보상(리워드)** — 어떤 보상으로 줄지는 추후, 테스트하며 밸런스 조정 |

- 자원 종류는 데이터로 정의한다 (`Wallet`). 화면 이름은 테마 문자열 ([../theme.md](../theme.md)).

## 1.1 군량의 역할

- 게임 진행 자원. **출진하려면 군량이 필요**하다.
- 전투 길이를 정한다 (군량이 떨어지면 사기 하락 → 퇴각).

## 2. 군량 흐름

```
얻기                                   쓰기
─────────────────────────────          ─────────────────────────
시작 군량 (초기 지급)          ──┐
광고 보기 보상                 ──┤
앱 결제 (상점, 추후)           ──┼──▶  보유 군량  ──▶ 출진 시 지참 (자동 3분 분량, 증감 가능)
특수 패키지 시간 회복 (추후)   ──┤                      │
승리 시 적 군량 포획           ──┘                      ▼
                                              전투 중 소비 (병사 1명 하루 1, 1분 = 1주)
                                                        │
                                              남은 지참 군량 반환 ──▶ 보유 군량

                                    보유 군량 ──▶ 징병 (새 병사)
                                    보유 군량 ──▶ 치료 (징병 비용의 절반)

결제 ──▶ 보유 돈 ──▶ 모병 (새 병사, 군량 소모 없음)
                  └─▶ 치료 (모병 비용의 절반)
```
