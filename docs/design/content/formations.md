# 진형 체계

> 상태: 설계 뼈대 (수치 미정) · 개발은 단계별로 순차 추가 (8장)
> 관련: [battle.md](battle.md) 2.2(진형 기본), 2.2.1(상성표), 2.6(장수 규율), 2.16(지형) · [troops.md](troops.md)(병종) · [troop-growth.md](troop-growth.md)(해금)
> 진형 이름은 고전 진법(팔진, 오행진) 명칭을 참고한 현재 테마 기준 이름이다. 데이터는 영문 id.

---

## 1. 설계 원칙

1. **진형 = 6개 소부대의 배치.** 군단이 이동하면 소부대는 진형이 정한 자리로 따라간다 (장수 기준).
2. **진형마다 특성치가 있다** (2장). 같은 병력·능력치라도 진형에 따라 강약이 달라진다.
3. **진형 상성** (4장): 같은 능력치면 진형 상성으로 승패가 갈린다.
4. **사이드그레이드**: 고급 진형도 약점이 분명하다. "최강 진형"은 없다.
5. **바꾸는 데 대가가 있다**: 진형 전환 중에는 대형이 흐트러져 취약하다 (6장).
6. **병종·지형과 궁합이 있다** (5장): 어떤 병종을 어느 자리에 넣느냐, 어떤 지형에서 펼치느냐가 중요하다.

---

## 2. 진형 특성치

| 특성치 | 의미 |
|---|---|
| 정면 폭 | 동시에 교전하는 병사 수 (넓을수록 화력↑, 얇아짐) |
| 돌파력 | 정면 공격 보정 |
| 측면 방어 | 측면 피격 시 피해 감소 |
| 후방 방어 | 배후 피격 시 피해 감소 |
| 이동 속도 | 군단 이동 보정 |
| 응집력 | 교전 중 대형이 흐트러지지 않는 정도 |
| 전환 시간 | 이 진형으로 바꾸는 데 걸리는 시간 |
| 원거리 효율 | 궁병 등이 쏠 수 있는 각도·사선 확보 |
| 포위력 | 적 측면을 감싸는 능력 |
| 범위 피해 감소 | 투석기·화살비·화계 같은 범위 피해에 대한 감소 |

모두 가산 보정(%p)으로 피해 계산·이동에 들어간다.

## 3. 진형 목록

↑ 높음 · ↓ 낮음 · - 보통

### 3.1 상성 순환 진형 (핵심 6종)

서로 물고 물리는 관계(4장)의 중심.

| 진형 | id | 모양 | 강점 | 약점 | 어울리는 병종·장수 |
|---|---|---|---|---|---|
| 어린 (魚鱗) | `fishScale` | 중앙에 겹겹이 모인 삼각형. 앞이 무너지면 뒤가 바로 나섬 | 중앙 돌파↑, 응집력↑, 적은 병력으로 버팀 | 측면↓, 포위력↓ | 보병·창병 중앙 / 균형형 |
| 학익 (鶴翼) | `craneWing` | 양 날개를 학처럼 펼침 | 포위력↑, 측면 공격↑ | 중앙이 얇음 (돌파에 약함) | 기병 양 날개, 궁병 중앙 뒤 / 통솔형 |
| 봉시 (鋒矢) | `arrowhead` | 화살촉 모양, 선봉에 힘을 모음 | 돌파력↑↑, 돌격 속도↑ | 측면·후방↓↓, 응집력↓ | 기병·중기병 선봉 / 맹장 |
| 방원 (方圓) | `circle` | 원형으로 사방을 막음 | 측면·후방 방어↑↑, 포위 무력화, 사기 안정 | 돌파력↓, 이동 속도↓↓ | 창병 외곽, 궁병 안쪽 / 책사 |
| 안행 (雁行) | `echelon` | 기러기처럼 사선으로 늘어섬 | 측면 우회, 원거리 효율↑ | 정면 압박에 약함, 소모전에 약함 | 궁병, 경기병 / 지력형 |
| 언월 (偃月) | `crescent` | 초승달, 장수가 앞에 섬 | 장수 용맹 효과 극대화, 선봉 사기↑ | 장수 노출 (일기토·포로 위험) | 정예 근접 / 맹장 |

### 3.2 기본·상황 진형

| 진형 | id | 모양 | 강점 | 약점 | 쓰임 |
|---|---|---|---|---|---|
| 방진 (方陣) | `square` | 사각형, 고전 진법의 기본 | 모든 특성치 보통, 응집력↑ | 특별한 강점 없음 | **기준 진형** (상성 없음, 보병 같은 역할) |
| 횡진 (橫陣) | `line` | 옆으로 길게 한 줄 | 정면 폭↑↑, 원거리 효율↑↑ | 얇아서 돌파에 약함, 측면↓ | 궁병 화력 집중, 넓은 평지 |
| 장사 (長蛇) | `column` | 뱀처럼 길게 한 줄 (행군 대형) | 이동 속도↑↑, 좁은 길 통과 | 측면↓↓, 정면 폭↓↓ | 행군, 좁은 길·다리 (좁은 길에서는 자동 전환) |
| 산개 (散開) | `loose` | 넓게 흩어짐 | **범위 피해 감소↑↑** (투석기·화살비·화계), 숲에서 이동↑ | 응집력↓↓, 기병 돌격에 매우 약함 | 투석기·궁병 상대, 숲 |

## 4. 진형 상성

### 4.1 핵심 6종 상성표

각 진형은 **유리 2, 불리 2, 보통 1**. (행: 공격 측, ○ 유리 · × 불리 · - 보통)

| 공격＼상대 | 어린 | 학익 | 봉시 | 방원 | 안행 | 언월 |
|---|---|---|---|---|---|---|
| 어린 |  | ○ | - | × | × | ○ |
| 학익 | × |  | ○ | × | ○ | - |
| 봉시 | - | × |  | ○ | × | ○ |
| 방원 | ○ | ○ | × |  | - | × |
| 안행 | ○ | × | ○ | - |  | × |
| 언월 | × | - | × | ○ | ○ |  |

근거 예: 어린은 학익의 얇은 중앙을 뚫고, 방원은 학익의 포위를 무력화하고, 봉시는 방원 한 점을 집중 돌파하고, 학익은 봉시의 약한 측면을 감싼다.

### 4.2 기본·상황 진형의 관계

상성표 대신 **특성치와 상황**으로 강약이 정해진다.

| 진형 | 유리한 상황 | 불리한 상황 |
|---|---|---|
| 방진 | 상대 진형을 모를 때 (무난) | 상성 진형을 만났을 때 이득이 없음 |
| 횡진 | 원거리 대결, 넓은 평지, 학익·안행 상대 | 어린·봉시 돌파 |
| 장사 | 이동 중, 좁은 길 | 교전 전반 (특히 측면 기습) |
| 산개 | 투석기·궁병·화계 상대, 숲 | 기병·봉시 돌격, 근접 정면전 |

## 5. 병종·지형 궁합

**병종 배치** (6개 슬롯: 선봉·중앙·좌익·우익·좌비·우비)
- 봉시: 선봉에 기병·중기병 → 돌파력 극대화.
- 방원: 외곽(좌익·우익·좌비·우비)에 창병 → 기병 돌격 차단, 중앙에 궁병.
- 횡진·안행: 궁병을 앞줄 가까이 → 원거리 효율.
- 학익: 양 날개(좌익·우익)에 기병 → 포위.
- (제안) **권장 배치 보너스**: 진형마다 권장 병종 배치를 데이터로 정하고, 맞추면 소폭 보너스 (스위치 `formationSynergy`).

**지형**
- 학익·횡진은 **넓은 평지**가 필요하다. 공간이 좁으면 자동으로 압축되고 장점이 줄어든다.
- 장사는 좁은 길·다리에서 자동 전환된다 ([battle.md](battle.md) 2.11).
- 방원은 포위당했을 때, 산개는 숲·투석기 상대에서 빛난다.

---

## 6. 진형 변경

- **전환 시간** = 진형 기본 전환 시간 − (병종 진형 변경 속도 + 장수 규율(통솔) + 장수 진형 숙련 + 부대 훈련도) 보정.
- 전환 중에는 **응집력이 크게 떨어져** 공격받으면 불리하다. 그래서 적이 붙기 전에 바꾸는 판단이 중요하다.
- 진형 변경은 ④ 패널 버튼이나 군단 원형 메뉴에서 언제든 할 수 있다 ([battle.md](battle.md) 4.3).

## 7. 습득과 숙련

| 단계 | 진형 | 얻는 방법 |
|---|---|---|
| 기본 | 방진, 장사(자동) | 처음부터 |
| 초급 | 어린, 학익, 횡진 | 초기 지급 / 스토리 보상 |
| 중급 | 방원, 산개, 안행 | 스토리 보상 / 부대 키우기 |
| 고급 | 봉시, 언월 | 부대 키우기, 장수 조건 (예: 통솔 60 이상) |

- 진형도 스킬처럼 **요구 능력치**(주로 통솔)를 둘 수 있다.
- **장수 진형 숙련**: 많이 쓴 진형은 전환 시간이 줄고 응집력이 오른다 (장수 키우기 항목으로 확장 가능).
- 단계 구분은 습득 순서일 뿐, 고급 진형이 더 강한 것은 아니다 (사이드그레이드).

## 8. 개발 순서

| 단계 | 진형 | 이유 |
|---|---|---|
| **1차** | 방진, 장사(자동), 핵심 6종 (어린·학익·봉시·방원·안행·언월) | 상성 순환이 6종이 다 있어야 성립 |
| **2차** | 횡진, 산개 | 원거리·범위 피해와의 상호작용 (투석기, 화계가 들어오는 시점) |
| 이후 | 테마·확장 진형 (예: 수상전 전용 진형) | 데이터만 추가 |
