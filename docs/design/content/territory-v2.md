> 구현할 때 [territory.md](territory.md) 2·3·5·6·7장(행정 구역 단계 · 지역 판정 · 지역 수비 · 연합 지역)을 이 내용으로 고치고 `verification.md`에 규칙 예시를 넣는다. R-45~R-50(지역 판정·영토 전투·수입·수비 등록·연합)은 원형 땅에 맞게 바뀐다.
> 숫자는 모두 **예시**다 (데이터로 두고 해 보며 고친다).
> 계기: 행정 구역(동·리) 단위는 도시에서 혼자 차지할 땅이 없고 지도 회사 경계 자료가 필요하다. 사용자 제안: 지도에 **깃발을 꽂고**, 깃발 둘레 **원**을 땅으로, 계급이 오를수록 원이 크게, 남의 원 안에 꽂으면 전투.

## 0. 한 줄 요약

**내 위치 근처에 장수를 보내 깃발을 꽂으면, 깃발 둘레 원(반지름 = 계정 계급)이 내 땅이다.** 남의 원 안에 꽂으면 1분 뒤 **공성전** — 수비자가 들어오면 유저 대전, 안 오면 AI가 수비한다. 이기면 상대 깃발을 뽑고 내 깃발을 꽂는다.

## 1. 지금 → 바뀌는 것

| 항목 | 지금 (territory.md) | 바뀜 |
|---|---|---|
| 땅 | 행정 구역 (리 · 읍면동 · 시군구 · 시도), 개발용 가상 지역 9곳 | **깃발 둘레 원**. 겹쳐도 됨 |
| 지도 | 지도 SDK 또는 자체 경계 (미결 7) | **지도 회사 없음**: GPS 좌표 + 칸 계산, 바탕은 Natural Earth(공공 영역) 한지풍 자체 그림 |
| 공격 범위 | 지금 지역 + 이웃 | **내 위치에서 반지름 안** |
| 차지 단위 | 지역 하나 = 주인 하나 | 깃발 하나 = 장수 하나 (여러 개 가능) |
| 수비 | 등록한 수비 편성 스냅샷을 AI가 | 깃발에 보낸 **장수·병력**이 수비. 수비자가 들어오면 직접 지휘 |
| 연합 | 읍면동 이상은 연합 전투 (군단 5+) | 연합 땅을 따로 두지 않음 — **깃발마다 연합 표**, 공격받으면 연합원이 전장으로 지원 |
| 지원 | 없음 | 전장 안에서 늦게 입장 (2.5) |

## 2. 규칙

### 2.1 깃발

- 깃발 하나 = **장수 1명 + 병력** 파견. 꽂으려면 보낼 수 있는 장수가 1명 이상 남아야 한다 (출진 · 포로 · 중상 아님). 깃발 수 상한 = 보낼 수 있는 장수 수.
- 꽂는 곳: **내 GPS 위치에서 반지름 안**. 좌표는 **100m 칸 가운데**로 맞춘다 (다른 유저에게 실제 위치를 보이지 않기 위해).
- 빈 땅(누구의 원도 아님)이면 바로 꽂힌다. 남의 원 안이면 공격 (2.3). 내 원·우리 연합 원 안에도 꽂을 수 있다 (겹침).
- [깃발 거두기]: 장수·병력이 돌아온다. [병력 바꾸기]: 그 깃발의 병종·인원.
- 수입: 깃발마다 하루 수입 (군량·돈, 예시 1,500·8), 24시간까지 쌓임, [수입 받기] → 우편 (R-47 방식 유지).

### 2.2 원 크기 = 계정 계급

계급이 정한 반지름 하나를 그 유저의 **모든 깃발(장수)에 똑같이** 쓴다. 꽂을 수 있는 범위도 같은 반지름.

| 계급 | 반지름 (예시) |
|---|---|
| 십부장 | 1km |
| 백부장 | 2km |
| 천부장 | 3km |
| 교위 | 5km |
| 장군 | 7km |
| 대장군 | 10km |

데이터: `campaign.json` `lord.ranks[].flagRadiusM` (구현할 때).

### 2.3 공성전

1. 남의 원 안에 깃발을 꽂으면(= [공격]) **바로 공성전**. 공격자는 출진할 장수·병력을 고른다.
2. **준비 1분**: 공격자에게 "전투 준비 중 — 1분 뒤 시작" 카운트 (그동안 [공격 취소] 가능). 수비자에게 **알림** ("○○ 깃발이 공격받습니다").
3. 수비자가 1분 안에 들어오면 **유저 대전**, 안 들어오거나 [AI에게 맡기기]면 **AI 수비** ([ai.md](ai.md)). 공격자는 어느 쪽이든 공성전을 진행한다.
4. 원이 여러 개 겹친 곳이면 공격 대상은 **가장 가까운 깃발** (예시 규칙).
5. 공격자가 이기면 **상대 깃발이 뽑히고 그 자리에 내 깃발**. 지면 공격 장수는 돌아오고 손실은 전투 결과대로.
6. 같은 깃발은 공성전이 끝나고 **보호 시간**(예시 30분) 동안 다시 공격받지 않는다.
7. 결과 확정은 서버 재현 (명령 기록 + 시드, R-29·R-46).

### 2.4 유저 대전 (단계적)

- **1단계**: 수비자가 들어오면 수비 쪽 **명령·계략을 직접** 내린다. 양쪽 명령은 서버를 거쳐 주고받고, 전투는 시드로 결정되므로 두 기기 결과가 같다.
- **2단계**: 완전 실시간 대전.
- 푸시 알림(FCM 등)은 외부 서비스 — 인터페이스 뒤, 꺼도 게임은 동작 (그때는 게임 안 알림만).

### 2.5 지원군 (전장 안)

- 영토 화면에는 지원 표시가 없다. 지원 부대는 **전장에 늦게 입장**하고, 입장할 때 "지원군 도착: ○○" 알림.
- **겹친 내 깃발**: 공격받은 깃발과 원이 겹친 내 다른 깃발의 장수·병력이 **전장 시간 하루 뒤** 입장 (전장의 하루 = 군량 하루치 소모 단위, 데이터 `ownFlagSupportDelayDays`로 조절).
- **연합원**: 공격받은 깃발과 가까운 연합원 깃발이 **거리에 따라 늦게** 입장 (전장 시간, 예시: 1km마다 n시간 — 데이터).
- 지원 부대가 오기 전에 수비 장수가 지면 땅을 빼앗긴다 (그 뒤 도착 예정 지원은 취소).

### 2.6 줌 단계

| 줌 | 범위 (예시) | 보이는 것 |
|---|---|---|
| 가까이 | ~5km | 모든 깃발 · 원 |
| 중간 | ~50km, 칸 5km | 칸마다 **대표 깃발 1개** (세력 = 병력 큰 순, 같으면 계급) + 나머지 수 "+n" |
| 멀리 | 도 · 나라 | **세력도**: 칸마다 가장 센 연합 색 + 연합 이름 · 연합장 |

- 내 깃발은 **어느 줌에서도 늘 보인다**. 줌 경계·칸 크기는 데이터.
- 칸 계산은 좌표만으로 한다 (행정 구역 자료 필요 없음).

## 3. 위치 · 지도 · 법

- 위치: `ILocationService` 그대로 (끔 / 가짜 / 기기). 휴대폰은 **위치 동의를 받아야 영토전 가능** — 처음 영토 탭에서 안내 → 권한 요청. 거절하면 영토 탭만 잠김.
- 지도 그림: **Natural Earth** (해안선 · 나라 · 시도 경계 · 강, 공공 영역, 출처 의무 없음)를 앱에 넣고 한지풍으로 그린다. 가까이 줌은 길 없이 칸 · 깃발 · 원. 동네 길(OpenStreetMap, 출처 표시 · 서버 부담)은 나중.
- 조작 방지: 가짜 위치 앱 감지(Android 모의 위치), 서버의 이동 속도 검사 (territory.md 3장 유지).
- **위치정보법** 신고 · 약관 · 동의는 출시 전 필수 (territory.md 4장 유지).
