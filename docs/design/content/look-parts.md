# 겉모습 부품 만드는 법 (R-150)

병사 · 장수 겉모습을 **번호 붙은 부품**으로 조립한다 (2026-11-24 사용자: "투구 · 갑옷 · 망토 · 칼 · 창 · 활 · 방패 · 말을 그럴듯하게, 높은 등급일수록 확 다르게, 번호를 말하면 지움").
부품은 **데이터만** — `data/Ui/lookParts.json` 하나. 코드는 고치지 않는다. 겉모습만이라 전투 계산과 무관.

- 조립: `unity/Assets/Game/Scripts/Battle3D/LookMeshes.cs` (사람 몸 · 말 몸은 코드, 부품은 데이터)
- 읽기: `LookParts.cs` (`LookPartLibrary`), 차림 정하기: `SoldierLook.cs`, 개발용 고르기: `DevLooks.cs`
- 보기: 개발 줄 **[병사꾸미기] · [장수꾸미기]** 탭 (부위 칸마다 번호 · 이름 · 등급 카드), 샘플전투2 우리 편 · 우리 장수
- 검사: `tests/Game.Tests/LookPartsDataTests.cs` (`dotnet test GameCore.sln`이 통과해야 함)

## 1. 번호 = 부위

| 글자 | 부위 | 붙는 자리 (`at`) | 예 |
|---|---|---|---|
| H | 투구 · 모자 | head | H01 삿갓, H05 깃 투구 |
| A | 갑옷 · 옷 | chest · waist · back · feet | A03 찰갑, A04 판금 흉갑 |
| C | 등 (망토 · 화살통 · 등 깃발) | back · chest | C02 짧은 망토, C01 화살통 |
| S | 칼 · 도끼 (오른손) | rightHand | S01 환도, S04 월부 |
| P | 창 · 긴 무기 (오른손) | rightHand | P01 창, P04 언월도 |
| B | 활 · 쇠뇌 (왼손 — 쇠뇌는 앞에 듦) | leftHand | B01 활, B03 쇠뇌 |
| D | 방패 (왼손) | leftHand | D01 둥근 나무 방패, D03 긴 방패 |
| M | 말 갖춤 (안장 · 덮개 · 마갑 · 장식) | saddle · horseHead · horseNeck · horseBody · horseRump · horseChest | M01 기본 안장, M03 마갑 |

- 번호는 글자 + 두 자리 (`H01` … `H99`, 모자라면 세 자리). **한 번 쓴 번호는 다시 쓰지 않는다** (사용자가 번호로 말함). 지울 때는 그 부품을 빼고, 그 번호를 가리키는 곳(troops · generals · loadouts · cosmetics.json 세트)도 고친다 — 테스트가 알려 줌.
- 무기 묶음 **L** (`loadouts`): 손에 드는 짝 (L01 칼 · 둥근 방패, L04 활 · 화살통 …). 오른손 = S · P, 왼손 = B · D, 등 = C (있을 때만).

## 2. 등급 (`grade`)

| 값 | 뜻 | 겉모습 기준 |
|---|---|---|
| basic | 기본 (처음부터) | 천 · 나무 · 가죽, 장식 거의 없음, 도형 2 ~ 5개 |
| coin | 엽전 | 가죽 · 쇠 조금, 테 하나 |
| gem | 금괴 | 쇠 투구 · 판금 · 찰갑, 테 · 징 · 목 가리개, 도형 5 ~ 10개 |
| cash | 결제 | **멀리서도 확 다름**: 금(gold) 테 · 깃(plume) · 술 · 큰 실루엣 (높은 깃, 넓은 날, 호랑이 얼굴 방패) |
| general | 장수 전용 | cash보다 더 크고 화려 (꿩 깃 투구 · 명광개 · 사모 · 장수 말갑) |

- 높은 등급일수록 **색만 바꾸지 말고 모양을 바꾼다** (사용자: "현질하거나 노력한 사람이 그럴듯해야").
- 세트(`cosmetics.json` 갑옷 세트)의 투구 · 방패 · 갑옷은 병종 기본 차림보다 **등급이 높을 때만** 바뀐다 (방패병의 긴 방패를 지킴).
- 어깨에 동그란 덧댐은 쓰지 않는다 (사용자: "어깨에 두른 건 빼, 망토나 갑옷스러운 걸로").

## 3. 부품 모양

```json
{
  "id": "H04",
  "name": "철 투구",
  "grade": "gem",
  "note": "선택 — 설명",
  "pieces": [
    {"shape": "dome", "at": "head", "pos": [0, 0.017, 0], "size": [0.076, 0.05, 0.076], "color": "hat"},
    {"shape": "box", "at": "head", "pos": [0.041, 0.02, 0], "size": [0.004, 0.036, 0.022], "color": "gold", "rot": [0, 0, -20], "mirror": true}
  ]
}
```

- **shape**: `box` 상자 · `sphere` 공 · `cylinder` 원기둥 · `capsule` 캡슐 (지름 = size x, 길이 = size y, 끝이 둥긂) · `cone` 원뿔 (뾰족한 쪽이 위) · `dome` 반구 (평평한 쪽이 아래).
- **pos**: 붙는 자리(at)에서 도형 **가운데**까지 (x 오른쪽 +, y 위 +, z 앞 +). **size**: 도형 **전체** 크기 (가로 · 높이 · 깊이). 원기둥 · 원뿔 · 반구 · 공은 x · z가 지름.
- **rot**: 도형 돌림 (도, Unity 차례 x → y → z). 원기둥을 눕혀 앞을 보게 = `[90, 0, 0]` (방패). 위를 향한 것을 앞으로 기울이기 = x 양수.
- **mirror**: `true`면 x를 뒤집어 하나 더 (양쪽 귀 · 날개 · 징). 돌림은 y · z를 뒤집음.
- 도형은 부품당 **1 ~ 24개**. 병사가 수백 명이라 가볍게 — 공 · 캡슐 · 반구는 상자 · 원기둥보다 무거우니 꼭 둥글어야 할 때만.
- 검사 범위: pos −0.6 ~ 0.6, size 0 초과 ~ 0.8, rot −360 ~ 360.

## 4. 자리 (`at`) 와 몸 크기

사람 (선 자세, 원점 발밑, 키 약 0.36 — 장수는 코드가 1.8배):

| 자리 | 위치 | 주변 크기 |
|---|---|---|
| head | (0, 0.33, 0) 얼굴 가운데 | 머리 지름 0.062, 정수리 +0.032, 이마 앞 z +0.031 |
| chest | (0, 0.235, 0) 가슴 | 몸통 가로 0.06 · 깊이 0.036 · 높이 0.1 (0.185 ~ 0.285), 목 +0.058 |
| waist | (0, 0.15, 0) 허리띠 | 허리 가로 0.05 · 깊이 0.036, 다리 위 끝 −0.012, 땅 −0.15 |
| back | (0, 0.235, −0.02) 등 | 등 겉면 z −0.018 쯤, 어깨 높이 +0.027 |
| rightHand | (0.066, 0.183, 0.012) 오른손 | 칼은 손에서 위로 (손잡이 −0.01 ~ +0.01, 날 위), 창은 세워서 (자루 아래 끝이 땅 가까이 = y −0.18) |
| leftHand | (−0.066, 0.183, 0.012) 왼손 | 방패 가운데 ≈ (−0.004, 0.017, 0.02), 활은 손에서 위 · 아래로 |
| feet | (0, 0, 0) 발밑 | 긴 옷자락 |

- 말 탄 사람은 코드가 사람 자리를 0.092 올린다 (엉덩이가 안장 위). 부품은 그대로 두면 됨.

말 (원점 발밑, 앞 +z):

| 자리 | 위치 | 주변 크기 |
|---|---|---|
| saddle | (0, 0.218, −0.01) 등 위 (안장 아래면) | 몸통 가로 0.075 · 높이 0.085 · 길이 0.26 (z −0.13 ~ 0.13) |
| horseBody | (0, 0.175, 0) 몸통 가운데 | 옆구리 겉면 x ±0.0375 |
| horseNeck | (0, 0.245, 0.14) 목 가운데 | 목 지름 0.042 · 길이 0.11, 앞으로 35° 기움 (`rot [35, 0, 0]`이면 목 따라) |
| horseHead | (0, 0.29, 0.19) 머리 가운데 | 머리 지름 0.036 · 길이 0.075, `rot [115, 0, 0]`이면 머리 따라 (주둥이 앞 아래) |
| horseRump | (0, 0.19, −0.095) 엉덩이 | 엉덩이 0.078 × 0.09 × 0.085 |
| horseChest | (0, 0.185, 0.1) 가슴 | 가슴 0.072 × 0.09 × 0.075 |

- 말 다리는 코드가 따로 흔든다 (부품을 붙이지 않음). 안장 윗면은 0.23 근처여야 탄 사람이 뜨지 않는다.

## 5. 색 (`color`)

고를 수 있는 색 (세트 · 꾸미기 탭이 정함, 없으면 기본):

| 자리 | 기본 | 쓰임 |
|---|---|---|
| main | 편 색 | 몸 · 갑옷 판 · 말 덮개 |
| trim | 편의 어두운 색 | 테 · 띠 · 가는 줄 |
| hat | main과 같음 | 투구 · 모자 몸 |
| cape | 편의 어두운 색 | 망토 · 등 깃발 |
| shield | 나무색 | 방패 판 |
| plume | 붉은색 | 깃 · 술 |
| legs | 편의 어두운 색 | (코드: 다리) |
| horse | 밤색 (장수 흰색) | (코드: 말 몸) |

정한 색 (늘 같음): `metal` 쇠 · `gold` 금 · `wood` 나무 · `dark` 가죽 · 짙은 갈색 · `white` 흰 천 · 시위 · `skin` 살 · `mane` 갈기 (말 색을 어둡게) · `team` 늘 편 색 (총대장 군기).

- 편 구분은 바닥 원 · 이름표로 충분해서 세트가 몸 전체 색을 바꿔도 된다 (사용자 2026-11-24).
- 높은 등급은 `gold` · `plume`을 써서 기본과 멀리서도 구분되게.

## 6. 기본 차림 (`troops` · `generals`)

```json
"troops": { "infantry": { "hat": "H01", "armor": "A01", "loadout": "L01" }, "cavalry": { "hat": "H01", "armor": "A01", "loadout": "L09", "tack": "M01" } },
"generals": { "warrior": { "hat": "H07", "armor": "A06", "back": "C05", "right": "P05", "tack": "M05" } },
"commanderExtra": "C06"
```

- 부위 키: `hat` · `armor` · `back` · `right` · `left` · `tack` · `loadout` (묶음을 먼저 펼치고 나머지 키가 덮음).
- troops 키 = `troopTypes.json`의 병종 id (없는 병종은 계열 — 보병 · 창병 · 궁병 · 기병 · 정찰병 · 공병 — 의 차림). generals 키 = `crowd.json` generalPresets (warrior 맹장 · standard 지장 · strategist 책사).
- 총대장은 `commanderExtra` 부품이 등에 더 붙는다.
- 1단계 병종 (보병 · 창병 · 궁병 · 기병 · 정찰병 · 공병) 기본 = **H12 쇠테 두건 · A02 가죽 조끼** + 병종 무기 (2026-11-25 사용자 사진). 승급 병종 기본은 나중에 정함.
- **세트의 계열별 부위** (`cosmetics.json` look): `"계열.부위": "번호"` (예 `"infantry.right": "S13"`, `"archer.back": "C10"`, `"-"` = 비움) — 그 계열이면 등급과 상관없이 그대로 입힌다. 세트가 색을 정하지 않은 자리(장식 테 · 다리)는 편 색 그대로.
- **편 기본 색** `teamColors`: 편(ally · enemy) → 색 자리 → 색 이름. 고른 색 · 세트 색이 없는 자리만 채운다. 적 = 진홍 몸 · 투구 · 망토 · 방패 · 깃 · 다리 + 검은 테 (2026-11-25 사용자 사진), 아군은 비워 둠 = 편 색 파랑. 꾸미기 미리보기의 파랑 = 전투의 아군 파랑.

## 7. 원격에 맡길 일 (부위마다 20개까지)

1. `data/Ui/lookParts.json`만 고친다 (코드 · 다른 파일은 건드리지 않음. 세트 연결 · 기본 차림 바꾸기는 데스크탑이 함).
2. 부위마다 번호 차례로 이어 붙여 **20개**까지: H · A · C · S · P · B · D · M. 등급은 부위마다 대략 basic 4 · coin 4 · gem 5 · cash 4 · general 3.
3. 시대 · 지역 느낌 (자체 세계관, 고대 동아시아풍): 삿갓 · 두건 · 전립 · 첨주 · 투구 · 관 / 무명 · 가죽 · 찰갑 · 두정갑 · 판금 · 명광개 · 도포 / 망토 · 화살통 · 등 깃발 · 등짐 / 환도 · 대도 · 도끼 · 철퇴 · 쌍검 / 창 · 장창 · 극 · 언월도 · 당파 · 낭선 / 활 · 각궁 · 쇠뇌 · 연노 / 둥근 · 네모 · 긴 · 등패 · 호두패 / 안장 · 덮개 · 마갑 · 장식. 실존 게임 · 작품의 고유 디자인을 그대로 베끼지 않는다.
4. 각 부품은 `name`(짧은 한국어) · `grade` · (선택) `note`. 높은 등급은 실루엣이 달라야 함 (2장).
5. 위 4장 크기를 보고 몸에 붙게 (투구는 정수리를 덮고, 갑옷은 몸통보다 조금 크게 0.066 ~ 0.08, 방패는 왼손 앞). 떠 있거나 몸속에 묻히지 않게.
6. `dotnet test GameCore.sln` 통과 (`LookPartsDataTests`).
7. PR 설명에 새 번호 목록 (부위 · 번호 · 이름 · 등급).

## 8. 사용자 흐름

- 사용자가 [병사꾸미기] · [장수꾸미기]에서 조합을 만들어 캡처 → 마음에 안 드는 번호는 "H07 지워" → 데스크탑이 지움.
- 좋은 조합은 [세트로 저장] (번호 JSON을 복사 · Editor.log에 "꾸미기 세트:") → 데스크탑이 상점 세트(`cosmetics.json`)로 만든다.
