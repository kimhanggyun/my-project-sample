# 샘플전투2 — 병사 단위 전투 (R-125, 시험 중)

> 상태: 시험 (2026-11-21). 기존 전투(battle.md, 소부대 = 점 + 화면 격자)와 **따로** 돈다. 사용자가 보고 판단한 뒤 기존 전투를 바꿀지 정한다.
> 코드: `src/Game.Battle.Model/Crowd/` (규칙), `unity/Assets/Game/Scripts/Battle3D/CrowdField3D.cs` · `Screens/SampleBattle2Screen.cs` (화면). 수치: `data/Rules/crowd.json`.

## 1. 왜 (2026-11-21 사용자)

- 게임의 핵심은 땅따먹기 + **보는 맛이 있는 전략 전투**. 지금 전투는 격자 덩어리가 겹치고, 뒷줄이 놀고, 칼질이 안 보여 재미가 없다.
- 원하는 것: 진형 **모양**이 결과를 바꾼다.
  - 얇은 일자를 돌격 삼각형(쐐기)이 뚫는다 — 맞닿은 곳만 맞교환이니 가운데가 먼저 비고, 양끝은 늦게 모인다. 그 틈에 적장에게 닿는다.
  - 두툼한 2~3줄은 쐐기로 뚫기 어렵다 (뒷줄이 메움) — 상성.
  - 두툼한 적을 V자로 감싸면 여러 방향에서 동시에 닿아 적이 불리 — 포위.
- 지금 규칙은 소부대를 크기 없는 점으로 계산하고 진형은 숫자 보정이라, 화면만 고쳐서는 위 장면이 **계산에서** 일어나지 않는다. 그래서 병사 단위로 계산한다.

## 2. 규칙 (R-125)

- 병사 하나 = 규칙의 병사 하나 (화면 병사도 하나). 장수도 병사 하나로, 체력이 크다 (`generalHp`).
- 매 틱 (`tickSeconds`), 병사를 id 순서로 계산하고 위치 · 피해는 한꺼번에 반영 (순서에 따른 유불리 없음).
  1. **군단 가운데**: 전진 명령이면 적 장수 쪽으로 `advanceSpeed`. 맞붙은 병사가 많을수록 느려진다 (`1 − 2 × 맞붙은 수 / 남은 수`, 0 아래면 멈춤). 앞 방향 = 적 장수 쪽.
  2. **병사**: `engageRange` 안에 적이 있으면 가장 가까운 적에게 간다 (대열을 떠나 몰려감 — 뒷줄도 앞으로). 가장자리 사이가 `attackReach` 안이면 서서 친다 (피해 1, 다음까지 `attackSeconds` + 0~`attackJitterTicks` 틱). 적이 없으면 자기 대열 자리로 (`moveSpeed`).
  3. **밀어내기**: 지름(`soldierRadius × 2`)보다 가까운 이웃(편 상관없이)과 겹친 만큼 절반씩 밀려나고, 다음 위치끼리 겹친 것을 두 번 더 풀어 준다 (뒤에서 미는 병사가 앞 병사 속으로 파고들지 않게) → 적과 섞이지 않고 맞닿는 선이 생긴다. 장수는 덜 밀린다.
  4. 체력 0이면 쓰러짐 (`soldierHp`).
- **끝**: 장수 체력 0 (사로잡음) 또는 병사 전멸이면 진다. `maxSeconds`가 지나면 남은 병사가 많은 쪽이 이긴다.
- **대열** (`CrowdFormations`, 앞 = 적 쪽, 간격 `spacing`): 일자 2줄 · 두툼 6줄 · 쐐기(꼭짓점이 앞, 줄마다 2k+1) · V자(벌린 쪽이 앞, 팔 두께 3줄). 장수는 대열 맨 뒤에서 `generalBack` 뒤.
- **대열 바꾸기**: 살아 있는 병사를 지금 위치의 좌우 순서대로 새 자리와 짝짓는다 (덜 엇갈리게). 맞붙은 병사는 싸움을 계속.
- 결정성: 고정소수점(`Fix`) · 시드 난수(`SeededRandom`)만. 같은 설정 · 시드 = 같은 결과.

## 3. 화면

- 격자 없음: 병사마다 위치를 틱 사이로 잇고, 방향만 화면에서 부드럽게 돈다 (초당 360°).
- 걷기: 튀지 않고, 다리 두 짝을 따로 떼어 간 거리만큼 번갈아 앞뒤로 흔든다 (2026-11-21 사용자 "귀신처럼 미끄러짐"). 바닥은 직접 만든 판 (기본 도형의 물리 부품 오류 없게). 공격: 대상 쪽으로 찌르며 몸을 ±40° 비틀어 무기를 휘두름. 쓰러짐: 0.15초 하얗게 → 넘어짐 → 땅으로 가라앉아 사라짐 (시체 남지 않음).
- 디자인 (사용자 "바꿔도 됨"): 병사 몸 전체가 편 색 (파랑 · 빨강, 다리 · 투구 테는 어두운 편 색), 얼굴만 살색 — 멀리서도 편이 갈린다.
- 시작 전: 우리 진형 · 적 진형 · 적 명령(제자리 · 전진) → [시작]. 싸우는 중: 진형 4개 · [전진/정지] · [다시] · 배속.
- 들어가는 곳: 개발 줄 [샘플전투] 탭 맨 위 카드 "샘플전투2".
