# 장수 키우기 (TO-BE)

> 상태: **TO-BE** — 하단 탭에 "준비 중"으로 표시. 컨텐츠는 나중에 구성한다.
> 전체 흐름: [../flow.md](../flow.md) · 관련 규칙: [battle.md](battle.md) 2.6(장수 능력치), 2.7(일기토), 2.8(스킬), 2.9(능력치 확장) · 구조: [../structure.md](../structure.md) Progression 모듈

## 1. 목적

장수의 레벨과 능력치를 키우고, 스킬과 진형을 배우게 한다.

**최종 목적: 다른 유저가 고용할 만한 장수를 만드는 것.** 키운 장수를 서버에 등록하면 다른 유저가 전투 기록을 보고 고용하고, 고용되면 보상을 받는다 ([hiring.md](hiring.md)).

## 2. 지금까지 정해진 것

- **세부 항목별 성장**: 지략 키우기, 무력 키우기, 통솔 키우기 등으로 나눈다. 항목마다 컨텐츠는 나중에 구성한다.
- 세부 항목 목록은 데이터(`growthTracks.json`)로 정의한다. 능력치가 늘어나면 항목도 데이터로 추가한다.
- **스킬 습득**: 장수마다 기본 스킬이 있고, 추가 스킬은 **스킬북**을 사서 이 탭에서 배운다 ([generals.md](generals.md) 4장). 스킬마다 요구 능력치가 있다 (예: 지략 70 이상).
- **진형 숙련도**: 장수별로 잘 쓰는 진형 (전환 시간·응집력 보너스).
- **특성 태그**: 맹장, 신중, 기습 등.
- **장수 레벨은 주로 이 탭에서 올린다** (확정). 전투로도 오르지만 아주 더디다 (스위치 `battleLevelUp`, [battle.md](battle.md) 2.19.1).
- 레벨업 시 능력치는 **성장률 방식** (장수별 고정 비율, 무작위 없음).

## 2.1 세부 항목 (성장 트랙)

| 항목 | 내용 | 상태 |
|---|---|---|
| 무력 | 무력 성장 | 컨텐츠 추후 |
| 지력(지략) | 지략 성장 | 컨텐츠 추후 |
| 통솔 | 통솔 성장 | 컨텐츠 추후 |
| 스킬 | 스킬 습득·강화 ([skills.md](skills.md)) | 컨텐츠 추후 |
| **일기토** | **일기토 전적에 따른 보상** (2.2) | 규칙 확정, 보상 수치 추후 |
| **논쟁** | 논쟁(지략 대결) 전적에 따른 보상 (예: 100승마다 지략 +1) | 확정, 보상 수치 추후 |

- 항목 목록은 `growthTracks.json`. 항목을 늘리거나 빼는 것은 데이터로 한다.

## 2.2 일기토 성장

- 장수마다 **일기토 전적**을 기록한다: 승, 패, 퇴각, 무승부, 연승.
- 전적에 따라 **보상 규칙**을 적용한다. 보상 내용(수치)은 나중에 입력한다.
- 보상 규칙 예:

| 조건 | 보상 (예) |
|---|---|
| 일기토 **100승마다** | 무력 +1 |
| **승패 차**(승 − 패)가 50 이상 | 특성 "맹장" |
| 10연승 | 칭호, 사기 보너스 |

- 일기토 전적은 고용 이력에도 표시한다 (장수 고용 판단 자료, [hiring.md](hiring.md)).

## 2.3 보상 규칙 엔진 (공통)

일기토뿐 아니라 모든 성장 항목에 같은 방식을 쓴다.

```
기록 카운터 (예: 일기토 승수, 승패 차, 전투 승리 수 …)
   → 조건 (몇 이상 / 몇마다 / 처음 달성)
   → 보상 (능력치 +, 스킬·진형 해금, 특성, 칭호, 자원)
```

```json
{
  "track": "duel",
  "rules": [
    { "counter": "duelWins",        "every": 100, "reward": { "stat": "might", "add": 1 } },
    { "counter": "duelWinLossDiff", "atLeast": 50, "once": true, "reward": { "trait": "fierce" } }
  ]
},
{
  "track": "debate",
  "rules": [
    { "counter": "debateWins", "every": 100, "reward": { "stat": "intellect", "add": 1 } }
  ]
}
```

- 새 카운터와 보상 종류는 추가형이다. 보상 수치는 테스트하며 정한다.
- 스위치로 켜고 끌 수 있다 (`duelGrowth`).

## 3. 탭이 생기기 전까지

- 능력치는 초기 지급값 + (더딘) 전투 레벨업으로만 바뀐다.
- 진형·스킬은 초기 지급 + 스토리 보상으로 얻는다 ([formation.md](formation.md), [story.md](story.md)).

## 4. 연결 방식

- 이 탭은 **장수 데이터(능력치, 배운 스킬·진형)를 바꾸는 역할만** 한다.
- 전투와 편성은 그 데이터를 읽기만 하므로, 탭을 추가해도 전투·편성 코드는 바뀌지 않는다.
- 탭 모듈: `GeneralGrowthTab` (`IMainTab` 구현), `mainTabs.json`에서 `status`를 `active`로 바꾸면 열린다.

## 5. 미결 사항

- [x] 세부 항목 → 무력, 지력, 통솔, 스킬, 일기토 (추가 가능)
- [x] 일기토 성장 → 전적 기록 + 보상 규칙 (2.2)
- [ ] 각 항목 컨텐츠, 보상 수치
- [ ] 성장에 쓰는 자원 (경험치만 / 재화·아이템)
