# 스토리 탭 · 출진

> 상태: 기획 확정 · 구현: 스텝 목록·출진·전투·결과, 스텝 12개 (1장 step01~06, 2장 step07~12 "북쪽 땅", 2026-11-10, 임시 대사), 전·후 대사(`data/Dialogue/<스텝>.json`, [다음]·[건너뛰기]). 지도 형태 목록·공략 보기는 아직
> 전체 흐름: [../flow.md](../flow.md) · 관련: [battle.md](battle.md), [formation.md](formation.md), [captivity.md](captivity.md), [economy.md](economy.md)

## 1. 흐름

```
스토리 탭 → 스텝 목록 → 스텝 정보 → (대사) → 출진 준비 → 전투 → 결과 → (포로 처리) → (대사) → 저장 → 다음 스텝 해금
```

### 1.1 스텝 목록
- 스텝은 차례로 해금된다.
- **깬 스텝은 반복할 수 있다** (확정). 부대 결속·군량 포획 등을 위해 다시 싸울 수 있다.
- 아군 장수가 포로가 되면 목록에 **구출 전투**가 따로 표시된다 (수용소 이름, 남은 기한).
- 지금은 **목록(스텝)** 형태로 보여준다. 나중에 **지도** 형태로 바꿀 수 있다 (5장 교체 포인트: 스텝 데이터에 지도 좌표만 추가하고 화면 모듈을 교체).

### 1.2 스텝 정보
- 전투 이름, 전장 유형, 출전 가능한 군단 수, 보상.
- **적 정보는 일부만 공개** (확정): 적 군단 수, 대략적인 총병력, 권장 레벨.
- 이 스텝에서 이미 확보한 시야(탐색 기억, [battle.md](battle.md) 2.10)는 미리보기 지도에 표시한다.
- **공략 보기**: 다른 유저가 공유한 이 스텝의 전투 녹화 ([replay.md](replay.md)).

### 1.3 대사
- 전·후 대사를 넣는다. **건너뛰기 버튼**을 둔다.
- 화면 (확정 2026-11-14, 시안 [17_dialogue](../mockups/17_dialogue/변경점.md)): 시작에 장 표시, 스텝 지형 수묵 배경, 반신 초상 좌우(아군 왼쪽 · 적 오른쪽, 말하는 쪽 밝게), 글자 한 자씩, [자동] [기록] [건너뛰기]. 대사 줄에 편(아군 · 적), 스텝에 배경 키 · 장 번호 · 장 이름.
- 스킬 사용 시 대사(장수 외침)는 **전투의 장수 말풍선 공통 시스템**으로 처리한다 ([battle.md](battle.md) 4.4). 대사 내용만 데이터로 넣으면 된다.

## 2. 스텝 데이터

- 스텝(step01, step02 …)마다 JSON 하나. 형식은 [battle.md](battle.md) 6장 "스텝 JSON 예시".
- 스텝이 정하는 것: 전투 이름, 세력, 맵(안개 포함), 적 군단·레벨·군량, 출전 가능한 아군 군단 수, 승패 조건, 이벤트(대사·증원), 보상(경험치, 진형·스킬 해금, 장수 합류 `joinGenerals` — 첫 클리어에 합류, 이미 있으면 조각 1, R-68).
- 아군 출전 구성은 스텝이 아니라 [부대 편성](formation.md)에서 가져온다.
- 스텝을 추가하는 방법: JSON 파일 하나 + 대사 파일 추가. 코드 수정 없음.

## 3. 대사

- 대사 파일은 스텝마다 하나 (`data/Dialogue/stepNN.json`의 `before`·`after`, 줄마다 `speaker` 장수 id + `key` 문자열 키) + 전투 중 이벤트 대사(스텝의 events). 파일이 없으면 예전 한 줄 대사 `dialogue.<스텝>.start`.
- 지금은 **임시 대사**를 넣고, 나중에 파일만 바꿔 넣는다.

```json
[
  { "speaker": "general_a", "portrait": "general_a", "text": "(임시 대사) 출진하라!" }
]
```

- `speaker`는 장수 id. 화면에 보이는 이름은 테마 문자열에서 가져온다 ([../theme.md](../theme.md)).

## 4. 출진 준비

> 구현 (2026-11-12, E22): 적 정보는 **대략**(장수·병력 천 단위 어림·진형, 예비 표시), 아군 편성은 **고른 상황 편성**(야전 등)을 표시, 내 출진 병력과 적 병력으로 **전력 판단**(유리·비슷·불리·위험), 스텝에 `recommendedLevel`이 있으면 권장 장수 레벨. **군량 ±**: 1~10분 분량 (자동 3분 = R-7), 모자라면 부족량 + [가진 만큼]·[상점]. 고른 분은 출진 요청의 군량으로 서버에도 그대로 간다 (`SortieAdvice`).

| 항목 | 내용 |
|---|---|
| 편성 | 스텝의 전장 유형(야전·공성 …)에 맞는 편성이 자동 선택된다 (없으면 기본 편성, verification R-35). 바꿀 수 있다 |
| 출전 병력 | 부상병·포로 장수는 빼고 계산 |
| 고용 | 고용한 장수·부대를 편성 칸에 넣는다 (서버 도입 후, [hiring.md](hiring.md)) |
| 군량 | 약 3분 분량 자동 계산, 증감 가능. **고용 병사 몫 포함** ([economy.md](economy.md)) |
| 출전 | 보유 군량에서 차감 → 전투 ([battle.md](battle.md)) |

**군량이 부족할 때** (확정)
- 출전 버튼을 비활성화하고 안내: **광고 보고 군량 받기 / 상점 / 출전 병력 줄이기**.

## 5. 전투 이후

**결과 화면**
- 승패, 사망·부상 병력, **부대 결속 증가**, (스위치가 켜져 있으면) 장수 경험치·레벨업, 포획한 군량, 진형·스킬 해금.
- **별점 평가는 두지 않는다** (확정).
- **녹화 저장 / 공략으로 공유** 버튼 ([replay.md](replay.md)).

**패배했을 때** (확정)
- 손실(사망·부상)은 그대로 반영.
- 지참한 군량 중 남은 것은 돌려준다.
- 바로 재도전할 수 있다. 확보한 시야는 유지된다.

**이후**
- 포로 처리: 적 장수 등용·해방, 아군 장수 포로 시 구출 전투 생성 ([captivity.md](captivity.md)).
- **숨은 보상** 판정: 특별 조건을 만족했으면 발견 연출 + 스킬·특성 지급 ([secrets.md](secrets.md)).
- 저장 → 다음 스텝 해금 (승리 시).

## 6. 교체·확장 포인트

| 바꾸고 싶은 것 | 방법 |
|---|---|
| 스텝 추가·수정 | `Steps/stepNN.json` |
| 대사 교체 | `Story/stepNN_*.json` |
| 스텝 해금 규칙 | `StepFlow` (차례 해금이 기본) |
| 스텝 목록 → 지도 표시 | 스텝 데이터에 지도 좌표 추가 + 스토리 화면 모듈 교체 (흐름·전투는 그대로) |
| 스킬 사용 대사 | 전투 이벤트(스킬 사용)에 대사 연결 |
| 스토리 대신 다른 진행 방식 (예: 전략 지도) | 같은 `BattleSetup`을 만들어 전투 호출, `BattleResult`를 받아 처리 ([../flow.md](../flow.md) 5장) |

## 7. 처음 안내 (튜토리얼, R-62)

- 따로 튜토리얼 스텝을 두지 않고, **화면을 처음 열 때 한 번** 짧은 안내 카드를 띄운다 (어두운 판 + 문장, [다음] / 마지막에 [닫기]).
- 안내는 데이터 `Rules/guides.json`: id, 자리(place: `tab.<탭 id>`, `screen.step`, `screen.battle`), 문장 키들. 문장은 테마 문자열 `guide.*` (지금은 임시).
- 지금 있는 안내: 처음(스토리 탭), 출진 전(스텝 화면), 전투(직접 지휘 첫 전투, 읽는 동안 멈춤 → [계속]으로 시작), 편성, 부대 정비, 장수, 장수 키우기(대결).
- 다 읽고 닫으면 행동 `guide.seen`으로 본 기록을 세이브에 남긴다 → 서버를 붙여도 다른 기기에서 다시 나오지 않는다. `guide.reset`(안내 다시 보기)은 규칙·행동만 있고 화면 버튼은 아직 없다 (설정 화면 개편 때).
- 새 안내 추가 = `guides.json` 한 줄 + 문자열. 새 화면이 안내를 띄우려면 `GuideOverlay.Show(앱, 루트, "자리 id")` 한 줄.
