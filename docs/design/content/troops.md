# 병종 체계

> 상태: 설계 뼈대 (수치 미정) · 개발은 단계별로 순차 추가 (6장)
> 관련: [battle.md](battle.md) 2.3(뼈대), 2.16(지형 규칙), 2.19(균형 원칙) · [troop-growth.md](troop-growth.md)(승급·훈련) · [../theme.md](../theme.md)(이름 교체)
> 병종 이름은 현재 테마(옛날 전투) 기준. 데이터는 영문 id를 쓴다. 특정 역사·소설 속 고유 부대명(특정 인물의 친위대 등)은 쓰지 않는다.

---

## 1. 설계 원칙

1. **뼈대는 4개**: 상성 삼각형(창병·궁병·기병) + 기준 병종(보병). 그 밖은 역할 계열(첨병·공성)과 확장 계열(수군·지원).
2. **승급은 "옆으로 강해지기"(사이드그레이드)**: 특화하면 **강점을 얻는 만큼 약점도 생긴다.** 상위 단계가 하위를 완전히 이기지 않는다. 그래야 높은 레벨 하나가 정답이 되지 않는다 (영원한 승자 없음).
   - 예: 장창병은 기병을 확실히 막지만 매우 느리고 측면·궁병에 약하다.
3. **상성은 "부드러운 상성"이 기본**: 유리·불리는 보정값(%p) 차이로 나타난다. 무조건 이기는 "단단한 상성"은 일부(예: 장창병 vs 기병 정면)에만 쓴다.
4. **상성은 태그로 계산**: 병종 이름이 아니라 태그(2장)로 상성·지형 규칙을 정한다. 새 병종은 태그만 달면 자동 적용.
5. **대가 구조**: 강한 병종일수록 하루 군량 소비(1·2·3)가 크거나, 느리거나, 지형 제한이 있다.
6. **3단계**: T1 기본 → T2 특화 → T3 정예. 승급은 부대 키우기(훈련)로 한다.

## 2. 태그

| 태그 | 의미 | 쓰이는 곳 |
|---|---|---|
| `melee` | 근접 | 상성 |
| `ranged` | 원거리 (공격 거리 일정 이상) | 상성, 원거리 규칙 |
| `mounted` | 기마 | 상성, 지형 (성벽·건물 불가, 숲 불리) |
| `polearm` | 장병기 (창·극) | 대기마 가산 |
| `shield` | 방패 | 원거리 피해 감소 |
| `heavy` | 중장 | 느림, 관통 공격에 약함 |
| `light` | 경장 | 빠름, 험지 이동 |
| `piercing` | 관통 공격 (노 등) | 중장 상대 가산 |
| `fire` | 불 공격 | 숲 점화, `flammable` 상대 가산 |
| `flammable` | 불에 약함 (등갑 등) | 화계·불화살 추가 피해 |
| `scout` | 정찰 | 시야·탐지 |
| `stealth` | 은신 | 복병 |

| `support` | 지원 | 직접 전투력 낮음 |
| `mountaineer` | 산악 | 산 이동·방어 가산 |
| `naval` | 수상 | 수상전 전용 |
| `elite` | 정예 | 사기 안정, 군량 큼 |

## 3. 병종 트리

표의 수치는 **방향만** 나타낸다 (↑ 높음, ↓ 낮음). 실제 값은 데이터에서 정한다. 공격 거리는 [battle.md](battle.md) 2.16 기준(보병 1, 창병 2, 궁병 10).

### 3.1 보병 계열 (기준) `infantry`

```
보병 ─┬─ 방패병 ─┬─ 근위병
      │          └─ 등갑병
      ├─ 도부수 ─── 돌격보병
      └─ 경보병 ─── 산악병
```

| 병종 | id | 단계 | 강점 | 약점 | 거리 | 군량 |
|---|---|---|---|---|---|---|
| 보병 | `infantry` | T1 | 균형, 전선 유지, 점령·성 진입 | 특별한 강점 없음 | 1 | 1 |
| 방패병 | `shieldbearer` | T2 | 원거리 피해 크게 감소, 정면 방어↑ | 느림, 공격↓, 측면 약함 | 1 | 1 |
| 도부수 (도끼·칼) | `axeman` | T2 | 공격↑, 방패 상대 가산 | 방어↓, 원거리에 약함 | 1 | 1 |
| 경보병 | `lightInfantry` | T2 | 빠름, 숲·험지 이동 | 방어↓, 기병 돌격에 약함 | 1 | 1 |
| 근위병 | `guard` | T3 | 장수 곁에서 방어↑, **장수 포로 확률 감소**, 사기 안정 | 느림, 비쌈 | 1 | 2 |
| 등갑병 | `rattanArmor` | T3 | **물리 피해 크게 감소**, 가벼워 얕은 강 통과 | **불에 매우 약함** (`flammable`) | 1 | 2 |
| 돌격보병 (결사대) | `assaultInfantry` | T3 | 성문·성벽 공격↑, 돌격↑ | 사기가 꺾이면 빠르게 무너짐 | 1 | 2 |
| 산악병 | `mountaineer` | T3 | **산 이동·방어 가산**, 산에서 매복 | 평지에서 약함 | 1 | 1 |

```
창병 ─┬─ 장창병 ─── 창벽병
      ├─ 극병 ───── 정예극병
      └─ 투창병
```

| 병종 | id | 단계 | 강점 | 약점 | 거리 | 군량 |
|---|---|---|---|---|---|---|
| 창병 | `spearman` | T1 | 기병 상대 가산 | 궁병에 약함 | 2 | 1 |
| 장창병 | `pikeman` | T2 | **기병 정면 돌격을 확실히 막음** (단단한 상성), 거리↑ | **매우 느림**, 진형 변경 느림, 측면·궁병에 약함 | 3 | 1 |
| 극병 | `halberdier` | T2 | 기병·보병 모두 상대 가능, 공격↑ | 원거리에 약함, 특화가 약함 | 2 | 1 |
| 투창병 | `javelineer` | T2 | 짧은 원거리 + 근접 가능, 방패 상대 가산 | 원거리 횟수 제한(근접 전환), 방어↓ | 4 | 1 |
| 창벽병 | `pikeWall` | T3 | 방원·횡진에서 정면 철벽, 사기 안정 | 거의 움직이지 못함, 측면·후방 치명적 | 3 | 2 |
| 정예극병 | `eliteHalberdier` | T3 | 공격·방어↑ 균형 정예 | 비쌈 | 2 | 2 |

### 3.3 궁병 계열 (원거리) `archer`

```
궁병 ─┬─ 노병 ─┬─ 연노병
```

|---|---|---|---|---|---|---|

| 노병 (쇠뇌) | `crossbowman` | T2 | **관통**: 중장 상대 가산 | 연사 느림, 근접 매우 약함 | 9 | 1 |

## 4. 상성 요약 (태그 기준, 부드러운 상성)

| 공격 ＼ 상대 | 보병 | 창병 | 궁병 | 기병 | 방패 | 중장 | 공성 |
|---|---|---|---|---|---|---|---|
| 보병 | - | - | ○ | - | - | - | ○ |
| 창병 (`polearm`) | - | - | × | **◎** | - | - | - |
| 궁병 (`ranged`) | - | ○ | - | × | **×** | - | - |
| 기병 (`mounted`) | - | **×** | ○ | - | - | - | ○ |
| 관통 (`piercing`) | - | - | - | ○ | ○ | **○** | - |
| 불 (`fire`) | - | - | - | - | - | - | - (`flammable` ◎) |

◎ 크게 유리 · ○ 유리 · × 불리 · - 보통. 값은 `balance.json`.

## 6. 개발 순서 (순차 추가)

| 단계 | 병종 | 이유 |
|---|---|---|
| **1차** (첫 전투) | 보병, 창병, 궁병, 기병, 첨병 | 뼈대 + 시야, 복병·간파 상호작용 |
| **2차** | 각 계열 T2 (방패병, 도부수, 경보병, 장창병, 극병, 노병, 장궁병, 화궁병, 경기병, 중기병, 궁기병, 매복병, 정찰기병) + 투석기 | 특화·상성 깊이, 화계 연계 |
| **3차** | T3 정예 + 공성(충차, 운제, 노포, 공병) | 성새전 |
| **4차** | 수군 (수상전), 지원 병종, 테마 특수 | 확장 전장 |

- 데이터 형식은 처음부터 전 병종을 담을 수 있게 만들고, 단계마다 데이터만 추가한다.

## 7. 미결 사항

- [ ] 병종별 실제 수치 (공격·방어·속도·거리·시야·진형 변경 속도·군량)
- [ ] 승급 조건 (훈련도, 장수 레벨, 스텝 해금, 비용)

- [ ] 수군 체계 (배가 병사를 태우는 방식 / 배 자체가 병종)
- [ ] 각 병종 이름 확정 (테마 문자열)
