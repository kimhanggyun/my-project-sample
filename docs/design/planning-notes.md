## 1. 프로젝트 개요

- 「삼국지 **와룡전**」(코에이)의 **전투 장면 일부만 참고**한 모바일 게임. **삼국지 게임이 아니다.** 세계관·인물은 자체로 만들고, 지금은 익명·임시 이름을 쓴다.
- **안드로이드와 아이폰에 동시 출시**할 예정. 엔진은 Unity가 유력 후보이며 설계가 끝난 뒤 확정한다 (impl/unity/decisions.md).
- 처음에는 **전투 부분만** 만든다. 나중에 스토리와 국가 경영(전략 화면)을 붙일 수 있게 구조를 잡는다.

### 참고 게임 정정 기록
- 처음에는 턴제 격자 SRPG(영걸전·공명전 계열)로 잘못 짚었다.
- 그 기준으로 웹 시안 「광종 전투」를 만들었지만, **장르가 달라 참고에서 제외한다.**
- 「공명전」 이야기도 잠깐 나왔으나 **최종 참고 게임은 와룡전**으로 확정했다.
- 와룡전 전투는 **실시간 군단 지휘** 방식이다.

## 2. 확정된 결정

| 항목 | 결정 |
|---|---|
| 엔진 | **설계 후 확정** (후보: Unity — impl/unity/decisions.md) |
| 그래픽 | **3D** (2D 아님) |
| 플랫폼 | 모바일, **안드로이드 + 아이폰 동시 출시** |
| 로그인 | **게스트 허용**. 자동 로그인(구글 플레이 게임즈 / Game Center), 계정 연동(구글 / Apple). 카카오 등 국내 로그인은 출시 시 생략, 나중에 추가 가능한 구조. 앱 시작 흐름은 content/startup.md |
| 화면 방향 | **세로** |
| 첫 개발 범위 | 전투만. 전략 화면은 이후 확장 |
| 첫 전장 유형 | **야전** → 성새전 → 수상전 순서 |
| 전투 진행 | 실시간 자동 전투 + 플레이어 지휘, 일시정지·배속 |
| 명령 단위 | **군단 단위** |
| 미니맵 | 기본 숨김, 탭하면 펼침 |
| 데이터 | 전투명, 군단명 등 **모든 값은 JSON** (예시 이름은 임시) |
| 스텝 구성 | 스텝(step01, step02 …)별로 맵, 적 군단 수, 전투력, 보상(경험치·레벨업) 설정 |
| 진형 | 6개 소부대의 **배치 위치**. 군단 이동 시 각자 자리로 이동 |
| 세부 동작 | **소부대별 능력치 입력** → 반경 내 최근접 적 처리, 능력치가 높으면 빈 곳을 스스로 메움 |
| 능력치 범위 | 1~100, **소수점 허용** |
| 장수 보너스 | 통솔 → 규율(즉각 반응, 진형 유지), 무력 → 용맹(공격·사기, 대신 지휘 이탈), 지략 → 판단력·스킬 |
| 진형 장단점 | 진형마다 특성치와 상성. **같은 능력치면 진형 상성으로 승패 결정** |
| 능력치 확장 | 능력치 항목은 데이터로 정의. 새 항목이 생겨도 코드 수정 없음 |
| 장수 능력치 | 통솔·무력·지략 등 여러 항목, 소부대 능력치에 영향 |
| 스킬 | 장수 스킬, **지략이 높을수록 어려운 스킬 사용 가능** |
| 병종 | 보병·창병·궁병·기병 기본, **성장하면 특화 병종으로 승급** |
| 장수 추가 규칙 | 지휘 범위, 진형 숙련도, 특성 태그, 문관 피격 → 채택 |
| 병력 표현 | 전투는 병력 숫자로 계산, **화면 병사 1명 = 병력 N명**. N은 기기 성능에 맞춰 끊기지 않는 선에서 최대한 많이 보이게 자동 조정 |
| 피해 계산 | 병력 1:1 기본, 상성·상황은 **가산(%p 합산)**. 합계에 상·하한 |
| 사기 | 피해 계산 가산 항목 중 하나 |
| 퇴각·포로 | 장수가 도망을 선택하면 퇴각, 적에게 포위되면 포로(군단 궤멸) |
| 아군 포로 | 적 **수용소**에 갇힘(표기), 출전 불가. **수용소를 공격하는 구출 전투**로 되찾음 |
| 적 포로 | 전투 후 **등용 / 해방** 선택. 등용 실패 시 **계속 감금**, 재시도 대기시간(기본 3시간) 후 다시 등용 시도. 해방 시 **보상**(내용은 추후) |
| 구출 기한 | **기본 1달**, 변경 가능 (실제 시간 기준). **지나면 자동 석방** |
| 등용 재시도 | 대기시간 **기본 3시간** (설정값) |
| 등용 불가 장수 | 존재. 장수 설정값 `recruitable`로 제어 (해방만 가능) |
| 이동 | 군단은 장수를 따라감 (장수 기준 경로 탐색, 소부대·병사는 추종). 좁은 길은 종대로 자동 전환 |
| 수치 조정 | JSON 값 + 개발용 실시간 조정 패널 + 자동 밸런스 시뮬레이터 |
| 전장 안개 | 기본으로 맵이 안 보임. **부대마다 시야가 다르고**, 척후병·능력치·지형으로 시야 확보 |
| 상태 표시 | 머리 위 표시 대신 **병사 몸**(색·자세·동작)으로 사기·버프 등 표시 |
| 진형·스킬 | **장수·부대 키우기에서 배움** (TO-BE 동안은 스텝 데이터가 지정) |
| 안개 | 스텝별 맵 데이터에 포함 |
| 전투 길이 | **군량**으로 결정. 시간당 소비량은 부대 인원에 비례 |
| 군량 | 게임 진행 자원. 출진에 필요, **앱 결제**로 구매 |
| 군량 소비 | 병사 1명당 하루 1, **전투 1분 = 1주**. 특수 병종은 2·3 (확장) |
| 군량 회복 | **특수 패키지 구입 시에만** 시간 회복 |
| 승리 보상 | **적 남은 군량 포획**. 빨리 이길수록 많음. 퇴각한 적은 살아남은 병사 몫만 가져가고 나머지 몰수 |
| 군량 충전 | **광고 보기 보상** + 앱 결제 |
| 광고 | 보상형 광고(군량), **상단 바 바로 아래 띠 배너는 탭별 화면에서만** (전투 제외). 상세: ads.md |
| 광고 제거 상품 | 배너 영구 제거 **5,000원**, 한 달 제거 **1,000원**(30일 이용권, 자동 갱신 없음) (구글·애플 모두) |
| 출진 군량 | **자동 계산(약 3분 분량)**, 플레이어가 늘리거나 줄일 수 있음 |
| 군량 소진 | 사기 지속 하락 → 자동 퇴각 |
| 시야 공유 | **아군 전체 공유** (부대마다 보는 범위만 다름) |
| 원거리 공격 | **궁병 능력치(사거리)에 따라 사정거리가 다름** + 병종·높이 보정 |
| 터치 명령 | 적 군단 터치 → 공격 대상 지정, 빈 땅 터치 → 이동 명령 |
| 스킬 지정 | 대상·지점 지정, 사거리 밖이면 접근 후 사용, 지점 스킬(복병 등)은 **이동만 / 도착 후 사용** 선택 |
| 전장 터치 선택 | 부대원을 감싼 영역(+여유 반경)을 터치하면 그 군단 선택. UI 선택과 같은 결과 |
| 군단 수 | **가변.** 스텝이 오를수록 늘리거나 맵별로 다르게. **기본 3개** |
| 스토리 | 대사는 임시로 넣고 나중에 직접 입력해서 교체 |
| 타이틀 | 임시 타이틀 |
| 코드 구조 | **시스템마다 클래스 분리**, 확장성 우선 |
| 레벨링 | 스텝별 레벨링 적용 |
| 메인 화면 | **하단 탭**: 스토리, 장수 키우기, 부대 키우기, 부대 편성 (추가 가능). **설정은 상단 톱니바퀴** |
| 키우기 탭 | 장수 키우기, 부대 키우기는 **TO-BE** ("준비 중"). **목적: 다른 유저가 고용할 장수·부대를 키우는 것**. 부대 키우기 = 부대를 통째로 손발이 맞게 훈련 (예: 보병 → 등갑병) |
| 용병 고용 (온라인) | **장수 고용**과 **부대 고용** 두 가지. 키운 장수·부대를 각각 **서버에 등록**, 다른 유저가 **전투 이력(승리·퇴각 등)**을 보고 고용, 고용되면 등록자 **보상**. 상세: content/hiring.md |
| 스텝 반복 | 깬 스텝 **반복 가능**. 목록 표시는 나중에 **지도**로 바꿀 수 있게 |
| 적 정보 | 적 군단 수·대략 병력·권장 레벨만 공개. **확보한 시야는 재도전 때 유지** |
| 대사 | 전·후 대사 + 건너뛰기. 스킬 사용 대사는 나중에 추가 |
| 군량 부족 | 출전 버튼 비활성 + 광고·상점·병력 줄이기 안내 |
| 패배 | 손실 반영, 남은 군량 반환, 바로 재도전 |
| 결과 평가 | **별점 없음**. 대신 **전투 녹화와 공략 공유** (content/replay.md) |
| 녹화·공유 | 게임 안은 **전투 기록**으로 공유(가볍고 3D 자유 시점), 게임 밖은 **영상(mp4) 저장 후 폰 공유 창**으로 공유 |
| 스텝 밸런스 | 스텝별 적군 밸런스는 **출시 후 고정** (개발 중에만 조정) |
| 전투 핵심 원칙 | **가위바위보처럼 절대 강자 없음, 상황에 따른 아슬아슬한 승리.** 모든 강점에 반격 수단·대가, 보정 상한, 정보(안개), 맵이 답을 바꿈 |
| 병종 특성 | 병종별 공격력·방어력·이동 속도·**공격 거리(보병 1, 창병 2, 궁병 10)**·시야·진형 변경 속도 |
| 지형 규칙 | 병종 × 지형 규칙표 (기병 성벽 불가, 투석기 산 불가, 산악병 산 가산, 건물 진입 불가), 해상전 기병 투입 불가 |
| 사기 | 시작 사기는 장수 역량. 사기 높을 때 공격 가산은 무력 비례, 방어 가산은 지략 비례 |
| 성향·특성 | **성향 1개**(용맹·냉정·신중·교활·충직·오만·소심: 퇴각·대결·AI 경향) + **특성 여러 개**(전투·지휘·계략·지형·날씨·병종·보급·대결·고유, 가산 보정, 단점 섞인 특성 포함). 특성 칸은 등급별 (content/traits.md) |
| 특성서 | 채택. 스킬북처럼 상점에서 구매 |
| 장수 부상 | **경상**(출전 가능, 능력치 −10%, 약 1시간) / **중상**(일기토 패배, 출전 불가, 약 6시간). 즉시 치료 가능, 대전·고용은 반영 안 함 (battle.md 2.5.3) |
| 숨은 보상 | 스토리·장수 키우기 등에서 **숨은 조건**을 만족하면 스킬·특성 획득(이스터 에그). 조건은 비공개, 발견 시 연출, **도감**(못 찾은 것은 ???)·**힌트**, 능력치 부족 시 스킬북·특성서로 보관, 전투 조건은 서버 재현으로 확정 (content/secrets.md) |
| 검증 예시 | **규칙 예시(R)**는 계산 방식(바꾸면 설계 버전↑), **수치 예시(N)**는 그 시점 예시 수치(밸런스 조정 시 갱신). 첫 구현 후 기준 전투 정답 파일 (design/verification.md) |
| 상점 원칙 | **상점 구매는 지름길일 뿐, 유일한 수단이 아님.** 상점에서 파는 모든 것은 플레이로도 얻을 수 있음 (예외: 광고 제거·시간 회복 같은 편의 기능). 뽑기 장수의 플레이 경로는 더 오래 걸리게. **현금 구매자 우대용 상점 전용 장수·스킬·특성은 추후 검토** (economy.md 0장) |
| 장수 획득 | **뽑기**(+ 초기 지급·등용·고용). **능력별 등급제**(예: 일반~전설, 능력치 범위·성장률·기본 스킬 수·스킬 칸). 국내 **확률 공개 의무** 준수, 뽑기 결과는 서버 결정. 뽑기 비용은 **전용 재화** (content/generals.md) |
| 장수 스킬 | 장수마다 **기본 스킬**, 추가 스킬은 **스킬북 구매 후 습득**(요구 능력치 충족) |
| 장수·부대 보유 | **장수와 부대를 따로 보유**. 군단 = 장수 + 소부대 칸 6개, **칸 1개 = 부대 1개**. 군단 병력 = 부대 병력 합계 ≤ 장수 통솔 한도. 병종 변경 = 부대 교체(훈련도·결속은 부대에 남음). 장수 포로로 군단 궤멸해도 부대는 남음 (formation.md 2장) |
| 카메라·화면·세이브 | 고정 쿼터뷰(이동·확대축소, 회전 없음) / 1080×1920 기준 + 안전 영역 / 클라우드 저장 기본 + 기기 사본 |
| 지형 상성 | 지형별 병종 전투 보정표 (예: 숲 = 보병 > 창병 > 궁병 > 기병) (battle.md 2.16.1) |
| 보급소 | 점령 시 군량 회복 |

| 병종 체계 | 뼈대 4(창·궁·기 삼각형 + 보병) + 첨병·공성 계열, T1~T3 사이드그레이드 트리, 태그 상성. 개발은 1차(보·창·궁·기·첨병) → 2차(T2+투석기) → 3차(T3+공성) → 4차(수군·지원) (content/troops.md) |

| 책략 점수 회복 | 사기가 높을 때 천천히 회복 (스위치로 켜고 끔) |

## 3. 참고 영상 분석 (안읍 전투, 장비군 vs 하후연군)

> 참고용 기록이다. 영상 속 인물·지명은 게임에 쓰지 않는다.

33초 분량 영상에서 프레임을 뽑아 확인한 내용이다.

### 화면 구성
- **전장:** 쿼터뷰 시점. 부대마다 병사 10~20명이 실시간으로 움직인다.
- **우측 상단:** 전투명과 세력 대결("안읍 전투 / 유비 대 장로"), 그리고 ◀ 적 군단명 ▶.
- **미니맵:** 공성전 맵은 세로로 긴 통로 구도다. 위에 적 성, 가운데 해자·다리, 아래에 아군이 있다.
- **지휘 패널:**
  - ◀ 아군 군단명 ▶
  - 진형 아이콘 16개
  - 명령 6개: 돌격 · 공격 · 대형 · 성벽 · 수비 · 후퇴
  - 대치 표시창: 적 진형 / 교전 / 아군 진형
  - 배속 버튼 ▶▶
- **하단 바:** 소부대 6개 카드(선봉·중앙·좌익·우익·좌비·우비). 카드마다 병종 아이콘과 상태가 표시된다.
- **대사 팝업:** 장수 초상화 + 대사. 예: "모두 성벽 위에서 공격하라!!", "졸장! 장비, 네놈 목을 일단 맡겨두마!"

### 전투 흐름
1. 아군이 다리를 건너 성문으로 돌격한다.
2. 성 안으로 진입한다.
3. 적 장수가 퇴각한다.
4. 전략 지도로 돌아가고 날짜가 흐른다.

전략 화면 메뉴(참고, 이후 확장 대상): 진언 · 인사 · 재정 · 편성 · 군단 · 거점 · 장군 · 세력. 자금·예비병·날짜도 표시된다.

## 4. 와룡전 전투 시스템 (분석 자료 반영)

출처는 사용자가 제공한 AI 요약 분석이다. **수치는 원작 검증 전이므로 조정 가능한 기본값으로만 사용한다.**

- **6개 소부대 군진:** 선봉, 중앙(장수), 좌익, 우익, 좌비, 우비.
- **진형과 상성:** 보병·기병·궁병 상성. 진형 변경 타이밍과 측면·배후 기습이 중요하다.
- **예비 병력 보충:** 원작 군단 최대 병력(약 6,000명, 우리 게임은 통솔에 따라 5,000~20,000)이 한 화면에 다 나오지 않는다. 죽은 병사 자리를 화면 밖에서 걸어 나와 채운다. 전선 유지가 핵심이다.
- **사기:** 사기가 떨어지거나 예비 병력이 약 10% 이하가 되면, 장수 성향에 따라 자동 퇴각한다.
  - 문관이 피격되면 사기가 급락한다.
  - 일류 책사는 자동 전술로 이를 보완한다.
- **능력치 역할:** 야전에서는 무력, 공성·수성에서는 통솔이 중요하다.
- **일기토:** 야전 직전에 무력 차이가 3 이내이면 높은 확률로 발생한다. 책사는 거부한다. 패배하면 사기가 폭락한다.
- **전장 유형:**
  - 야전
  - 성새전: 수비 측이 크게 유리
  - 수상전: 배다리 위라 대형이 흐트러지는 난전
- **전투지휘와 위임:** 직접 지휘하거나 AI에게 자동 전투를 맡길 수 있다.

### 맵
- 성벽 맵 말고도 여러 지도가 있다.
- 맵은 **조립식 지형 부품**(평지, 숲, 언덕, 강, 다리, 성벽, 성문 …)을 배치해 데이터로 정의한다.
