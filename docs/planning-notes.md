## 1. 프로젝트 개요

- 「삼국지 **와룡전**」(코에이)의 전투를 참고한 모바일 게임.
- Unity로 개발해 안드로이드부터 출시할 예정.
- 처음에는 **전투 부분만** 만든다. 나중에 스토리와 국가 경영(전략 화면)을 붙일 수 있게 구조를 잡는다.

### 참고 게임 정정 기록
- 처음에는 턴제 격자 SRPG(영걸전·공명전 계열)로 잘못 짚었다.
- 그 기준으로 웹 시안 「광종 전투」를 만들었지만, **장르가 달라 참고에서 제외한다.**
- 「공명전」 이야기도 잠깐 나왔으나 **최종 참고 게임은 와룡전**으로 확정했다.
- 와룡전 전투는 **실시간 군단 지휘** 방식이다.

## 3. 참고 영상 분석 (안읍 전투, 장비군 vs 하후연군)

33초 분량 영상에서 프레임을 뽑아 확인한 내용이다.

### 화면 구성
- **전장:** 쿼터뷰 시점. 부대마다 병사 10~20명이 실시간으로 움직인다.
- **우측 상단:** 전투명과 세력 대결("안읍 전투 / 유비 대 장로"), 그리고 ◀ 적 군단명 ▶.
- **미니맵:** 공성전 맵은 세로로 긴 통로 구도다. 위에 적 성, 가운데 해자·다리, 아래에 아군이 있다.
- **지휘 패널:**
  - ◀ 아군 군단명 ▶
  - 진형 아이콘 16개
  - 명령 6개: 돌격 · 공격 · 대형 · 성벽 · 수비 · 후퇴
  - 대치 표시창: 적 진형 / 교전 / 아군 진형
  - 배속 버튼 ▶▶
- **하단 바:** 소부대 6개 카드(선봉·중앙·좌익·우익·좌비·우비). 카드마다 병종 아이콘과 상태가 표시된다.
- **대사 팝업:** 장수 초상화 + 대사. 예: "모두 성벽 위에서 공격하라!!", "졸장! 장비, 네놈 목을 일단 맡겨두마!"

### 전투 흐름
1. 아군이 다리를 건너 성문으로 돌격한다.
2. 성 안으로 진입한다.
3. 적 장수가 퇴각한다.
4. 전략 지도로 돌아가고 날짜가 흐른다.

전략 화면 메뉴(참고, 이후 확장 대상): 진언 · 인사 · 재정 · 편성 · 군단 · 거점 · 장군 · 세력. 자금·예비병·날짜도 표시된다.

## 4. 와룡전 전투 시스템 (분석 자료 반영)

출처는 사용자가 제공한 AI 요약 분석이다. **수치는 원작 검증 전이므로 조정 가능한 기본값으로만 사용한다.**

- **6개 소부대 군진:** 선봉, 중앙(장수), 좌익, 우익, 좌비, 우비.
- **진형과 상성:** 보병·기병·궁병 상성. 진형 변경 타이밍과 측면·배후 기습이 중요하다.
- **예비 병력 보충:** 군단 최대 병력(약 6,000명)이 한 화면에 다 나오지 않는다. 죽은 병사 자리를 화면 밖에서 걸어 나와 채운다. 전선 유지가 핵심이다.
- **사기:** 사기가 떨어지거나 예비 병력이 약 10% 이하가 되면, 장수 성향에 따라 자동 퇴각한다.
  - 문관이 피격되면 사기가 급락한다.
  - 일류 책사는 자동 전술로 이를 보완한다.
- **능력치 역할:** 야전에서는 무력, 공성·수성에서는 통솔이 중요하다.
- **일기토:** 야전 직전에 무력 차이가 3 이내이면 높은 확률로 발생한다. 책사는 거부한다. 패배하면 사기가 폭락한다.
- **전장 유형:**
  - 야전
  - 성새전: 수비 측이 크게 유리
  - 수상전: 배다리 위라 대형이 흐트러지는 난전
- **전투지휘와 위임:** 직접 지휘하거나 AI에게 자동 전투를 맡길 수 있다.

### 맵
- 성벽 맵 말고도 여러 지도가 있다.
- 맵은 **조립식 지형 부품**(평지, 숲, 언덕, 강, 다리, 성벽, 성문 …)을 배치해 데이터로 정의한다.

## 5. 제안 사항 (Claude 의견)

| 주제 | 제안 | 이유 |
|---|---|---|
| 일시정지 중 명령 | 허용 | 모바일 터치 조작 부담을 줄임 |
| 위임 버튼 | 추가 | 원작의 위임 기능. 실시간 지휘 피로도 완화 |
| 진형 수 | 첫 버전 4~6종 | 원작은 16종이지만 모바일 UI와 밸런스를 고려 |
| 화면 병사 수 | 소부대당 상한, 병력 수와 분리 | 3D 모바일 성능. 원작의 보충 방식과도 맞음 |
| 데이터 형식 | JSON (ScriptableObject 대신) | 텍스트라 직접 수정하기 쉽고, 클라우드 작업에서도 편집 가능 |
| 씬 생성 | 에디터 메뉴(`Tools > Setup Scenes`)로 자동 생성 | 클라우드 환경에서는 Unity 에디터 실행 불가 |
| Unity 버전 | Unity 6 LTS | 장기 지원 |
| 적 레벨 | 스텝 JSON에 고정값 | 의도한 밸런스 유지 |
| 아군 성장 | 스텝 간 레벨 이월 | 육성의 재미 |
| 전투 모듈 경계 | `BattleSetup` → 전투 → `BattleResult` | 전략 화면을 붙여도 전투 코드 수정 없음 |
| 규칙과 화면 분리 | Model(순수 C#) / View(Unity) | 테스트 가능, 유지보수 |
| 3D 에셋 | 로우폴리 임시 에셋 → 교체 | 초기 개발 속도 |
| 세로 레이아웃 | 상단 전장 / 중단 지휘 패널 / 하단 소부대 카드 | 원작 미니맵의 세로 통로 구도와도 맞음 |

## 6. 미결 사항

### 전투 규칙
- [ ] 한 전투에서 한쪽당 **군단 최대 수**
- [ ] 명령 6개의 세부 동작, 특히 "대형"과 "성벽"
- [ ] 첫 버전 **진형 종류**와 각 진형 효과
- [ ] 병종 추가 여부 (보병·기병·궁병 외)
- [ ] 승리 조건 종류 (적 대장 격파, 성 점령, 시간 버티기)
- [ ] 사기 증감 규칙의 구체 수치
- [ ] 일기토 연출 방식 (별도 화면 / 전장 위 연출)
- [ ] 책사 자동 전술 종류

### 성장
- [ ] 경험치 획득 기준 (승리, 격파 수, 생존 등)
- [ ] 레벨업 시 능력치 상승 방식 (고정 / 성장률 / 랜덤)
- [ ] 레벨 상한

### 화면·연출
- [ ] 카메라 기본 각도와 조작 (회전 허용 여부)
- [ ] 3D 아트 방향 (사실풍 / 로우폴리 / 카툰)
- [ ] 결과 화면 구성

### 프로젝트
- [ ] 저장소: `my-project-sample`을 계속 쓸지, 새 저장소로 옮길지
- [ ] 화면 해상도 기준 (예: 1080×1920)

## 7. 작업 환경 메모

- 이 작업은 클라우드 환경에서 진행되며, 다음 제약이 있다.
  - Unity 에디터 실행 불가: 코드와 데이터는 여기서 만들고, 실행과 확인은 맥북에서 한다.
  - 맥북 로컬 파일 접근 불가: 참고 자료는 대화에 업로드하거나 GitHub에 올린다.
  - YouTube, 위키 등 일부 사이트 접근 차단: 필요하면 환경 설정의 Allowed domains에 추가한다.
- 맥북 폴더 연결: Claude Desktop의 **Settings → Claude Code → Remote Control**에 Git 저장소 폴더를 등록하면 이 세션에서 연결을 요청할 수 있다.
